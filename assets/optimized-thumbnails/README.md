# 작은 화면용 개체 이미지

원본 PNG와 스프라이트는 수정하지 않는다. 원래 캔버스 비율과 투명 여백을 유지한 상태로 목록용 320px, 큰 정지 미리보기용 640px WebP를 별도 출력한다. 얼굴·지느러미·반투명 가장자리는 밝고 어두운 배경에서 확인한다.

`npm run images:thumbnails`로 갱신한다. 로컬에 없는 원본은 `-- --fetch-missing`을 명시했을 때만 공개 Storage에서 읽어 로컬 캐시에 보존한다. 일반 앱 빌드에는 네트워크 접근이나 이미지 재변환이 필요하지 않다.

생성 manifest는 입력 해시·원본 위치·크기·출력 해시 URL을 기록한다. 같은 원본과 변환 설정은 같은 URL을 사용하고, 그림이나 설정이 바뀌면 새 URL을 만든다. 현재 카탈로그에 없는 경로와 이미지 오류에는 원본 경로를 사용한다. 애니메이션 프레임과 배치 기준점에는 이 변환을 적용하지 않는다.
