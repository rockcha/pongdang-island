## 일반·희귀

퐁이처럼 친근하고 통통한 비율과 명확한 실루엣을 사용합니다. 작은 화면에서도 형태와 표정이 잘 읽혀야 합니다. 일반도 사실적인 생물 도감 그림으로 만들지 않습니다. 희귀는 같은 카툰 그림체를 유지하면서 개체 고유의 색·재질·무늬를 풍부하게 표현합니다. 눈이 없는 생물이나 사물에 얼굴을 억지로 붙이지 않습니다.

## 특급·신화

신화 생성은 [신화 제작·검수 절차](../mythic-sprites/README.md)와 [검수한 개체별 참고](../mythic-sprites/index.md)를 함께 사용합니다. 스타일·개체 동일성·배치 가이드의 역할을 분리하고, 원본 단계의 셀 경계 검사부터 앱 연결까지 해당 절차를 따릅니다.

신화 어종의 필수 시트 구성은 4×2의 8프레임입니다. 앞 4장은 기본 동작, 뒤 4장은 개체별 추가 행동으로 구성하고 6초 주기로 재생합니다. 눈 상태·발광만 반복하는 공통 행동 대신 개체의 구조와 설정에 맞는 동작을 설계합니다. 머리·몸통 기준점과 동일한 배율을 유지하며 모든 자세의 끝부분·발광이 셀 경계를 넘지 않게 검수합니다. 앱 연결·모션 감소·누락 검사 절차는 [이미지 작업 규칙](../../AGENTS.md)을 따릅니다. 특급은 기본 2×2의 4프레임을 사용합니다.

첫 번째 참고 이미지의 매끈한 빛·색과 부드러운 판타지 일러스트 표현을 기준으로 합니다. 굵은 갈색 선을 그대로 유지한 채 금장·보석만 늘리는 방식은 피합니다. 지느러미·꼬리의 흐름, 섬세한 명암, 자연스러운 빛무늬로 화려함을 표현합니다. 신화도 같은 그림체 계열에서 개체 설정에 맞게 신비감과 표현의 밀도를 높입니다.

보라색·별무늬·가오리라는 소재 자체를 모든 개체에 강제하지 않습니다. 퐁이의 털·귀·낚싯바늘·불가사리도 다른 개체에 복제하지 않습니다. 등급과 개체 설정에 맞는 그림체만 참고합니다.

2026-10-21 사용자 확정: 별빛 가오리 참고의 실루엣을 그대로 재사용하지 않습니다. 위로 길게 솟은 날개형 지느러미, 작은 몸통과 리본 꼬리를 반복하거나 색·비늘·보석만 바꾸는 방식은 금지합니다. 사용자가 그 형태를 명시적으로 요청한 경우에만 허용합니다. 생성 프롬프트에는 참고의 역할을 채색·조명·재질로 한정하고, 새 개체의 해부 구조와 실루엣을 별도로 명시합니다. 검수에서도 채색과 별개로 몸통·지느러미·꼬리의 외곽선을 확인합니다.

## 생성·검수

### 프레임이 위아래로 끊기는 문제 방지

그림하울 교체 과정에서 투명한 위치를 머리 기준 패치로 잡아, 매칭 실패가 거대한 유한 오차 값과 `[0,0]` 이동으로 저장되는 문제가 확인됐다. 여백 검사 통과와 숫자가 유한하다는 사실만으로 위치 보정이 성공했다고 판단하지 않는다.

- 프롬프트에 모든 셀의 눈·머리 좌표와 머리 크기를 고정한다. 위 행과 아래 행의 상대 머리 높이도 같아야 한다. 꼬리의 파동과 개체 전체의 세로 이동을 구분한다.
- 시트 생성 후 기준 패치를 실제 PNG 위에서 확인한다. 눈 주변·단단한 볼처럼 불투명한 고정 부위를 선택하고, 투명 배경·움직이는 꼬리·지느러미·열리는 입은 피한다. 기본 비율 좌표를 개체 확인 없이 재사용하지 않는다.
- `register-sprite-anchors.ps1`은 충분한 불투명 표본이 없는 패치, 매칭 실패, 큰 오차를 오류로 중단해야 한다. `[0,0]`은 성공의 증거가 아니며, 매우 큰 유한 RMSE도 실패다. 실패를 기본 0 보정으로 대체해 등록하지 않는다.
- 정지 위치에서 `0→1→2→3→0`을 최소 세 번 재생하고 눈·볼의 기준선을 겹쳐 확인한다. 특히 `1→2`의 행 전환과 `3→0`의 반복 경계를 검사한다. 머리 높이가 튀면 위치 보정·그리드·원본 자세를 수정하고, 자세 자체가 달라졌으면 재생성한다. 프레임별 확대나 속도 증가로 감추지 않는다.
- 보정은 시트 전체에 하나의 배율과 프레임별 평행 이동만 적용한다. 수정한 경로·실제 셀 크기가 런타임 보정 키와 일치하는지 확인하고, 어항과 도감 양쪽에서 게임 표시 크기로 재생한 후에 등록한다.

### 유영 동작과 눈깜빡임

움직일 요소는 개체의 구조와 이동 방식, 이동할 때 받는 물살을 기준으로 정합니다. 꼬리·지느러미만 의무적으로 움직이는 규칙이 아닙니다. 물살에 흩날리는 촉수·몸 가장자리·천·장식, 부드러운 몸의 수축·이완, 탈것의 추진기·작은 안정판 등 해당 개체에 어울리는 요소를 선택합니다. 단단한 몸통·선체는 안정적으로 유지하고, 앞지느러미는 손처럼 한쪽만 크게 젓지 않습니다. 상어·고래는 큰 팔 젓기보다 작은 자세 조정과 자연스러운 물살 반응을 우선합니다.

스프라이트의 최우선 목표는 개체가 자연스럽게 이동하는 모습입니다. 기본 네 프레임은 그 개체가 이동할 때 힘을 쓰거나 물살에 반응할 부분의 연속 동작으로 구성합니다. 몸의 구조에 맞춰 움직일 요소와 안정적으로 유지할 요소를 구분하며, 손·팔처럼 보이는 부위가 한쪽만 과하게 움직이지 않게 합니다. 눈깜빡임은 부가 표현이며, 네 칸을 눈 상태만 다른 그림으로 채우거나 이동 프레임을 희생해 눈 전용 프레임으로 나누지 않습니다. 눈깜빡임을 넣을 여유가 없으면 열린 눈을 유지하고 이동 동작을 우선합니다.

각 프레임은 동일한 셀 좌표를 기준으로 머리·눈·몸통 중심·몸통 크기를 정확히 고정합니다. 꼬리나 지느러미가 펼쳐졌다는 이유로 개체 전체를 다시 가운데 정렬하거나 자동 확대·축소하지 않습니다. 얼굴·몸통의 기준점을 겹쳐 비교하고, 프레임만 재생하는 제자리 미리보기에서 위아래 떨림·좌우 점프·크기 변화가 없는지 확인합니다. 고등급일수록 몸통을 크게 흔드는 대신 꼬리·지느러미의 동작과 이음새를 더 정교하게 만듭니다.

특급·신화일수록 스프라이트 동작을 더 세심하게 설계합니다. 특급은 지느러미·꼬리가 부드럽게 이어지는 유영, 신화는 개체의 구조에 맞는 보조 움직임(유려한 지느러미, 탐사선 추진기·조명 등)을 더합니다. 빛만 바꾸거나 같은 그림을 네 번 복제하는 것으로 대체하지 않습니다. 몸통 위치·크기·머리 방향은 네 프레임에서 고정하고 실루엣의 불필요한 흔들림을 방지합니다.

눈깜빡임을 추가하는 경우 유영 동작을 유지하면서 동일한 얼굴 위치에서 짧고 자연스럽게 감았다 뜨도록 검수합니다. 감긴 눈은 눈꺼풀 선으로 표현하고 눈이 사라지거나 얼굴이 바뀌지 않게 합니다. 사람·동물 탑승자가 있는 탈것은 탑승자의 눈을 검수하며, 눈 없는 생물이나 사물에는 눈을 억지로 추가하지 않습니다. 실제 재생 크기와 속도에서 유영 동작을 먼저 확인한 뒤 눈깜빡임과 반복 이음새를 확인하고 배치 기록에 남깁니다.

새 어종은 **머리가 화면 오른쪽을 향하고 앞으로 유영하는 원본**으로 통일합니다. 썸네일과 2×2 시트의 네 프레임 모두 같은 방향이어야 합니다. 실제 생성 결과를 확인하고 방향이 다르면 재작업합니다. 기존 왼쪽 원본은 예외 목록과 반전 설정을 유지합니다. [방향 규칙·필수 프롬프트·기존 어종 목록](artwork-facing.md)을 함께 읽습니다.

1. 등급을 확인하고 해당 참고 PNG를 실제로 엽니다.
2. 썸네일 생성 시 해당 이미지를 **스타일 참고**로 전달하고 프롬프트에도 역할을 명시합니다.
3. 스프라이트는 최종 썸네일을 **동일 개체 참고**로 사용합니다. 등급별 그림체와 색·몸 비율을 유지합니다.
4. 체크무늬는 참고 스크린샷의 배경 표시입니다. 결과에 체크무늬·검정 배경·화면 테두리를 넣지 않고 실제 알파 투명 PNG로 생성합니다.
5. 2×2 시트는 동일 크기 네 칸에 전신과 지느러미가 모두 들어가야 하며, 중앙 분할선과 바깥 가장자리의 투명 여백을 검사합니다.
6. 생성 배치 manifest에 등급·참고 파일의 저장소 상대 경로·참고 역할·최종 프롬프트를 기록합니다. 폴더와 업로드 규칙은 [업로드 안내](../../storage-upload/README.md)를 따릅니다.

이 문서는 향후 생성의 기준이며, 과거 에셋의 일괄 교체를 의미하지 않습니다.

스프라이트의 셀 해상도·투명 여백·표시 크기와 화질 검수는 [크기·선명도 기준](sprite-sizing.md)을 따릅니다.
