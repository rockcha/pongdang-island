# 세로 아쿠아리움 배경

최신 모바일용 배경 4개입니다. 기존 가로 원본은 ../aquarium-backgrounds/에 보관합니다.

Storage의 public `aquarium-backgrounds` 버킷 루트에 아래 파일을 같은 이름으로 업로드/교체합니다. 로컬 폴더명 aquarium-backgrounds-portrait를 Storage 하위 폴더로 만들지 않습니다.
- default.png: 맑은 물빛
- coral.png: 산호 정원
- moon.png: 달빛 바다
- pearl.png: 진주 동굴

SQL 재실행은 필요 없습니다. 기존 카탈로그 경로와 동일합니다. 이 작업에서는 이미지 생성과 파일 저장만 수행했으며 화면의 어항 표시 비율은 변경하지 않았습니다. 세로 전체 구도를 표시하려면 어항 뷰를 9:16로 맞춰야 합니다. Storage 교체 후 캐시에 이전 이미지가 남을 수 있습니다.

생성 도구: built-in image_gen. 각 기존 가로 이미지를 스타일 참고로 사용했습니다.
공통 프롬프트: 기존 부드러운 카툰 페인팅·색감·조명·테마를 유지한 새로운 9:16 세로 모바일 수중 배경. 가로를 자르거나 늘리지 않고 세로에 맞게 재구성. 중앙과 상단은 미래 물고기를 위한 열린 물 공간, 하단과 가장자리에 풍경. 물고기·동물·텍스트·UI·테두리 없음.
