## 완료 상태

- 최종 PNG 36장(썸네일 18·2×2 시트 18)을 collectibles 버킷에 업로드했습니다. 기존 파일 덮어쓰기는 없었습니다.
- 36개 공개 URL에서 이미지를 다시 내려받아 로컬 파일과 SHA-256이 모두 일치함을 확인했습니다. [업로드 검증 기록](upload-report.json).
- 모든 PNG는 투명 RGBA 정사각형이며 10MB 제한 이내입니다. 프레임 가장자리와 중앙 분할선에 불투명 픽셀이 걸치지 않는지 검사했습니다. [알파 검사 기록](alpha-report.json).
- 프레임에 걸치던 스프라이트는 내장 image_gen으로 여백을 보정했습니다. 최종 프롬프트와 보정 프롬프트는 [manifest](manifest.json)에 있습니다.
- DB에는 아직 37번 SQL을 적용하지 않았습니다. 36번까지 적용된 DB에서 37번을 실행하면 도감·낚시에 등록됩니다.
