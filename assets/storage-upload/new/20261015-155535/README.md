# 상어·고래 유영 시트 교체

2026-10-15 교체 배치입니다. built-in image_gen으로 기존 썸네일의 캐릭터와 특급 판타지 그림체를 유지한 시트 2장을 재생성했습니다. [최종 프롬프트](manifest.json).

| 유지한 종 ID | 새 이름 | 교체한 Storage 경로 |
| --- | --- | --- |
| pongdang-shark | 햇물결 상어 | fish/epic/sunwave-shark_sprite.png |
| pongdang-whale | 물결날개 고래 | fish/epic/wavefin-whale_sprite.png |

눈은 네 프레임 모두 열린 상태이며 꼬리 추진과 지느러미 젓기·복귀의 네 단계를 표현합니다. 모두 오른쪽 원본입니다. 고래는 꼬리 여백을 보완했고 렌더링의 프레임별 머리·몸통 기준점 및 크기 보정값을 새로 측정했습니다. 새 경로는 초당 4프레임으로 0→1→2→3을 반복하며 눈 전용 프레임을 건너뛰는 처리를 사용하지 않습니다.

두 PNG를 업로드하고 다운로드 해시와 비교했습니다. 실제 DB에서 이름·설명·새 이미지 경로·토착 해제·현재 5개 전체 해역 서식지를 갱신하고 재조회로 검증했습니다. 기존 종 ID와 썸네일은 유지합니다. 이전 시트는 과거 배치에 보존하지만 현재 두 종은 새 시트를 사용합니다.

재설치·다른 프로젝트 적용은 [42 변경 SQL](../../../../supabase/sql/42-shared-shark-whale/01-shared-shark-whale.sql)을 41 이후 실행합니다. 모든 해역은 적용 당시 public.regions 전체이며, 이후 새 지역 추가는 별도 서식지 등록이 필요합니다.
