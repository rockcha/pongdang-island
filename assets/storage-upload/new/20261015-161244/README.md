새 토착종 ID는 `pongdang-native-shark`, `pongdang-native-whale`입니다. 기존 공통 서식종 ID인 `pongdang-shark`, `pongdang-whale`을 재사용하지 않습니다. 기존 사용자의 보유 개체·발견 기록과 기존 썸네일은 유지합니다.

## 생성·검수

- 특급·신화 스타일은 저장된 `epic-mythic-starlight.png`의 색 윤곽·그라데이션·입체감 기준입니다.
- 새 토착 썸네일은 위 스타일 참고와 `public/branding/pongi.png`의 주황 계열·머리 불가사리 단서를 함께 사용했습니다. 유영 시트는 각 최종 썸네일을 동일 개체 참고로 사용했습니다.
- 기존 세 종도 각 기존 썸네일을 동일 개체 참고로 사용해 재생성했습니다. 앞지느러미나 큰 장식 날개를 팔처럼 흔들지 않고, 개체 구조와 물살에 반응할 요소를 중심으로 구성했습니다.
- 다섯 시트는 모두 네 프레임이 오른쪽을 바라보고 눈은 열린 상태입니다. 머리·몸통·선체를 기준으로 프레임별 위치·배율을 측정하고 `swim-frame-layout.ts`에 보정값을 기록했습니다.
- 탐사선은 추진 효과가 칸을 넘지 않도록 여백을 보완했습니다. 다섯 시트는 초당 4프레임으로 0→1→2→3을 재생하며 눈 전용 프레임 건너뛰기를 사용하지 않습니다.
- `node scripts/verify-native-pongdang-current-swim.mjs`로 7개 정사각형 RGBA PNG, 5개 균등 2×2 시트와 Storage 용량 제한을 검증했습니다.

## 적용 상태

이미지 7장은 `collectibles` 버킷에 이 배치 아래 상대 경로 그대로 업로드하고 다운로드 SHA-256 비교로 확인했습니다. 기존 세 종의 새 시트 연결은 원격 DB 반영 및 재조회 검증을 마쳤습니다.

새 토착종 2개는 원격 API의 단일 서식지 제약으로 아직 등록되지 않았습니다. [43 등록·교체 SQL](../../../../supabase/sql/43-native-pongdang-and-current-swim/01-native-pongdang-and-current-swim.sql)을 42 이후 SQL Editor에서 실행해야 합니다. 동일 SQL은 기존 세 종의 시트 연결도 재현합니다.
