# 안개달 쓰레기·장식품 6종

안개달(`mistmoon`) 단독 서식 개체입니다. built-in image_gen으로 생성한 투명 PNG 6개이며 실제 결과의 온전한 실루엣과 여백을 확인했습니다. 쓰레기는 기존 표류 동작, 장식품은 고정 배치를 사용합니다. 별도 애니메이션 시트는 없습니다.

| 개체 | 종류 | 등급 | 크기 | 판매 가치 |
| --- | --- | --- | --- | --- |
| 멈춘 달시계 | 쓰레기 | 희귀 | 42 | 75 |
| 루네아의 실패한 초대장 | 쓰레기 | 특급 | 52 | 240 |
| 금 간 찻잔 | 쓰레기 | 일반 | 38 | 15 |
| 졸음버섯 군락 | 장식품 | 일반 | 68 | 50 |
| 꿈을 담는 우물 | 장식품 | 희귀 | 84 | 190 |
| 루네아의 기록 서가 | 장식품 | 특급 | 100 | 680 |

일반·희귀는 퐁이 카툰 스타일, 특급은 부드러운 판타지 스타일입니다. 사물에 눈이나 얼굴을 붙이지 않았습니다. 달시계는 금 간 유리와 끊어진 사슬, 초대장은 손상된 종이·봉인, 찻잔은 깨진 테두리와 모래로 낡은 흔적을 표현했습니다.

[최종 프롬프트·참고 이미지·설정](manifest.json), [등록 SQL 안내](../../../../supabase/sql/45-mistmoon-relics/README.md).

Storage 업로드 완료. 원격 종·서식지 등록은 44번 다음 [45번 SQL](../../../../supabase/sql/45-mistmoon-relics/01-mistmoon-relics.sql)을 SQL Editor에서 실행해야 합니다. 종과 서식지는 같은 트랜잭션에서 등록합니다. 이미지 검증: `node scripts/verify-mistmoon-relics.mjs`.
