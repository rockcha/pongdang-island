# 산호빛 여울 토착 컬렉션

내장 image_gen을 사용했습니다. 일반·희귀는 저장된 퐁이 카툰 참고, 특급·신화는 별빛 가오리의 판타지 일러스트 참고를 실제 전달했습니다. 신규 15종과 기존 꽃산호 해룡·산호꽃 말미잘을 설정합니다.

새 15종은 모두 coral 토착종이며 서식지는 산호빛 여울 한 곳입니다. 여울의 작은 회전목마는 장식품, 바다 오르골은 요청대로 일반 쓰레기입니다.

## 기존 개체와 고정 애니메이션

- 산호해마는 사용자 확인에 따라 기존 꽃산호 해룡입니다. 기존 왼쪽 원본·썸네일·등급·서식지·ID를 유지하고 v2 시트만 교체합니다.
- 산호꽃 말미잘은 희귀 장식품 ID를 유지하고 촉수 시트를 추가합니다. 기존 승인 썸네일은 그대로 복사했습니다. DB에 없으면 49 SQL에서 등록합니다.
- 천년산호 거대게와 말미잘은 movement_type=fixed, idle_animated=true입니다. 좌표는 고정하고 1.2fps로 다리·산호 끝 또는 촉수를 움직입니다. 편집 중·모션 감소 설정에서는 정지합니다.

## 파일과 적용

최종 PNG 27개(썸네일 16·시트 11)입니다. 26개를 새로 생성하고 승인된 말미잘 썸네일 1개를 재사용했습니다. 버킷 경로 계층으로 분류했으며 메타데이터·문서는 업로드 대상이 아닙니다.

```powershell
npm.cmd run storage:upload -- assets/storage-upload/new/20261015-192806
node scripts/verify-coral-collection.mjs
```

이번 작업에서 PNG 업로드를 완료하고 공개 URL 27개의 HTTP 200·SHA256 일치를 확인했습니다. 결과는 upload-report.json에 있습니다. 원격 SQL은 실행하지 않았습니다. 48 이후 supabase/sql/49-coral-collection/01-coral-collection.sql을 실행합니다. 반복 실행할 수 있고 기존 소유·배치·발견을 보존합니다.

## 검수

모든 최종 썸네일·시트를 실제 열어 확인했습니다. 갑각류·문어에 섞였던 포유류 표현은 재작업했고, 프레임 경계에 닿은 해룡·곰치·거대게와 해파리의 여백을 재작업했습니다. 새 어종은 오른쪽 원본, 기존 꽃산호 해룡만 왼쪽 예외입니다.

PNG는 1254×1254 RGBA, 시트 셀은 627×627입니다. 알파 32 이상 기준 모든 프레임은 셀 경계를 비웁니다. source 파일의 프레임을 개별 자동 확대·잘라내기하지 않았습니다. 일부 시트는 80~88% 목표보다 큰 예외이며 가는 다리·촉수·산호 끝의 동작 범위를 보존했습니다. 가장 가까운 경우에도 셀 경계에서 9px 이상 떨어집니다. 실측 점유율과 경계는 alpha-report.json에 있습니다.

원본의 행 사이 위치 오차는 머리·눈·뿌리의 작은 RGB 패치를 비교해 렌더러에서 보정합니다. anchor-config.json의 패치와 frame-registration.json의 이동량을 swim-frame-layout.ts에 반영했고 프레임별 배율은 모두 1입니다. 측정 과정에서 PNG는 수정하지 않습니다.

[재생 미리보기](preview.html)는 원래 PNG에 같은 좌표 보정을 적용합니다. 크기·배경·정지/재생을 바꾸어 확인할 수 있습니다. 물리적인 모바일 기기에서의 검수는 별도입니다.

최종 프롬프트·참고·원본 경로는 manifest.json과 metadata.json에 기록했습니다. 현재 생성 규칙은 assets/references/collectible-style/README.md, sprite-sizing.md, artwork-facing.md가 기준입니다.
