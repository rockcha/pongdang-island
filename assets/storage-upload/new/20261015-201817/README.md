# 공통 바다 개체 16종

일반 4종, 희귀 어종 8종, 특급 2종, 신화 1종, 희귀 쓰레기 1종입니다. 모든 현재 해역에 등장하며 토착 아이콘을 붙이지 않습니다.

설정과 설명은 [SQL 51](../../../../../supabase/sql/51-shared-ocean-life/01-shared-ocean-life.sql)에 있습니다. 50 다음에 실행합니다. 원격 SQL은 별도 실행해야 합니다.

- 어종 15종: 썸네일과 2×2 스프라이트 각 1장.
- 모래시계 병: 희귀 쓰레기 썸네일 1장.
- 일반·희귀는 저장된 퐁이 카툰 그림체, 특급·신화는 별빛 가오리의 판타지 그림체를 참고했습니다.
- 돌고래와 범고래는 기본 체색입니다. ‘칠흙’은 ‘칠흑’으로 표기했습니다.
- 완두 해면·빼꼼 붕장어·별꽃 관벌레·침수된 풍차는 `fixed` + `idle_animated=true`입니다. 풍차는 요청대로 어종으로 등록합니다.
- `preview.html`에서 원본 네 프레임과 제자리 애니메이션을 확인할 수 있습니다.
- `manifest.json`에 파일 경로·참고·프롬프트를 기록합니다. PNG는 생성 도구 원본을 사용하며 코드로 잘라내거나 확대하지 않습니다.
- `alpha-report.json`은 읽기 전용 여백 측정, `frame-registration.json`은 기준점 이동 측정입니다.

업로드: `npm.cmd run storage:upload -- assets/storage-upload/new/20261015-201817`

업로드 후 공개 응답과 로컬 해시 비교는 `upload-report.json`에 기록합니다.

완료: PNG 31장 업로드, 공개 응답 31개 HTTP 200 및 로컬 해시 일치. SQL·이동·프레임 보정 관련 테스트 35개와 프로덕션 빌드 통과. 원격 SQL은 실행하지 않았습니다.

여백 보정 후 완두 해면·붕장어·범고래·관벌레 등은 긴 축 점유율이 목표보다 작은 프레임도 있습니다. 수축 동작과 전체 동작 범위를 보존하기 위해 프레임별 확대를 하지 않았고 DB 표시 크기로 보완했습니다. 일각고래의 가장 넓은 자세는 약 89%이며 모든 끝부분이 셀 안에 있습니다. 읽기 전용 기준점 탐색 범위는 160px로 넓혀 큰 생성 위치 차이도 보정했습니다.
