# 기존 장식품 4종 스프라이트

과거 생성 배치 기록입니다. 현재 생성·저장 규칙은 [에셋 안내](../../../README.md)를 따르며 원격 반영 여부는 별도 확인합니다.

기존 썸네일의 모양과 색을 참고해 2×2 투명 스프라이트를 추가합니다. 일반·희귀 공통 퐁이 카툰 그림체 기준을 사용합니다.

| 개체 | 등급 | 동작 |
| --- | --- | --- |
| 소라빛 바람개비 | 일반 | 막대와 중심축 고정, 날개 회전 |
| 여울의 작은 회전목마 | 희귀 | 지붕과 받침대 고정, 해마 조각 이동 |
| 진주 품은 조개 | 일반 | 아랫껍데기와 진주 고정, 윗껍데기 여닫힘 |
| 산호 덮인 보물상자 | 희귀 | 상자 하단 고정, 뚜껑 여닫힘 |

썸네일·보유·발견·배치·크기는 유지합니다. 조개는 기존 썸네일 경로가 rare 폴더이지만 현재 등급은 일반이며 새 시트는 normal에 둡니다.

업로드 명령: `npm.cmd run storage:upload -- assets/storage-upload/new/20261015-204537`

DB 적용: [SQL 53](../../../../supabase/sql/53-animated-decorations/01-animated-decorations.sql)을 52 다음에 실행합니다. 원격 SQL 실행은 별도입니다.

생성 프롬프트·참고는 `manifest.json`, 여백 검사는 `alpha-report.json`, 기준점 보정은 `frame-registration.json`, 업로드 검증은 `upload-report.json`에 기록합니다. `preview.html`에서 제자리 재생을 확인할 수 있습니다.

완료: PNG 4장 Storage 업로드, 공개 응답 HTTP 200과 로컬 해시 일치 확인. 16개 프레임의 경계 여백 검사 통과. 관련 테스트 37개와 프로덕션 빌드 통과. 원격 SQL은 실행하지 않았습니다.
