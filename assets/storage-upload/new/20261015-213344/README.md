# 아틀란티스 개체 18종

과거 생성 배치 기록입니다. 현재 생성·저장 규칙은 [에셋 안내](../../../README.md)를 따르며 원격 반영 여부는 별도 확인합니다.

일반 초록등 바다거북 1종은 전 해역 공통입니다. 특급 산호에 덮인 난파선은 산호 토착 장식품입니다. 나머지 16종은 별잠 유적의 아틀란티스 토착 개체입니다. 등급·분류·이동 유형은 `species.json`과 [SQL 56](../../../../supabase/sql/56-atlantis-collection/README.md)에 있습니다.

물결 나선과 삼지창 인장을 왕국 공통 문양으로 사용합니다. 일반·희귀는 퐁이 카툰풍, 특급·신화는 풍부한 판타지 일러스트풍입니다. 새 어종은 오른쪽 원본입니다.

수호병은 `fixed` + `idle_animated=true` 어종입니다. 위치를 고정하고 망토·허리 장식·갑주 고리·수정 심장을 움직입니다. 찻잔둥지 블레니도 고정형 어종이며, 분수와 난파선은 애니메이션 장식품입니다.

총 썸네일 18장과 스프라이트 15장입니다. 쓰레기는 금 간 향유병·잃어버린 왕관·깨진 왕국 타일 3종입니다.

업로드: `npm.cmd run storage:upload -- assets/storage-upload/new/20261015-213344`

업로드 후 SQL 56을 55 다음에 실행합니다. 원격 SQL은 별도 실행합니다. 기존 보유·발견·배치는 유지합니다.

PNG 33장 Storage 업로드를 완료했고 공개 URL 33개 모두 HTTP 200 및 로컬 SHA-256 일치를 확인했습니다. 관련 테스트 44개와 프로덕션 빌드를 통과했습니다. 원격 DB에는 SQL을 실행하지 않았습니다.

참고·프롬프트는 `manifest.json`, 여백은 `alpha-report.json`, 기준점은 `frame-registration.json`, 공개 업로드 검증은 `upload-report.json`에 기록합니다. `preview.html`에서 제자리 재생을 확인할 수 있습니다.

## 여백 검수

15개 시트 모두 셀 경계 침범이 없습니다. 가장 넓은 자세의 긴 축 점유율은 71.9~84.7%입니다. 일부는 80% 목표보다 작으며 팔·날개·장식의 동작 여백과 네 프레임 동일 배율을 우선한 예외입니다. 개별 프레임 확대는 하지 않았습니다. 실제 기기별 DPR 검수는 별도입니다.
