# 공통 수초 장식품 5종과 쓰레기 2종

과거 생성 배치 기록입니다. 현재 생성·저장 규칙은 [에셋 안내](../../../README.md)를 따르며 원격 반영 여부는 별도 확인합니다.

일반 장식품: 리본 잘피, 조약돌 바다이끼, 꼬불 미역. 희귀 장식품: 진주알 바다포도, 장밋빛 부채해초. 일반 쓰레기: 녹슨 병뚜껑, 금 간 꼬마 화분.

내장 image_gen으로 퐁이 카툰 스타일을 참고해 투명 썸네일 PNG 7장을 생성했습니다. 수초는 정지 이미지이며 스프라이트는 없습니다. 전 해역 공통으로 토착 아이콘이 없습니다. 이름·크기·가격은 species.json, 참고와 최종 프롬프트는 manifest.json에 있습니다.
