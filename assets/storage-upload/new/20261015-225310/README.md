# 수초 받침 수정과 제자리 애니메이션

과거 생성 배치 기록입니다. 현재 생성·저장 규칙은 [에셋 안내](../../../README.md)를 따르며 원격 반영 여부는 별도 확인합니다.

잘피·미역은 작은 모래 받침, 바다포도·부채해초는 작은 돌 받침, 바다이끼는 기존 조약돌 형태입니다. 뿌리를 노출하지 않고 받침은 고정한 채 잎과 가지 끝만 물살에 흔들리게 만들었습니다.

수정 썸네일 5장과 2×2 애니메이션 시트 5장입니다. 내장 image_gen을 사용했으며 manifest.json에 참고·프롬프트를 기록합니다. 기존 일반·희귀 카툰 스타일과 공통 서식지·크기·가격·배치를 유지합니다.

[SQL 59](../../../../supabase/sql/59-animated-aquatic-plants/01-animated-aquatic-plants.sql)를 58 다음에 실행합니다. 원격 SQL은 별도 실행합니다. [미리보기](preview.html)에서 보정된 동작을 확인할 수 있습니다.

## 여백·기준점 검수

네 프레임 모두 셀 경계를 침범하지 않습니다. 각 시트에서 가장 큰 자세의 긴 축 점유율은 75.4~88.0%입니다. 잘피·이끼·바다포도는 잎의 동작 여백과 모든 프레임 동일 배율을 위해 80%보다 작은 예외를 유지했습니다. 받침대의 RGB 기준점을 측정해 프레임별 위치 차이를 렌더러에서 보정하며 이미지 자체를 자르거나 개별 프레임을 확대하지 않았습니다. 기기별 DPR 검수는 별도입니다.

PNG 10장 업로드를 완료했고 공개 URL 모두 HTTP 200과 로컬 SHA-256 일치를 확인했습니다. SQL·프레임 기준점 테스트 37개를 통과했습니다. 원격 DB에는 SQL을 실행하지 않았습니다.
