# 입문용·청동 분리와 낚싯대 이미지 완성

2026-10-16 built-in image_gen으로 입문용 세트 썸네일과 5종(입문용·잔물결·별잠 유물·꿈실·루네아)의 릴 테두리·회전판·찌 15개를 생성했습니다. 기존 썸네일은 재질·문양 참고로 확인했고 실제 부품은 정면 회전 가능한 단독 이미지로 생성했습니다. 원본 PNG를 수정하지 않고 표시 중심과 크기를 코드에서 맞춥니다. 채택한 최종 프롬프트는 [manifest](manifest.json)에 기록했습니다.

기존 첫물결의 4개 이미지는 청동 경로로 복사해 이어받았습니다. 이번 배치는 새 생성 16개와 재사용 4개, 총 20개입니다. Storage `collectibles/equipment/rods/`에 업로드했습니다. 입문용 ID는 `basic`을 유지하며 이미지 폴더만 `starter`를 사용합니다. 과거 `basic` 이미지 경로를 덮어쓰지 않습니다.

현재 9종 모두 `thumbnail.png`, `reel-frame.png`, `reel-rotor.png`, `float.png`를 사용합니다. 이전에 완성한 나무·산호꽃·안개달과 기존 7종 썸네일은 [이전 배치](../20261016-152733/README.md)에 있습니다. 같은 날 대상 프로젝트의 공개 Storage URL 36개를 다운로드해 RGBA PNG 형식과 로컬 원본 SHA-256 일치를 확인했습니다. 게임의 회전량·휘어짐·찌 움직임·게이지는 유지합니다. 실패율·토착 확률은 설정·표시 전용이며 실제 확률은 적용하지 않습니다.
