# 루네아 8포즈 회전 시험

내장 image_gen으로 기존 루네아를 참고하여 생성했습니다. 프롬프트는 [manifest.json](manifest.json)에 보존합니다.

- 원본: `fish/mythic/lunea-mistmoon-goddess_turn-v2_sprite.png`
- 앱 파일: `public/aquarium/turns/lunea-mistmoon-goddess_turn-v2_sprite.png`
- 4열 × 2행, 오른쪽 측면에서 왼쪽 측면으로 회전합니다.
- 한 번에 한 포즈, alpha=1. 프레임별 확대·축소 및 페이드 없음.
- 회전 시트는 넉넉한 여백을 포함하므로 8포즈 모두 동일한 1.6배를 적용합니다. 행별 세로 위치와 포즈별 가로 기준점만 보정하며 개별 포즈를 바운딩 박스에 맞춰 확대하지 않습니다.
- 기본 유영 4번째 프레임의 확대 보정 제거.
- 1.2초 회전, 방향 변화 0.12초 유지 후 시작. 회전 중 반전 요청은 현재 회전 종료 후 처리.
- SQL 변경·원격 Storage 업로드 없음. 다른 종은 적용하지 않습니다.

알파 경계 진단은 `alpha-report.json`입니다. 경계 진단은 몸통 크기 일치나 실제 기기에서의 시각 검증을 대신하지 않습니다. 미리보기의 슬라이더로 포즈를 정지해 확인할 수 있습니다.

최종 시트는 1774×887입니다. 알파 200 기준 8개 포즈 모두 셀 경계 픽셀은 0입니다. 투명 여백 확보를 위해 점유율 목표보다 작게 생성했으며 공통 표시 배율로 맞췄습니다. 생성 원본의 포즈별 해부학적 비율까지 수치상 동일하다고 보장하지 않습니다.
