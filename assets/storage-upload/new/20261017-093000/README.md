# 신화 4종 · 6초 주기 행동

루네아 외 신화 네 종의 8프레임 시트를 내장 image_gen으로 생성했습니다. 기존 썸네일과 종 ID는 유지하고 앱에 포함한 시트만 교체합니다. DB·원격 Storage 변경 없음.

| 종 | 특수 행동 |
| --- | --- |
| 아틀란티스 수호병 | fixed로 제자리에 서서 망토가 흔들리고 갑옷 문양으로 청록빛이 퍼짐 |
| 퐁이 탐사선 | 탐조등 방향 변화와 퐁이 눈깜빡임 |
| 천년산호 거대게 | 등 산호의 발광과 집게 한 번 벌리기 |
| 새벽을 여는 일각고래 | 뿔 → 등 → 꼬리 순서로 이동하는 금빛 |

각 PNG는 1774×887, 4열×2행입니다. 기본 0–3프레임 유영 후 특수 행동이 포함된 시퀀스를 재생하며 전체 주기는 6초입니다. 모션 감소 설정에서는 0프레임을 표시합니다. 개체별 animation_seed로 재생 시작 시점을 다르게 합니다. 루네아의 기존 행동·위치 보정은 유지합니다.

`*-registration.json`은 첫 프레임의 고정된 몸통 영역에 대한 RGB 패치 비교 기록입니다. 포즈·발광으로 픽셀 색이 달라 비교 오차가 있으며 해부학적 완전 일치를 뜻하지 않습니다. 원점 위치만 보정하고 각 시트에 공통 배율을 적용하며 개별 프레임 확대·축소와 전체 반투명 효과는 없습니다. `*-alpha.json`은 셀 경계 검사 기록입니다. 게임 표시 크기의 실제 재생에 대한 최종 판단은 미리보기에서 확인합니다.

원본은 `fish/mythic/`, 앱 제공 파일은 `public/aquarium/swim/`에 있습니다. 원본 참조 경로·프롬프트·선택 결과는 [manifest.json](manifest.json)에 보존합니다. [통합 미리보기](../../../../artifacts/mythic-actions-preview.html)는 앱의 `mythic-swim.ts`를 변환한 동일한 함수로 실행합니다. 자동 재생·프레임 정지·좌우 반전·이동 비교를 지원합니다.
