# 푸른골 확장 · 공통 7종 / 푸른골 토착 15종

내장 image_gen으로 썸네일 22장, 유영 시트 19장, 수호병 고정 자세 시트 1장을 생성했습니다. 총 42장입니다. 원본 프롬프트·참고 역할은 `manifest.json`, 유영 생성은 `sprite-sources.json`, 재작업은 `corrections.json`·`final-padding.json`에 보존합니다. 재작업 기록에 있는 최종 선택이 초기 결과보다 우선합니다.

## 모든 현재 해역에 등장

- 희귀: 은검 황새치, 돛너울 돛새치, 강철등 참다랑어, 비늘갑옷 바라쿠다, 금줄 부시리, 대왕농어
- 특급: 바다날개 대왕 가오리

현재 7개 해역(퐁당·산호·심연·안개달·별잠·태고·푸른골)에 연결하며 토착종으로 표시하지 않습니다.

## 푸른골 전용

- 일반: 닻줄 감긴 바위(장식), 은물결 숭어, 푸른등 삼치, 청줄 날치, 줄무늬 동갈치
- 희귀: 푸른창 청새치, 청동 방어, 푸른골 대왕농어, 가라앉은 항로 표지석(장식), 모래에 묻힌 대포(장식), 긴꼬리 환도상어
- 특급: 푸른점 표범상어, 푸른비늘 만새기, 물결무늬 대왕곰치
- 신화: 흰돛의 수호자, 세일라

이 15종은 `native_region_id='bluegrove'`이며 서식지는 푸른골 하나입니다. 공통 대왕농어와 푸른골 대왕농어는 별도 ID입니다. 장식품은 고정 배치용 썸네일만 사용합니다.

## 움직임과 검수

일반·희귀·특급 어종은 2×2 4프레임, 세일라는 4×2 8프레임입니다. 모든 신규 어종은 오른쪽을 향합니다. 세일라는 6초 주기로 흰 돛을 펼치며 청록색 항로 문양이 빛납니다. 수호병은 양발이 바닥에 붙은 고정 자세에서 망토와 문양만 움직이며 걷기 시트를 사용하지 않습니다.

`sprite-alpha.json`의 일반 2×2 시트와 `seila-alpha.json`의 8프레임을 별도로 검사했습니다. 최종본은 셀 경계 침범이 없습니다. 그림 점유율이 80–88%를 벗어나는 긴 어종은 전신·지느러미·주둥이·꼬리 보존을 우선했습니다. `body-registration.json`은 고정된 몸통 패치의 이동 측정이며, 날치·세일라는 움직이는 날개·돛을 제외한 머리 패치로 수동 위치를 지정했습니다. 측정에는 색·형태 변화에 따른 잔차가 있으므로 완전한 해부학적 일치를 보장하는 값은 아닙니다. 프레임별 배율 변경은 하지 않습니다.

[전체 미리보기](../../../../artifacts/bluegrove-expansion-preview.html)는 로컬 원본과 앱의 위치 보정 함수를 사용합니다. 제자리 자동 재생·프레임 정지·좌우 반전·서식지 필터를 지원합니다. 실제 기기별 시각 평가는 별도입니다.
