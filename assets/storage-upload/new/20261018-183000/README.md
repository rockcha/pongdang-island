# 꿈먹는 심연 · 보랏빛 심해 개체

선택된 어종·쓰레기·장식품의 최종 PNG와 재현·검수 자료입니다. 등급과 표시 수치의 기준은 `supabase/catalog/catalog.json`, 이미지별 생성 프롬프트·참고 역할·원본 위치·해시는 `manifest.json`입니다. 기본 내장 image_gen으로 제작했고 원본은 보존했습니다.

어종은 오른쪽을 향하는 2×2 유영 시트를 사용합니다. 열수구·진주조개·자수정 심장은 제자리에 고정한 채 연무·진주빛·내부 발광을 재생합니다. 나머지 사물은 정적 PNG입니다. 장식 편집 중과 동작 줄이기 설정에서는 장식 애니메이션을 멈춥니다.

칸 경계에 닿은 유영 시트는 생성 도구로 여백을 수정했습니다. `sprite-audit.json`은 알파 경계 측정, `anchor-config.json`과 `anchor-registration.json`은 얼굴/바닥의 위치 측정입니다. PNG를 프레임별로 잘라 확대하지 않고 동일 시트 배율과 기준점 보정만 `src/features/aquarium/dreamabyss-frame-layouts.json`에 적용했습니다. 일부 원본의 점유율은 80–88% 목표 밖이지만 셀 침범은 없으며 공통 표시 배율로 보정했습니다. `preview.html`에서 재생·정지·프레임 전환으로 확인할 수 있습니다.

Storage에는 이 폴더 안의 `fish/`, `trash/`, `decorations/` 계층을 업로드합니다. JSON·HTML·SQL·README는 버킷에 올리지 않습니다. `install.sql`은 이번 25종과 해당 서식지만 다루는 원격용 증분 SQL입니다. 기존 플레이어 개체·지갑은 변경하지 않습니다. 전체 로컬 이력은 CLI migration과 카탈로그 생성기로 관리합니다.

원격의 관련 제약을 먼저 확인했으며 장식품 스프라이트 허용 규칙은 이미 존재했습니다. `upload-verification.json`에는 대상 프로젝트·조회 시각과 신규 카탈로그/서식지 및 공개 이미지 바이트 대조 결과만 기록했습니다. 전체 스키마나 migration 이력의 동등성을 확인한 자료는 아닙니다.
