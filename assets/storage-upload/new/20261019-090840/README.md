# 등급별 테마 제작

사용자가 선택한 심플·감성·스페셜 각 2개를 내장 image_gen으로 제작했다. 심플은 기존 시간 배경, 감성은 가을 연못, 스페셜은 심해 우체국을 각 프롬프트의 스타일·구도 참고로 전달했다. 최종 프롬프트·참고 파일·원본 경로·생성 당시 등급과 가격은 manifest.json에 보관한다. 운영 등급·가격의 원본은 supabase/catalog/catalog.json이다.

중앙 여백과 등급별 디테일 차이를 6개 비교 이미지로 검수했다. `aquarium-backgrounds/`의 PNG를 해당 Storage 버킷 루트에 업로드한다. 기존 업로더에 이 배치 경로와 `--dry-run` 또는 `--upload`를 전달하며, 공개 다운로드 SHA-256과 로컬 원본 일치를 검증한다. 기존 이미지는 교체하지 않는다.
