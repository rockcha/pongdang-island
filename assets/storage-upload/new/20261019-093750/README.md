# 붉은 부채산호 이미지 보강

사용자 요청으로 기존 배경을 내장 image_gen에서 편집했다. 붉은 부채산호 군집을 여러 겹으로 늘리고 크기·색·가지 결·바위 표면을 보강했다. 중앙 수영 공간은 유지한다. 원본과 수정본을 시각 검수했으며 전체 프롬프트와 참고 원본은 manifest.json에 남긴다.

Storage에는 red-fan-coral-v2.png로 새로 업로드하고 기존 카탈로그 ID의 image_path만 변경한다. 별도 경로로 캐시 충돌을 피하며 원본 파일·기존 보유권·가격·등급은 유지한다. 업로드는 기존 upload-aquarium-backgrounds.mjs에 이 배치 경로를 전달하며 공개 다운로드의 SHA-256과 로컬 원본을 비교한다.
