# Reel and float layers

Generated with the built-in imagegen skill using matching rod thumbnails for identity and the existing Lunea components for rendering style. The manifest records the full prompts and reference paths.

Each rod has an independent stationary ring, rotating spool and upright float. Upload with `npm run storage:upload -- assets/storage-upload/new/20261019-132700`; verify public downloads against local SHA-256 before completing. Runtime positioning is registered in `rod-image-assets.tsx`; preserve separate frame/rotor transforms and SVG error fallbacks.
