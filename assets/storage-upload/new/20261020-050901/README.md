# 퐁당섬 토착 개체 이미지

개체 설정과 등급은 catalog.json이 원본이다. 기성 두 개체는 후원자 구기성님에 대한 감사 설정을 사용한다.

일반·희귀는 저장된 퐁이 카툰 참고를, 신화 로봇과 특급 입구는 판타지 참고를 사용했다. 해마 탄 퐁이는 사용자 요청으로 특급이지만 희귀 카툰 그림체를 유지한다. 해파리와 귀상어는 해달의 얼굴 대신 따뜻한 색과 불가사리만 공유한다. 쭈꾸미는 앞쪽 입 하나만, 해마 고삐는 양손이 서로 다른 쪽을 잡는다.

모든 새 어종은 오른쪽 원본이다. 시트 경계가 잘리지 않도록 동일 배율의 여백 보완을 생성 도구로 요청했다. 원본별 프레임을 따로 잘라 확대하지 않았다. 몸통·얼굴 RGB 기준점의 위치 보정은 registration.json과 robot-registration.json에 기록하고 앱의 프레임 레이아웃에 연결했다. 눈만 바뀌는 동작 대신 촉수·꼬리·보행·추진기 동작을 사용한다.

로봇은 4×2 기본 이동 네 장과 접기·펼치기 네 장, 6초 주기다. 기존 클라이언트용 2×2 기본 유영 시트도 별도 유지한다. 새 클라이언트는 public/aquarium/swim의 8프레임을 사용하며 모션 감소에서는 0프레임을 유지한다.

긴 축 목표 80~88%에 대해 쭈꾸미는 촉수 확장 프레임이 약 89.3%이나 90%를 넘지 않고 경계 여백을 유지한다. 해마·해파리는 원본 여백을 보존하고 앱의 고정 배율로 표시 크기를 보완한다. 알파 점유율은 sprite-audit.json을 참고한다. 기기별 실제 선명도와 원격 파일 상태는 이 로컬 검사만으로 보장하지 않는다.

업로드는 저장소 루트에서 npm run storage:upload -- assets/storage-upload/new/20261020-050901 --dry-run으로 경로를 확인하고 같은 명령의 --dry-run을 제거한다. README·manifest·검사 JSON은 업로드 대상이 아니다. 업로드 후 공개 URL의 해시를 manifest와 대조한다. DB 변경은 CLI migration 20261019201440_pongdang_mascot_native_species.sql의 신규 종·서식지만 적용하며 기존 원격 전용 종은 건드리지 않는다.
