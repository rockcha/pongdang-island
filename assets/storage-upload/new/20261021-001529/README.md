# 만타·흰 늑대 유영 수정

기존 외형을 기준으로 image_gen에서 새 동작을 제작했다. 만타는 양쪽 지느러미의 물결 운동, 흰 늑대는 수평 자세와 교대하는 발 젓기를 사용한다. 두 시트 모두 오른쪽을 향하는 2×2 네 프레임이며 기존 썸네일은 유지한다. 프롬프트·참고 파일·생성 원본은 manifest에 보존한다.

최종 시트는 모든 셀에 동일한 배율을 사용해 투명 여백을 확보한 뒤, 얼굴의 RGB 패치로 측정한 평행 이동만 적용해 머리를 정렬했다. 자세별 바운딩 박스에 맞춰 확대·축소하지 않았다. `registration-before.json`은 조립 전 이동량, `registration.json`은 최종 PNG의 잔여 이동량이다. `sprite-audit.json`은 셀별 알파 경계 검사이며 시각적인 동작 품질의 증거를 대신하지 않는다.

새 Storage 경로로 연결해 이전 이미지 캐시 및 이전 시트 전용 위치 보정과 구분한다. 최종 시트의 머리는 픽셀 기준으로 정렬되어 새 경로에는 별도 프레임 보정이 필요 없다. 기존 이미지와 배포 이력은 삭제하지 않는다. 적용 전 업로드 도구의 dry-run을 확인하고, 업로드 후 공개 파일 해시와 카탈로그 경로를 재조회한다.
