# 푸른골·안개달 및 공통 신화

그림체는 일반·희귀의 퐁이 참고와 특급·신화의 별빛 가오리 참고를 따랐다. 유면 및 루네아 계열 특급은 기존 루네아의 기사도 소재 참고로 사용했다. 이름·등급·가격의 원본은 `supabase/catalog/catalog.json`, 생성 프롬프트·선택 원본·수정 이력·최종 파일 해시는 이 배치의 `manifest.json`이다.

## 유지할 조건

- 신규 생물 원본은 오른쪽을 향한다. 쓰레기 두 종은 일반 등급이다.
- 신화 생물은 4×2의 8프레임이며 기본 유영 4장과 개체별 추가 행동 4장을 6초 주기로 재생한다. 모션 감소에서는 첫 프레임을 유지한다.
- 프레임별 확대·축소와 전체 불투명도 변화로 동작을 대체하지 않는다. 프레임 등록은 얼굴·몸통의 평행이동만 보정한다.
- 수염·긴 지느러미·집게 동작에 여백이 필요해 일부 시트의 점유율은 80~88% 목표보다 작다. 효과의 가장 넓은 자세와 얼굴 가독성을 함께 검수하며, 프레임마다 별도로 꽉 채우지 않는다.
- 공통 신화는 토착 해역 없이 현재 모든 해역의 서식지에 등록한다. 새 해역 추가 시 공통종 서식지 유지 절차를 따른다.

## 검증·배포

`*-registration-config.json`을 기존 `scripts/register-sprite-anchors.ps1`에 전달해 얼굴 기준점 이동을 재측정할 수 있다. 일반·희귀·특급은 `-Columns 2`, 신화는 `-Columns 4`를 사용한다. 원본 교체 시 측정 결과와 앱의 프레임 보정, 신화의 `public/aquarium/swim/` 복사본도 함께 갱신한다.

`tests/bluegrove-mistmoon-creatures.test.ts`와 `tests/mythic-swim.test.ts`, `npm run db:verify`로 카탈로그·서식지·이미지 해시·프레임 연결을 검증한다. Storage 업로드는 이 배치 폴더를 대상으로 기존 업로드 도구를 사용하며, `scripts/verify-collectible-batch.mjs`로 공개 PNG 해시와 관련 원격 카탈로그만 확인한다.

신규 카탈로그 SQL은 CLI가 생성한 `20261021005824_bluegrove_mistmoon_and_shared_creatures.sql`이다. 원격의 기존 종과 이력을 덮어쓰지 않도록 신규 17개 ID로 생성 범위를 제한했다. Storage 업로드 성공과 원격 DB 적용은 별도로 확인해야 한다. 작업 도중 MCP 인증 갱신 및 CLI 네트워크 연결에 실패했으므로 원격 DB 적용은 미확인 상태이며, 연결 복구 후 해당 migration의 적용 여부를 먼저 확인한다.
