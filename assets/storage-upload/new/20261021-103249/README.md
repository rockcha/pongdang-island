# 루네아의 거울비늘 재제작

사용자 요청에 따라 기존 가오리형 실루엣을 둥근 물고기 몸통과 부채꼬리로 교체했다. 최종 색은 연보라·진주빛이며 큰 거울 비늘과 금빛 초승달 반사를 유지한다. 특급 참고는 채색과 재질에만 사용했다. 동일 실루엣 재사용 금지 규칙은 `assets/AGENTS.md`와 등급별 그림체 기준에 기록했다.

개체 ID·가격·이미지 Storage 경로를 유지하므로 DB SQL 변경은 없다. 이 배치의 두 PNG로 해당 경로만 교체하며 `mirrorscale-lavender-v2` URL 버전으로 이전 캐시를 구분한다. 이전 배치의 원본과 생성 기록은 보존한다.

`registration.json`은 새 시트의 얼굴 기준점 이동 측정값이다. 현재 앱의 `reviewed-frame-layouts.json`은 이 측정값을 사용하며, 과거 시트 보정값을 적용하지 않는다. `sprite-audit.json`과 manifest의 최종 해시를 통해 파일·셀 여백을 확인한다. 프레임마다 배율을 바꾸지 않는다.
