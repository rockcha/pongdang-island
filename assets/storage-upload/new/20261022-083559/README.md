# 공통 신화 7종: 8프레임 추가 행동

built-in image_gen으로 기존 개체를 동일성 참고, 등급별 PNG를 채색·명암 참고로 전달해 4×2 시트를 재생성했다. 종별 최종 프롬프트와 참고 경로는 manifest.json에 있다. generated/*.source는 원본 PNG 바이트를 보존한다. 업로드 도구가 원본을 함께 전송하지 않도록 별도 확장자를 사용한다.

앞 4장은 유영, 뒤 4장은 준비·전개·복귀·안정이다. 군체는 무리의 나선, 허성은 내부 필라멘트 전개, 해골고래는 뼛조각 궤도, 에클리온은 일식 코로나와 지느러미 전개, 요르문간드는 몸의 고리 수축·이완, 하프구파는 산호·씨앗 전개, 카리브디스는 외투 가장자리와 흡입 동작을 사용한다.

prepare-shared-mythic-eight.ps1은 모든 셀에 같은 배율을 적용해 84% 점유율과 투명 여백을 확보한다. 프레임별 확대를 하지 않고 안정된 몸통 패치의 위치를 측정해 shared-mythic-action-layouts.json을 생성한다. 원격 카탈로그의 기존 호환 경로를 새 런타임에서 8프레임 로컬 에셋으로 선택한다. 이전 6프레임은 과거 생성 자료로 유지하며 실행 코드의 예외는 제거했다. DB·출시 시각 변경은 없다.

Storage에는 fish/mythic/*_swim8_sprite.png를 신규 업로드한다. 기존 호환 이미지를 덮어쓰지 않는다. 이 추가 동작을 서비스에 반영하려면 앱 코드를 배포해야 한다. tests/shared-mythic-eight.test.ts와 전체 신화 검사는 격자·8개 자세·6초 주기·모션 감소·위치 보정을 검증한다.
