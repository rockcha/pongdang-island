# 신화 7종 셀 경계 복원과 공개 이미지 캐시

기존 시트는 생성 원본에서 개체가 셀 경계를 넘고 있었다. 잘린 셀을 나중에 축소해도 코·꼬리를 복원하거나 옆 셀 조각을 없앨 수 없으므로, 여백이 있는 배치 가이드를 먼저 만들고 built-in image_gen으로 재생성했다. 형태가 스타일 참고의 가오리로 바뀐 시안은 제외하고 개체 동일성을 유지한 수정본만 사용한다. 최종 프롬프트·참고·원본 출처는 manifest.json에 있다. generated/*.source와 *.guide는 원본 PNG 바이트이며 업로드용 파일과 구분한다.

prepare-shared-mythic-eight.ps1의 RequireSafeSource 검사는 후처리 이전의 모든 프레임에 셀 너비 8% 이상의 여백이 있어야 통과한다. 같은 배율·셀 중심을 모든 프레임에 적용하며, 프레임별 확대 없이 머리·몸통 패치로 위치를 보정한다. 여백으로 작아지는 부분은 개체 전체에 같은 표시 배율을 적용한다. 8프레임·6초 반복과 모션 감소를 유지한다. 새 _swim8_v2_sprite.png를 연결하며 DB·가격·출시일은 바꾸지 않는다.

업로드는 storage:upload로 수행한다. PNG IDAT를 무손실 재압축하며 원본 스캔라인이 동일한지 확인한다. 버전 파일은 새 경로로 업로드하고 공개 다운로드 해시를 다시 확인한다. 오래된 시트는 재현 자료로 보존한다. 앱 코드를 배포해야 새 경로·캐시 정책이 적용된다.

공개 이미지 캐시는 Workbox CacheFirst이며 버전별 URL을 구분한다. 캐시 동작은 실제 Chromium에서 같은 URL 첫 로딩·재로딩·페이지 재접속과 새 버전 URL을 비교했다. 실제 어항의 일곱 개 WebGL 렌더러와 관련 회귀 테스트도 확인한다. 캐시는 다운로드가 있었던 결제 사용량을 소급해서 줄이지 않으며, 기기별 최초 다운로드·캐시 만료/정리 시에는 전송이 발생한다.
