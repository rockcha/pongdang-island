# 해역 정면 상징 아이콘

내장 `image_gen`으로 세이렌의 정면 하프와 냠냠 한상바다의 정면 김밥 한 조각을 생성했습니다. [manifest](manifest.json)에 최종 경로·정확한 프롬프트·입력 역할을 보존합니다. 기존 섬 아이콘은 채색 참고이며, 새 아이콘은 작은 크기의 식별을 위해 단일 사물만 표시합니다.

원본은 `sources/*.source`에 보존하고, UI용 PNG는 알파를 유지한 전체 이미지 동일 비율 축소로 384×384에 내보냈습니다. `public/region-icons/*-v2.png`를 공통 `regionIcons`에 연결합니다. 배경·지도 그림은 별도 자산입니다. 아이콘은 앱 배포에 포함되는 정적 파일이며 DB 변경은 필요하지 않습니다.
