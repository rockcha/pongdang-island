# 그림하울·황금 고래상어·네메리온

내장 `image_gen`으로 생성했습니다. [manifest](manifest.json)에 가격·이동·서식지·최종 프롬프트, [생성 입력](generation-log.json)에 단계별 정확한 프롬프트와 원본 경로를 남깁니다. 특급·신화 참고 PNG는 채색·빛·재질만 참고하고 늑대장어·고래상어·실러캔스의 구조를 각각 유지합니다.

늑대장어와 황금 고래상어는 공통 특급이며 현재 모든 해역에 서식지를 등록합니다. 네메리온은 원시섬을 주 서식지로 갖는 신화입니다. 네메리온의 구체 외형은 별도 지시가 없어 고대 실러캔스로 기획했습니다. 이름은 기존 도감의 ‘부제, 고유명’ 표기를 따릅니다.

특급 시트는 2×2 네 자세입니다. 늑대장어는 긴 몸의 파동, 고래상어는 육중한 꼬리 추진과 안정적인 가슴지느러미를 사용합니다. 네메리온은 4×2 여덟 자세로 앞 네 장은 유영, 뒤 네 장은 턱·아가미 벌리기 준비→전개→복귀→안정이며 6초 주기로 연결합니다. 모션 감소에서는 첫 자세를 유지합니다.

원본은 `sources/*.source`에 보존합니다. 신화의 원본 여백 8% 기준을 통과한 뒤 전체 시트 동일 배율로 내보내며, 프레임별 배율은 바꾸지 않습니다. 신화 추가 행동의 안전 여백을 위해 넓게 생성한 시트는 전체 표시 배율로 보완합니다. 원본·내보내기·몸통 위치 보정 검사는 `registration.json`, `sprite-audit.json`으로 확인합니다.

`prepare-nyamnyam-sprites.ps1 -Root <배치>` → `inspect-nyamnyam-art.ps1 -Root <배치> -RequireComplete` → `register-sprite-anchors.ps1`(2열·4열 각각) → `export-nyamnyam-compat.ps1 -Root <배치>` → `register-ocean-creatures.mjs` 순서입니다. 네메리온은 기존 클라이언트용 첫 네 자세 시트도 보존하고 앱은 별칭으로 8자세 원본을 선택합니다. 카탈로그 배포는 신규 CLI migration에 세 ID만 지정한 `db:catalog`를 사용합니다. 공개 PNG 7개 업로드 뒤 `verify-nyamnyam-upload.mjs <배치>`로 바이트를 대조합니다.
