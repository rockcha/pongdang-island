# 쏜살 낚싯대 이미지

아이보리·황동·주황색과 제비 날개 문양으로 빠른 입질을 기다리는 장비를 표현합니다. 기존 잔물결 낚싯대 이미지는 채색·재질 참고이며 형태를 복제하지 않습니다.

내장 image_gen으로 썸네일, 고정 릴, 회전 릴, 찌를 각각 생성했습니다. 최종 프롬프트·파일 경로·업로드한 파일의 SHA-256은 manifest.json에 기록합니다. 투명 배경을 보존하고 업로드 과정에서는 무손실 최적화만 적용했습니다.

릴은 바깥 이미지 경계가 아닌 축을 기준으로 배치합니다. 회전 부품의 축과 고정 프레임의 축을 맞추고, 찌는 몸통 중심을 기준으로 연결합니다. 부품을 교체할 때에는 정지 상태뿐 아니라 실제 릴 회전도 확인합니다.
