# 개발자의 눈물이 담긴 병

사용자 지정 판매가 5골드인 일반 쓰레기. 기존 일반 유리병과 같은 공용 서식지를 사용하며, 어항에서는 바닥 부근에 정적으로 놓인다. fixed 이동 유형을 명시하고, trash의 기존 DB 제약을 만족하는 양의 speed 값은 실제 이동에 사용하지 않는다.

생성 도구·스타일 참고·최종 프롬프트·파일 경로는 manifest.json에 기록한다. 업로드는 기존 storage:upload 명령으로 수행하고 공개 다운로드 해시를 대조한다. 이미지 업로드 뒤 대상 종만 포함한 CLI migration을 적용한다.
