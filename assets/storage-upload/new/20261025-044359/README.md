# 퐁이 해저 시추 플랫폼 썸네일 시안

사용자가 승인한 썸네일을 기준으로 작업하는 퐁이 여섯 마리와 고정된 플랫폼의 8프레임을 제작했다. 썸네일 프롬프트는 manifest.json, 스프라이트 생성 단계별 입력·실패 시안·최종 프롬프트는 sprite-generation.json에 보존한다.

원본 셀의 알파 여백을 먼저 검사한 뒤 모든 프레임에 동일 배율을 적용하고, 불투명한 철탑 패치로 이동 보정했다. 독립적인 실루엣 자르기·자동 확대는 하지 않는다. 검사값과 보정량은 registration.json에 있다. 호환 시트는 기존 앱의 2×2 분할을 위한 것이며 새 렌더러는 public/aquarium/swim의 동일한 8프레임 원본을 사용한다.

업로드 시 원본·가이드·실패 시안은 제외하고 manifest.files의 Storage 경로 세 파일만 별도 임시 배치에 복사해 storage:upload를 실행한다. 무손실 최적화한 전송 바이트를 이 배치에 되돌리고 공개 URL의 SHA-256을 대조한다. 카탈로그 원본과 CLI migration이 등록 기준이며 과거 migration 재실행이나 기존 플레이어 데이터 변경은 하지 않는다.
