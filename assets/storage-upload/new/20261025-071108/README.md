# 할로윈 개체 제작 배치

일반·희귀는 퐁이 카툰풍, 특급은 별빛 참고의 채색·조명만 사용한다. 썸네일을 개체 동일성 참고로 삼아 생물의 오른쪽 방향 2×2 유영 시트를 만든다. 쓰레기는 얼굴을 추가하지 않고 정적으로 표시한다. 최종 프롬프트와 입력 역할은 manifest.json에 보존한다.

원본은 sources의 `.source` 파일에 보존한다. 원본 셀의 투명 여백을 먼저 검사한 뒤 시트 전체에 하나의 배율만 적용하고, 실제로 확인한 불투명 머리 패치로 프레임별 평행 이동을 측정한다. 프레임별 자동 확대·실루엣 재정렬은 하지 않는다. registration.json과 anchor 결과는 재현 자료이며, 어항과 도감 미리보기에서 행 전환·반복 경계·실제 표시 크기도 확인한다.

업로드는 이 폴더를 인자로 storage:upload를 실행한다. sources의 원본·manifest·검수 자료는 업로드하지 않는다. 전송 과정의 무손실 압축 후 공개 URL과 로컬 PNG의 해시를 다시 대조한다. 카탈로그 원본 편집 후 CLI가 생성한 빈 migration에 db:catalog로 SQL을 만들고, 관련 종·이벤트 기간·서식지·이동 설정을 원격에서 재조회한다. 기존 할로윈 기간은 변경하지 않는다.
