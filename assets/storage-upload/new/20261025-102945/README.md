# 퐁이 이동형 개체 썸네일 시안

보물 인양선과 거북이 탐험대의 썸네일 비교용 시안이다. 카탈로그·가격·출시 시각은 등록하지 않는다. 향후 제작할 경우 두 개체 모두 오른쪽 원본과 양방향 유영을 기준으로 하며, 이동 높이 계획은 manifest.json에 기록한다.

퐁이 원본은 캐릭터 동일성, 별빛 참고는 채색·재질, 기존 해저 플랫폼은 같은 게임의 마감과 여러 퐁이가 협업하는 표현에만 사용한다. 입력별 역할과 최종 프롬프트는 manifest.json에 보존한다. 생성 원본은 sources의 `.source` 파일로 보관하고, 검토할 PNG는 버킷 경로 형태의 하위 폴더에 복사한다. 이 배치는 썸네일 시안이며 자동 업로드 대상으로 사용하지 않는다.
