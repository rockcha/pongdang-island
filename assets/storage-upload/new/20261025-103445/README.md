# 퐁이 이동형 신화 개체 제작

승인된 인양선·거북이 썸네일의 동일성을 유지한다. 선체·등껍질과 얼굴의 위치는 고정하고, 인양선은 상자 승강·핸들·프로펠러·조명, 거북이는 네 지느러미·깃발·망원경·뒤쪽 퐁이의 손을 실제로 움직인다. 기본 유영 네 자세와 추가 행동 네 자세가 6초 안에서 이어지며 모션 감소에서는 첫 자세를 유지한다.

상자의 최저 위치와 펼친 지느러미를 포함한 동작 범위 때문에 가이드에는 넓은 투명 여백을 둔다. 원본에서 모든 셀의 여백을 확인한 뒤 시트 전체에 하나의 배율을 적용한다. 위치는 움직이지 않는 선체 창틀 또는 거북이 얼굴의 불투명 패치로 보정하며, 손·깃발·망원경·상자·빛을 기준점으로 잡지 않는다. 프레임별 실루엣 확대나 자동 중앙 정렬은 금지한다.

원본·가이드는 `.source` 확장자로 보존한다. 프롬프트·입력 역할·동작 계획은 manifest.json, 원본 여백·등록 결과는 registration.json에 있다. 호환용 2×2 시트는 0·2·5·7 자세를 동일 배율과 측정된 평행 이동으로 추출하며, 새 앱의 어항과 도감은 public/aquarium/swim의 8프레임 원본을 함께 사용한다.

Storage 업로드 후 무손실 최적화한 파일과 공개 URL의 해시를 대조하고 public 복사본도 같은 바이트로 맞춘다. 카탈로그 원본에서 가격·이동·공통 서식지를 등록한 뒤 빈 CLI migration에 db:catalog로 SQL을 생성한다. 기존 종이나 보유 개체는 변경하지 않는다. 원격 등록 완료와 앱 코드 배포 완료는 별도로 확인한다.
