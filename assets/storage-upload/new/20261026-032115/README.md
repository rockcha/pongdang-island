# 일반 폐품 쓰레기 이미지

Built-in `image_gen`으로 각 개체를 따로 생성했다. 일반 등급 퐁이 참고는 짙은 갈색 윤곽선과 셀 채색의 스타일에만 사용하고, 사물에는 얼굴을 넣지 않았다. 최종 프롬프트와 원본 생성 위치·Storage 경로는 `manifest.json`에 있다. 이미지는 투명 PNG이며 정적인 바닥 고정 사물이므로 스프라이트 시트는 사용하지 않는다.

최종 파일은 이 폴더의 `trash/normal/`에 있다. 기존 업로드 도구로 PNG를 무손실 압축한 뒤 `collectibles` 버킷의 같은 상대 경로로 올린다. 배치 루트의 README와 manifest는 업로드하지 않는다. 공개 다운로드와 최종 로컬 파일 해시를 비교하며, 재업로드 전에 기존 경로에 다른 바이트가 없는지 확인한다.

카탈로그 원본은 `supabase/catalog/catalog.json`이며 이 배치의 등록 SQL은 `20261025182323_three_common_industrial_trash.sql`이다. 가격·등급·이동 수치의 원본은 카탈로그로 유지한다. 이후 이미지 교체는 파일명 버전을 올려 별도 카탈로그 migration으로 연결한다.
