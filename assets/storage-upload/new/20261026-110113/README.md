# 발전기금 배너

이미지 생성 원본과 실제 앱 배너의 출처는 `manifest.json`에 보존한다. 원본은 `.source` 확장자의 PNG이며, 런타임에서는 리사이즈한 WebP를 사용한다. 기존 섬 일러스트를 참조하여 노을빛 항구와 등불로 자율 후원의 따뜻함을 표현했다. 제목과 계좌번호는 이미지에 굽지 않고 실제 HTML로 표시한다.

`finalPath`는 프런트엔드 정적 파일이다. 이 배너에는 Storage 업로드가 필요하지 않으며 앱 배포에 포함한다. 화면 검증은 `artifacts/development-fund/`의 모바일·데스크톱 캡처를 참고한다.
