# 하트를 전하는 퐁이

기존 감사 인사 퐁이를 참조하여 내장 imagegen으로 하트를 내미는 여덟 프레임을 생성했다. 참조·전체 프롬프트·원본·앱 경로·알파 경계 검사는 manifest에 보존한다.

전체 원본을 같은 비율로 정규화한 뒤 모든 셀에 같은 배율과 여백을 적용했다. 셀마다 꽉 차게 자르거나 따로 확대하지 않는다. 런타임은 한 줄의 투명 WebP 시트이며 하트를 품에 안기·앞으로 내밀기·자랑하기·역순 복귀·잠시 쉬기를 반복한다. 머리·발의 위치를 유지하고 전체 캐릭터 확대나 불투명도 변화로 동작을 대신하지 않는다. 모션 감소에서는 하트를 안은 첫 프레임을 정지 표시한다.

프런트엔드 정적 에셋으로 배포하며 Storage 업로드는 필요하지 않다. 실제 페이지의 작은 표시 크기, 프레임 중간과 마지막 복귀, 모바일 화면에서 검수한다.
