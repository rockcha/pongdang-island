# 밤낮으로 개발하는 퐁이

감사 인사 퐁이를 참조하여 내장 imagegen으로 노트북을 두드리는 여덟 프레임을 생성했다. 전체 프롬프트와 원본·최종 경로, 프레임별 알파 경계는 manifest에 보존한다.

모든 프레임을 같은 배율·여백으로 정규화하여 한 줄의 투명 WebP로 배치했다. 머리·발·노트북 위치와 크기를 유지하고 손·표정의 작은 움직임을 반복한다. 해·달은 별도 HTML 아이콘으로 부드럽게 교대하며 캐릭터 전체의 색이나 배율을 바꾸지 않는다. 모션 감소에서는 첫 프레임과 해 아이콘을 정지 표시한다.

후원하기 탭의 두 번째 소개 슬라이드에서 사용한다. 슬라이드가 숨겨지거나 앱이 비활성화되면 재생을 멈춘다. 프런트엔드 정적 에셋이므로 Storage 업로드는 필요하지 않다.
