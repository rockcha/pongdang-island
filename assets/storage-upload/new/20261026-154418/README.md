# 공통 기름 어종

일반 공통 물고기 세 종. 판매가는 사용자 지정값을 따른다. 전갱이와 삼치는 중층을, 장어는 중·하층을 유영하며 모든 현재 해역에서 획득 대상이다.

`manifest.json`에 built-in image_gen 최종 프롬프트와 참조 역할을 기록했다. 일반 등급 Pongi 스타일과 기존 기름 정어리의 채색을 참고하고, 어종별 최종 썸네일을 네 프레임의 동일성 참조로 사용했다. `sources/`는 생성 원본을 보존한다. 삼치의 첫 시트는 경계 여백 검사에서 제외하고 재생성했다.

기존 `prepare-common-fuel-art.ps1` 절차로 불투명 머리 패치를 측정하고 한 배율로 네 프레임을 정렬했다. 프레임별 확대·축소는 하지 않았다. `registration.json`은 실제 머리 정합·안전 여백 측정값이며 `preview.source`는 밝고 어두운 배경의 실제 축소 프레임 검수용 PNG다. 썸네일과 시트 모두 오른쪽 원본이다. PNG 업로드 시 무손실 압축 후 해시를 방향 등록에 반영한다.

원격 반영·검증 범위는 `asset-verification.json`을 따른다. MCP OAuth 갱신 실패로 기존 서버 전용 PostgREST 연결을 사용해 신규 카탈로그와 서식지를 반영했다. 로컬 CLI migration은 보존했으며 원격 migration history에 적용 완료로 기록하지 않았다. 전체 원격 구조 비교를 뜻하지 않는다.
