# 한상바다 음식 어종

`manifest.json`에 built-in image_gen의 최종 프롬프트와 참고 역할, 원본·출력 경로를 기록했다. 일반·희귀 모두 퐁이 참고의 카툰 채색만 사용하고 개체는 오른쪽을 향하게 제작했다. 한상바다 토착 물고기이며 개체별 이동 높이는 카탈로그가 기준이다.

스프라이트는 실제 유영 자세 네 장으로 구성한다. 경계 여백이 부족한 초기 결과는 폐기하고 동일한 크기·머리 위치의 배치 가이드로 재생성했다. 원본을 보존하고 시트 전체에 공통 배율을 적용했다. 소시지 문어복은 측정한 평행 이동만 내보내기에 반영했으며 프레임별 확대는 하지 않았다. `anchor-matches.json`은 보정 전, `final-anchor-matches.json`과 `final-bounds.json`은 최종 이미지의 독립 검사다. 최종 정렬은 네 프레임 모두 머리 이동량이 0이고, 실제 어항과 도감에서 반복 재생 및 밝고 어두운 배경의 외곽을 확인했다.

업로드 도구가 PNG를 무손실 최적화한 뒤 공개 다운로드와 로컬 해시를 대조했다. 새 아트를 교체할 때 원본 안전 여백·머리 기준 패치·네 프레임 반복 경계를 다시 검사하고 방향 해시 및 썸네일 파생물을 갱신한다. 가격·등급·서식지는 이 문서에 중복 관리하지 않고 카탈로그와 migration을 검증한다.
