# 약탈자의 항로 이미지 제작 자료

카탈로그 원본은 `supabase/catalog/catalog.json`이다. 이 배치의 manifest 가격은 제작 당시 기록이며 이후 운영 가격을 대신하지 않는다.

일반·희귀는 퐁이 참고의 둥근 형태와 선명한 표정, 특급·신화는 별빛 참고의 세부 재질을 사용했다. 신화의 이름은 칭호와 이름을 합친 세 종으로 해석했다. 물고기는 오른쪽을 향하며, 걷는 갑각류는 바닥 높이를 사용한다. 쓰레기와 장식물은 고정한다.

`sources/*-sprite.source`는 생성 원본 PNG다. 확장자를 달리해 업로더가 원본과 실패 시안을 올리지 않게 했다. 초기 실패 시안은 `*-initial.source`에 남겼다. 셀 경계에서 잘린 원본은 재생성했으며, 원본의 안전 여백을 검사한 뒤 전체 시트에 동일한 배율만 적용했다. 생성 입력과 프롬프트는 manifest의 items·entries·generations를 확인한다.

신화는 4×2의 8자세다. 블러드세일은 촉수와 붉은 지느러미, 바르카는 다리·닻 집게, 모르가르는 꼬리·망토 지느러미와 턱이 움직인다. 기본 유영과 추가 행동이 6초에 반복되며 마지막 자세는 중립 자세로 복귀한다. 프레임별 확대나 불투명도 전환을 사용하지 않는다. `registration.json`은 동일 배율과 단단한 몸통·머리 패치의 RGB 등록 측정 결과다. `anchors-*.json`, `registered-*.json`으로 측정을 재현한다. 모르가르와 투구게는 움직이는 부위를 피하도록 눈 주변 패치를 직접 지정했다.

이미지 테두리 기준은 [공통 제작 기준](../../../references/collectible-style/README.md)을 따른다. 밝고 어두운 배경 및 실제 표시 크기에서 실루엣을 확인한다. 원본 검사는 `node scripts/audit-collectible-images.mjs assets/storage-upload/new/20261027-034411`로 재현한다. 신화 원본은 각 셀 알파 32 기준 8% 이상의 여백을 확보해야 한다. 수치 통과만으로 자세·잘림·가장자리·동작 검수를 대체하지 않는다.

`audit.json`은 원본 경계 검사, `preview-verification.json`은 실제 Phaser 어항·도감 미리보기의 브라우저 검사, `storage-verification.json`은 공개 다운로드의 SHA-256 검증이다. `region-art/manifest.json`은 배너·배경·지도의 별도 Storage 경로와 해시다. 지도는 낚시에서 모으는 4조각이며 지도 상점용 행과 중복 등록하지 않는다.

개체 업로드 때는 `fish`, `trash`, `decorations`만 별도 스테이징 폴더에 복사한다. 배치 루트에는 `region-art`가 있어 개체 업로더에 루트 전체를 전달하면 안 된다. 업로드에는 버전 경로를 사용하고 공개 다운로드 바이트를 검증한다. 원격 DB 적용과 프론트 배포 완료는 별개다.
