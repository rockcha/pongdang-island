# 해적 디테일 보강과 신화 교체

기존 7종에 역할이 읽히는 해적 장비를 보강하고 두 신화를 탐욕의 황금손·저주받은 황금함대로 교체했다. 종 ID는 보유 개체·발견 기록·선물·과거 낚시 결과가 참조하므로 유지한다. 가격·등급·서식지도 보존하며 신규 출시 시각을 다시 등록하지 않는다. 현재 설정의 원본은 카탈로그이고 manifest의 가격은 제작 당시 기록이다.

일반·희귀는 기존 개체의 해부 구조와 퐁이 카툰 스타일, 특급·신화는 부드러운 판타지 재질을 사용한다. 입력 역할과 생성 프롬프트는 manifest 및 generation 자료에 남긴다. 외눈붕어의 화면에 보이는 눈은 모든 자세에서 검은 안대로 가린다. 신화는 기존 캐릭터를 모사하지 않은 황금 손과 선체가 결합된 괴수다. 황금함대는 걷는 갑각류였던 기존 형태를 대체하므로 이동을 수중 유영으로 바꾼다.

황금손은 손가락을 조금 풀고 보물을 손바닥 안으로 끌어모은 뒤 중립 자세로 돌아온다. 황금함대는 후미 선체·돛이 작게 움직이고 포문이 열렸다 닫힌다. 두 시트는 4×2의 8자세이며 6초 반복과 모션 감소 시 0자세를 사용한다. 위치 보정은 움직이는 손가락·보석 대신 단단한 손바닥, 포문 대신 선수의 눈 주변 패치로 측정한다. 프레임별 확대나 불투명도 전환을 사용하지 않는다.

`sources/*-sprite.source`는 후처리 전 PNG다. 셀 경계의 안전 여백을 통과한 원본만 전체 시트에 같은 배율로 준비한다. 작은 제스처와 장비의 잘림을 방지하려고 생성 가이드에 넓은 여백을 사용하며 실제 표시 크기는 시트 전체의 공통 배율로 보정한다. 초기 실패 시안이나 이전 콘셉트인 `*-previous.source`는 최종본이 아니다. 테두리는 [공통 기준](../../../references/collectible-style/README.md), 동작·등록은 [신화 제작 절차](../../../references/mythic-sprites/README.md)를 따른다.

원본 여백은 `audit.json`, 실제 위치 측정은 `registration.json`과 `registered-*.json`을 확인한다. `node scripts/audit-collectible-images.mjs assets/storage-upload/new/20261027-090400`으로 경계를 검사하고 `artifacts/verify-pirate-refactor-ui.mjs`로 실제 Phaser 어항·도감, 반복 동작과 모션 감소를 확인한다. 가이드는 정적인 위치 참고이며 최종 애니메이션으로 사용하지 않는다. 업로드는 완성된 fish PNG만 스테이징하고 공개 다운로드 SHA-256을 검증한다. DB 반영과 프론트 배포는 별개다.
