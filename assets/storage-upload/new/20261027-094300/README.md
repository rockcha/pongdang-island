# 공통 일반 개체 제작

사용자가 희귀 이상 작업을 보류했으므로 이번 배포는 manifest의 일반 개체만 포함한다. 보류한 개체는 카탈로그·서식지·신규 출시 목록에 등록하지 않는다. 가격·경로·이동 값은 카탈로그가 원본이며 여기에서 별도 목록으로 관리하지 않는다.

내장 `image_gen`으로 제작했다. 사용자 지정 정제용 청어 원본에서 갈색 윤곽선·따뜻한 입체 음영·눈 표현을 참고하되 각 생물의 구조·무늬를 유지했다. 썸네일 확정본으로 위치 가이드를 만들고 네 개의 실제 동작을 생성했다. 최종 입력과 프롬프트, 원본·Storage 경로는 manifest와 generation에 보존한다. 원본은 sources에 두며 잘린 원본을 축소하여 통과시키지 않는다.

원본 셀 경계 검사 뒤 전체 프레임에 공통 배율만 적용한다. 머리·몸통의 불투명 패치를 눈으로 확인하고 RGB 위치 보정을 측정한다. 윤곽 범위나 움직이는 꼬리로 개별 프레임의 크기를 맞추지 않는다. 앱은 중간 자세를 역순으로 거쳐 반복 경계가 튀지 않게 하고 모션 감소에서는 첫 프레임을 유지한다. 바다토끼의 바닥 이동과 다른 개체의 유영을 구분한다.

검증은 `tests/shared-common-art.test.ts`, `tests/shared-wonders-sql.test.ts`와 배치의 audit·registration·preview-verification·storage-verification을 사용한다. 검수 화면은 `artifacts/shared-common-review.html`이다. 밝고 어두운 배경의 가장자리, 실제 어항·도감, 모바일 DPR 1·2·3, 모션 감소를 확인한다.

공개 이미지의 바이트 해시를 먼저 검증한 뒤 이번 CLI migration 두 개만 원격에 적용하고 관련 행과 서식지를 다시 조회했다. 기존 로컬·원격 migration 이력 차이는 복구하지 않았으며 전체 구조 호환성을 검증한 기록이 아니다. 원격 적용 범위는 `artifacts/shared-common-deployment.json`에 남긴다.
