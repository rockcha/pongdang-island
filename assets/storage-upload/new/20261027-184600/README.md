# 데우스 제로 스프라이트

몸체와 받침대는 고정하고 후광 조각·가슴 안 물고기·청록색 잔광만 움직입니다. 4×2 8프레임, 8초 반복이며 모션 감소에서는 첫 프레임을 유지합니다.

원본은 잘림 없이 약 4.7% 이상의 여백을 가졌으며 모든 셀에 같은 투명 여백을 추가했습니다. 위치 보정은 불투명한 무릎/몸체 패치를 기준으로 측정했습니다. 최종 시트는 512px 셀, 호환 시트는 0·2·4·6 프레임의 2×2 배치입니다. 기존 썸네일과 가격·고정 이동 유형은 유지합니다.

`manifest.json`의 입력 역할·최종 프롬프트와 `bounds.json`, `registration.json`으로 재현·검증합니다. 이 배치 폴더를 `storage:upload`에 넘겨 버전 경로로 업로드한 뒤 공개 바이트 해시를 확인합니다. 카탈로그 연결은 `20261027094729_animate_deus_zero.sql`이며 앱 배포와 원격 적용은 별도입니다.
