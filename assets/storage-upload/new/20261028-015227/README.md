# 햇살이 머무는 열대 수초항

따뜻한 햇살·유목 은신처·열대 수초로 구성한 감성 테마입니다. 중앙과 중간 수심은 실제 개체를 위한 여백으로 유지하며 배경에는 생물을 그리지 않습니다.

내장 image_gen으로 세로 배경을 생성한 뒤 이를 동일성 참고로 파노라마를 재구성했습니다. 최종 프롬프트·참고·생성 원본과 공개 이미지 검증용 해시는 manifest.json에 보존합니다.

세로 및 파노라마를 시각 검수하고 `scripts/upload-aquarium-backgrounds.mjs <이 폴더> --dry-run` → `--upload` 순으로 업로드합니다. 공개 바이트 검증 뒤 카탈로그 migration을 적용합니다. 파노라마의 개발용 배치 경로와 운영용 파일명은 theme-panoramas.json에서 연결합니다. DB·Storage 등록과 프런트엔드 배포는 별개입니다.
