# 검은돛 해적만

해질녘 해적선 아래에서 부두의 작은 보물상자까지 이어지는 수중 배경입니다. 실제 물고기를 위한 중앙 유영 공간을 유지하고, 선체·닻·기둥·보물은 가장자리와 바닥에 둡니다.

내장 image_gen으로 가로 시안을 생성하고, 이를 기준으로 실제 어항 비율의 파노라마와 세로 배경을 각각 재구성했습니다. 최종 프롬프트·참고·생성 원본·경로·해시는 manifest.json에 보존합니다.

테마의 카탈로그 원본은 `supabase/catalog/catalog.json`입니다. 세로 배경과 파노라마를 같은 테마에 연결하며, 파노라마만 따로 구매하거나 중복 과금하지 않습니다. 변경·등록은 대상 프로젝트와 관련 원격 상태를 먼저 조회한 뒤 DB 관리 절차를 따릅니다. Storage 업로드 시 manifest에 지정한 파일만 전송하고 공개 다운로드 해시를 확인합니다.
