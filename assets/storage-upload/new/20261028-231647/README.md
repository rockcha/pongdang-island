# 해적 퐁이 이미지

내장 image_gen으로 생성했다. 최종 프롬프트·참고 이미지 역할·버킷 경로·바이트 해시·배포 정보는 manifest.json이 원본이다. 썸네일과 2×2 유영 시트 모두 오른쪽을 향한다.

## 제작과 검수

승인한 썸네일을 개체 동일성 참고로, 작은 네 자세 배치 가이드를 여백 참고로 사용했다. 원본은 sources/의 .generated.source 파일로 보존한다. 꼬리와 코트·두건·밧줄 끝의 움직임을 우선하며 눈 상태만으로 프레임을 나누지 않았다.

frame-registration.json은 원본의 불투명 눈·볼 패치를 측정한 결과다. 각 프레임 전체를 정수 좌표로 이동하고 동일한 투명 여백을 추가해 머리 위치를 고정했다. 모든 원본 RGBA 픽셀을 보존하며 프레임별 배율·불투명도는 바꾸지 않았다. packing-verification.json과 packed-registration.json에서 픽셀 보존과 실제 패치 매칭을 확인한다. 최종 시트는 런타임의 개체별 위치 보정 없이 재생한다.

셀 점유율은 일반적인 80~88% 목표보다 작다. 모자·천·밧줄의 동작 여백과 원본의 희미한 알파까지 보존하기 위해 공통 패딩을 유지한 예외이며, 실제 어항 표시 크기로 보완했다. 원본과 최종 시트의 투명도·여백, 밝고 어두운 배경의 전 프레임, 실제 어항·도감 렌더러의 반복 재생 및 모바일 DPR 2·3과 모션 감소를 검수했다. 자동 결과는 audit.json과 browser-verification.json에 있다.

## 업로드와 적용

fish/epic 아래 PNG만 동일 collectibles 버킷 경로로 업로드한다. sources·review·JSON·README는 업로드하지 않는다. 업로드 도구의 무손실 압축 후 바이트를 이 폴더에도 동기화했으며 공개 다운로드 해시를 비교했다.

카탈로그 원본에서 생성한 20261028142356_plunder_three_epic_pirate_pongis.sql과 원격 전용 선택 컬럼의 방향만 보완하는 20261028143916_pirate_pongi_remote_facing_metadata.sql을 적용했다. 후자는 해당 컬럼이 없는 로컬 DB에서는 구조를 추가하지 않는다. 두 migration 모두 과거 이력이나 기존 종을 수정하지 않는다.

원격 확인 범위는 신규 3종·서식지·방향 메타데이터·이미지 6장과 새 이력이다. 전체 원격 구조·과거 이력 동등성과 프런트엔드 배포를 확인한 기록은 아니다.
