# 반딧불 요정여울 이미지 제작

이 배치는 사용자 지정 63종과 해역·장비 이미지를 보존합니다. 일반 장식물 평균가는 사용자 확인한 40골드입니다. 가격·이동 설정·참고 이미지와 최종 프롬프트는 manifest.json을 따릅니다. 승인한 도토리복어와 등지기 요정 시안을 개체 동일성 참고로 사용합니다.

생성 원본을 검수하고 공개 업로드 해시와 원격 카탈로그를 확인하기 전에는 출시 완료로 취급하지 않습니다. 원본은 저장소의 artifacts/previews/firefly/originals/에 보존하며 업로드 도구에는 최종 파일만 전달합니다.
