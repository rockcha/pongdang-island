# 파라오의 황금해 썸네일 시안

파피루스 해마(특급 느낌)와 오벨리스크 거신(신화)의 외형 확인용 단일 썸네일입니다. 기본 제공 `image_gen`으로 생성했고, 참고 PNG는 채색·조명·재질에만 사용했습니다. 프롬프트와 파일·이동 기획은 manifest를 기준으로 합니다.

현재는 컨셉 검토용입니다. 카탈로그·가격·해역 등록이나 이미지 업로드는 하지 않았습니다. 이동 수치와 등급은 기획안이며 실제 동작을 적용한 값이 아닙니다. 정식 제작 시 외곽·소형 표시를 최종 검수하고 승인된 외형 기준으로 특급 기본 시트와 신화 8프레임 시트를 별도 제작합니다.
