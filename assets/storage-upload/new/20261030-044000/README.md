# 파라오의 황금해

사용자 지정 59종과 지역·낚시 장비를 함께 제작한다. 일반·희귀는 퐁이 카툰풍, 특급·신화는 별빛 가오리의 채색·재질만 참고하는 판타지 일러스트풍이며, 전부 황금·모래 계열로 통일한다. 구체적인 가격·이동 설정·참고 역할·생성 프롬프트는 manifest.json에 보존한다.

지도는 4조각이고 앞 2조각은 희귀, 뒤 2조각은 특급이다. 원본 이미지는 assets/generated/pharaoh-20261030에 별도 보존한다. 배치 가이드는 위치 참고이며 실제 애니메이션 결과를 대신하지 않는다. 스프라이트는 원본 여백과 몸통 기준점을 검수하고 동일 배율·정수 이동으로 최종 PNG에 정렬을 반영한다.

검증은 pharaoh-region.test.ts의 평균 판매가·서식지·지도 후보·수령 재시도·최종 잠금 해제, 이미지 원본/최종 감사, 어항과 도감의 실제 재생을 포함한다. 공개 업로드 바이트 해시, 관련 DB 재조회와 프런트엔드 배포 확인은 각각 구분한다. DB나 Storage에 등록했다는 이유만으로 앱 배포 완료로 표현하지 않는다.
