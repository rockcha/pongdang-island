# 호루스 위치 튐 수정

이 배치는 기존 여덟 자세의 그림을 다시 그리지 않고, 얼굴·왕관·가슴의 독립적인 기준점을 합의해 정수 픽셀 평행 이동만 적용한다. 이전 날개 근처 단일 패치는 복귀 프레임의 몸 위치를 잘못 잡았다. 이전 시트와 보유 개체 ID·가격·출시 시각은 유지한다.

`scripts/align-horus-v2.mjs`는 모든 비투명 RGBA 픽셀을 보존하고 프레임별 확대·축소·불투명도 변경을 하지 않는다. 셀 크기와 표시 배율도 유지한다. 원본·세 기준점의 사전/사후 측정·프롬프트 출처·파일 해시는 manifest와 registration에 기록한다. 새 PNG의 런타임 이동 보정은 0이다.

어항과 도감은 같은 호루스 전용 재생 순서를 사용한다. 기본 활공에서 접힌 날개 자세를 거쳐 특수 동작으로 들어가고 중립 자세로 복귀한다. 기존 앱은 첫 네 자세의 2×2 호환 시트를 사용한다. 검수는 6초 반복 경계, 제자리 재생, 어항 이동·반전, 모션 감소 및 DPR 1·2·3을 포함한다. 업로드와 DB 등록은 프런트엔드 배포와 구분한다.
