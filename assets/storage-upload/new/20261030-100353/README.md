# 황금해 전경과 낚시터 분리

해역 소개는 왕국 전체를 담은 전경을, 낚시는 수면 높이의 바다 풍경을 사용한다. 두 용도를 같은 그림으로 합치지 않는다. 전경은 화면 비율이 달라도 전체가 보이도록 표시하고 여백만 부드러운 배경으로 채운다.

생성 프롬프트·참고 그림·원본·최종 경로는 manifest에, 공개 다운로드 검증은 storage-verification에 기록한다. 낚시터 그림은 기존 원본을 변경하지 않고 별도 경로에 복사했다. 실제 HomePage·HarborPage·FishingStandby의 화면 검수는 artifacts/previews/pharaoh/overview-verification.json에서 재현 조건을 확인한다. 이미지·DB 경로 적용과 프런트엔드 배포는 별개다.
