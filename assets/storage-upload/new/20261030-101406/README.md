# 황금해 신화의 각성 동작

네 개체는 모래빛 본체·황금 장식·각성 때 선명해지는 문양을 공유한다. 기본 4초와 특수 동작 2초를 한 주기로 사용한다. 몸체는 4×2 시트에서 움직이고, 손 위 원자 궤도와 상형문자는 렌더러의 별도 벡터 레이어로 회전한다. 넓은 후광이나 전체 불투명도·배율 변화로 동작을 대신하지 않는다.

아누비스는 지팡이와 영혼의 저울을 들고 부유한다. 거신은 펼친 손 위의 원자 모형, 호루스는 양쪽 날개와 머리 위 문자, 스카라베는 커진 태양과 황금 변신이 핵심이다. 모션 감소에서는 기본 자세와 고정된 은은한 문양만 남긴다.

입력 그림의 역할·프롬프트·생성 원본과 최종 파일은 manifest에 보존한다. 최초 시트와 거신의 후광·여백 실패 시안은 검수 기록으로 남기고 등록하지 않았다. raw-compact-audit는 후처리 전 여백, anchor-config와 anchor-results는 실제로 검토한 세 고정 부위, registration과 final-registration은 정수 이동·공통 패딩 및 최종 위치 잔차의 근거다. 얼굴·가슴 등 경직 부위를 정렬하며 날개·천·손의 외곽선을 기준점으로 삼지 않는다. 최종 시트에 이미 정렬했으므로 런타임 이동 보정을 더하지 않는다.

공개 PNG는 픽셀을 변경하지 않는 압축 후 업로드했고 다운로드 해시는 storage-verification에서 확인한다. 실제 Phaser 어항과 CollectiblePreview의 반복 재생·DPR·모션 감소 검수 자료는 artifacts/previews/pharaoh/renderers에 있다. 합성 개체를 사용했으며 플레이어 데이터를 쓰지 않았다. 이미지·이동 설정의 원격 적용과 프런트엔드 배포는 구분한다.
