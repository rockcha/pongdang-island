# 천년왕조의 마지막 유산, 황금가면

스카라베의 자리를 부유하는 파라오 황금가면으로 교체한다. 기존 종 ID를 유지해 보유·도감·선물·거래 연결과 최초 출시 시각을 이어받으며 판매가는 바꾸지 않는다. 파일명의 scarab은 기존 데이터의 식별자다. 새 개체 출시나 보유분 지급으로 처리하지 않는다.

금빛 가면은 경직된 기준체이고, 눈에서 이어진 푸른 영혼과 작은 장식이 8프레임 안에서 흐른다. 기본 4초 뒤 영혼이 모이고 펼쳐지는 2초 동작으로 연결한다. 별도 벡터 레이어의 푸른 빛도 두 눈에 붙여 흐르게 한다. 모션 감소에서는 기본 자세와 고정된 문양으로 멈춘다.

manifest에는 입력 역할·생성 프롬프트·원본·최종 파일을, raw-compact-audit에는 후처리 전 여백을 보존했다. 여백이 부족한 첫 시안은 rejected 기록으로 남기고 등록하지 않았다. 가면의 얼굴·이마·관자 부위를 기준으로 정수 평행 이동을 측정해 최종 PNG에 반영했으며 원본 비투명 RGBA를 보존했다. 최종 시트에 런타임 이동 보정을 중복 적용하지 않는다.

등록 시에는 공개 PNG 다운로드 해시, 대상 행·가격·인증 역할 조회를 다시 확인한다. 실제 Phaser 어항과 CollectiblePreview의 합성 개체 검수는 artifacts/previews/pharaoh/renderers에 있다. 이미지·카탈로그 적용과 클라이언트 배포는 별개다.
