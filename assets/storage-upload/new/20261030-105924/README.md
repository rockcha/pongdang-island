# 황금해 고급 어항 테마

잠든 피라미드의 뜰과 태양이 잠긴 왕릉은 밝은 사암 정원과 어두운 태양 제단으로 분위기를 나눈다. 두 배경 모두 세 화면에 이어지는 단일 수중 파노라마이며, 중앙과 주 유영 높이는 비워 개체의 실루엣이 묻히지 않도록 한다. 건축물은 가장자리와 먼 배경에 배치한다.

원본·참고 역할·프롬프트·가격·등록 정보는 manifest를 따른다. 생성 원본은 sources에 별도로 보존하며, 최종 PNG에는 픽셀을 바꾸지 않는 압축만 적용했다. 공개 다운로드 해시는 storage-verification에 기록한다. 상점에는 전체 비율을 유지한 경량 미리보기를, 실제 어항에는 원본 파노라마를 사용한다.

실제 상점 카드·구매 확인창과 합성 개체를 넣은 실제 Phaser 어항을 로컬에서 검수했다. 구매·재시도·수조 적용 검증은 로컬 가상 계정으로 실행하며 원격 플레이어의 골드를 사용하지 않는다. 이미지·상점 카탈로그 등록과 프런트엔드 배포는 구분한다.
