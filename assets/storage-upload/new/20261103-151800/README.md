# 공통 저가 개체 이미지

일반·희귀 퐁이 그림체를 기준으로 만든 6종이다. 물개 인형은 사용자 수정에 따라 ‘꼬질 물개 인형’으로 정하고 단추 대신 일반 눈을 사용한다. 정확한 생성·수정 프롬프트는 [prompts.json](prompts.json), 파일별 해시·이동 설정·검증 범위는 [manifest.json](manifest.json)을 따른다.

희귀 쓰레기는 같은 배치의 희귀 물고기보다 낮은 가격으로 책정했다. 기존 희귀 최저가보다 낮은 공통종을 추가하려는 요청을 반영한 값이다. 인형은 바닥 고정, 물고기는 개체별 깊이에서 이동하며 오른쪽을 향한 원화를 진행 방향에 맞춰 뒤집는다.

`sources/*.source`는 생성 도구의 원본 PNG 바이트다. `prepare-assets.mjs`는 썸네일에 투명 여백만 추가하며, `align-sprites.mjs`는 실제 눈·볼 기준점 측정 결과로 전체 셀을 정수 이동한다. 원본 픽셀을 재도색하거나 프레임마다 크기를 바꾸지 않는다. 기준점 설정·측정 JSON과 원본·최종 투명도 감사 결과를 함께 보존한다.

업로드는 저장소 루트에서 `node assets/storage-upload/new/20261103-151800/upload.mjs --dry-run`으로 먼저 확인한다. 실제 업로드는 같은 명령에서 `--dry-run`을 제거한다. 이 명령은 최종 9개 이미지만 별도 staging에 복사하므로 원본·가이드·검토용 시트를 업로드하지 않는다. 업로드 뒤 공개 URL의 바이트 해시와 manifest를 비교한다. 카탈로그는 별도 CLI migration으로 적용하며 이미지 업로드만으로 등록되지 않는다.

실제 어항과 도감 미리보기로 DPR 1·2·3 및 모션 감소를 확인했다. 밝고 어두운 배경의 외곽, 네 프레임 반복 경계, 실제 표시 크기를 함께 검토한다. 회귀 검증은 `tests/cute-shared-species*.test.ts`, 전체 카탈로그 검증은 `npm run db:verify`를 사용한다.
