# 농장 체험판 가공품·건물 이미지

빠르게 생산·가공·판매 흐름을 체험하기 위한 정적 이미지 배치다. 기존 밀·작물과 종자 상점 그림을 스타일 참고로 사용하고, 새 식품과 건물마다 기능을 알아볼 수 있는 형태를 부여한다. 정확한 프롬프트·참고 역할·원본·최종 해시는 `manifest.json`이 원본이다. 기존 작물과 종자 상점·판매소·연구소 이미지는 앞선 배치를 유지한다.

원본 PNG 바이트는 `sources/*-thumbnail.source`에 보존한다. 식품은 256px, 건물은 512px로 전체 캔버스를 같은 비율로 축소하며 알파나 여백을 임의로 깎지 않는다. 저장소 루트에서 `node assets/storage-upload/new/20261103-173500/prepare.mjs`로 최종 PNG와 `public/farm/art/v1/`의 정적 사본을 다시 만든다. 이 작업은 운영 DB·Storage를 변경하지 않는다.

원본과 최종본은 `scripts/audit-collectible-images.mjs`로 각각 검사하고, 최종 검사에는 `--final`을 추가한다. 밝고 어두운 접촉 시트와 실제 모바일 화면에서 외곽·표시 크기를 함께 확인한다.

체험판 레시피는 `food-catalog.ts`가 원본이다. 재료는 제작 시작 시 한 번 차감하고, 작업은 건물별로 보관하며 완성품 수령 시 한 번 지급한다. 다른 시설에서 제작하거나 재료가 부족한 요청은 일부 재료도 차감하지 않아야 한다. 미수령 작업이 있는 건물은 회수할 수 없다. `tests/farm-processing*.test.*`에서 이 조건과 원재료·가공품 판매소 구분을 검증한다.
