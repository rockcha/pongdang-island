# 실용적인 농장 건물 외형

사용자 수정에 따라 기와와 장식적인 상점 외형을 실제 농장 시설의 구조·재료로 교체한다. 금속 판 지붕, 단순 목조 골조, 축사 문과 경사로, 벽돌 화덕, 천막 판매대 등 기능에 맞는 형태를 사용한다. 작은 정사각형 타일 배치와 위에서 내려다보는 카메라를 유지하며, 건물마다 장식만 바꾼 같은 집을 반복하지 않는다.

`manifest.json`은 정확한 프롬프트·원본·참고 역할·최종 해시를 보존한다. 외양간을 먼저 검토해 공통 시점과 재질 기준을 정하고, 나머지는 개별 건물 용도에 맞게 생성한다. 기존 기와 건물을 스타일 참고로 사용하지 않는다. 원본 PNG 바이트는 `sources/*-thumbnail.source`에 있다. 최종 파일은 전체 캔버스를 같은 비율로 512px로 축소하고 알파와 여백을 유지한다.

저장소 루트에서 `node assets/storage-upload/new/20261103-174500/prepare.mjs`로 최종 PNG와 `public/farm/art/v2/buildings/` 사본을 다시 만든다. 화면은 `building-art.ts`의 명시적인 버전 선택을 사용한다. 과거 생성 원본은 검증 자료로 유지하지만 새 화면의 오류 대체 이미지로 사용하지 않는다. 이미 천막 판매대·유리 온실인 그림은 기존 버전을 유지한다.

원본과 최종 파일 각각 `scripts/audit-collectible-images.mjs`로 알파·여백을 검사하고 최종 검사에는 `--final`을 추가한다. 밝고 어두운 접촉 시트와 모바일 지도·건물 모달·편집 팔레트를 함께 검토한다. 변경 범위는 정적 외형이며 생산 규칙·골드·배치 크기·운영 DB를 변경하지 않는다.
