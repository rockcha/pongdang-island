# 정면 비중을 높인 농장 건물

사용자가 승인한 농장 그림체·재료·색감을 유지하면서 지붕보다 정면 출입구와 작업 공간이 잘 보이도록 편집한 배치다. 각 건물의 기존 그림을 편집 대상으로 전달한다. 작은 지도에서도 구별되도록 종자 진열대·사료 보관소·화덕·유제품 작업대 등의 전면 특징을 강조한다.

종자 연구소는 현미경·종자 샘플병·발아 실험대를 통해 연구 시설로 읽혀야 한다. 외양간과 닭장의 동물은 건물 내부에 살짝 보이는 정적인 그림이며 실제 축산 개체나 보유 수량을 추가하지 않는다. 단순 금속 지붕과 농장 구조를 유지하며 기와·장식적인 처마를 다시 도입하지 않는다.

정확한 편집 프롬프트·대상 경로·원본·해시는 `manifest.json`에 보존한다. 생성 원본 PNG 바이트는 `sources/*-thumbnail.source`에 있다. 전체를 같은 비율로 512px로 축소한 뒤 모든 비투명 픽셀을 보존하는 범위에서 통째로 정수 이동해 바닥 위치를 보정한다. 보이는 픽셀을 자르거나 건물별 비율을 늘리지 않으며, 실제 이동량과 도달한 기준선은 manifest에 기록한다. 저장소 루트에서 `node assets/storage-upload/new/20261103-180113/prepare.mjs`로 최종 PNG와 `public/farm/art/v3/buildings/` 사본을 다시 만든다.

원본과 최종 파일 각각 `scripts/audit-collectible-images.mjs`로 검사하고 최종 검사에는 `--final`을 추가한다. 밝고 어두운 접촉 시트로 정면 비율·특징·투명 외곽을 검토한 뒤 실제 지도·모달·편집 목록과 모바일 표시 크기를 확인한다. 배치 크기와 생산·거래 규칙은 변경하지 않는다.
