# 한 칸에 한 작물 농장 이미지

로컬 농장 UI 전용이며 DB 개체·판매가·이동 시스템 및 원격 업로드와 무관하다. 빈 밭 원본은 이전 배치에서 재사용한다. 나머지는 built-in image_gen으로 생성한 한 개체 중심 이미지이며 참고 역할과 최종 프롬프트는 manifest.json에 보존한다.

공통 단계는 빈 밭·심은 직후·긴 줄기 세 장이다. 성장 50%부터 공통 줄기, 100%부터 작물별 완성 이미지를 사용한다. 한 칸에서는 하나의 큰 식물만 보여주며 실제 수확 수량도 한 개로 유지한다.

밭 간격을 좁히기 위해 prepare.mjs가 모든 원본에 동일한 가시 알파 합집합 영역과 사각 칸 맞춤을 적용한다. 최종 PNG는 512px에 바깥 여백 4px로 만든다. 단계별 자동 확대·위치 조정은 하지 않는다. 원본은 sources/*-generated.source에 별도 보존한다.

재현: node assets/storage-upload/new/20261103-231501/prepare.mjs

검증: 원본 정규화·최종 이미지의 투명 여백 검사, 밝은/어두운 배경 검토, 실제 밭의 0%·50%·100% 전환과 모든 작물의 수령 준비 화면 확인.
