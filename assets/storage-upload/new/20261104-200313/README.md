# 공통 장식물 제작 배치

일반·희귀는 퐁이 카툰풍, 특급은 부드러운 판타지 일러스트풍으로 개별 생성한다. 정적 고정 장식물이며 생물처럼 이동하지 않는다. 이동·높이·가격·참고 역할·개별 프롬프트와 최종 이미지 경로는 manifest가 원본이다.

생성 원본은 sources/*.source에 보존하고 업로드하지 않는다. 최종 PNG만 decorations/<등급>/ 아래에 두며 파일명 버전은 재사용하지 않는다. 새 개체 평균 판매가는 일반 40·희귀 150·특급 800골드이며 기존 개체 가격은 바꾸지 않는다.

node scripts/prepare-shared-decorations.mjs <이 배치 경로>로 정규화한 뒤 이미지 감사 스크립트 --final과 밝고 어두운 접촉 시트를 확인한다. --metadata-only는 업로드 도구의 무손실 PNG 최적화 후 해시를 갱신하며 이미지를 다시 생성하지 않는다.

카탈로그 원본 편집 후 CLI로 만든 빈 migration에 db:catalog --table collectible_species와 개별 --id를 전달한다. 새 종만 적용하며 공통 서식지는 현재 등록된 모든 해역에 명시한다. 운영 적용 여부는 실제 원격 재조회로 확인한다.
