# 은하수의 끝자락 제작

사용자 지정 개체의 기획 입력은 `scripts/prepare-galaxy-assets.mjs`, 배경 입력은 `scripts/galaxy-scene-specs.mjs`에 보존한다. 이 배치의 manifest는 생성 도구, 입력 참고 이미지, 실제 프롬프트와 파일 해시를 기록한다. 가격의 출시 원본은 검수 후 등록하는 카탈로그다.

일반·희귀는 기존 퐁이 카툰 참고의 채색을, 특급·신화는 판타지 일러스트 참고의 재질과 빛을 따른다. 참고 동물의 해부 구조를 다른 종에 복제하지 않는다. 신화 건축물 두 종은 사용자 분류대로 어종을 유지하되 바닥 가까이에 고정하고 전용 8프레임 동작을 사용한다.

스프라이트는 확정 썸네일과 배치 가이드로 생성한다. 가이드의 복제 이미지는 동작 산출물이 아니다. 셀 중앙 60%로 생성해 특수 동작과 행성 궤도에 여백을 확보한 뒤, 원본 여백 검사·단단한 기준점 등록·최종 PNG 정렬·실제 크기 반복 재생을 검수한다. 프레임별 확대나 투명도 변경으로 동작을 대신하지 않는다.

`sources/`는 보정 전 생성본이다. 업로드에는 검수된 최종 PNG만 사용한다. 전체 이미지와 정렬 검수가 끝나기 전에는 카탈로그 등록 스크립트가 중단된다. 원격 등록 전 공개 다운로드 해시를 확인하고, 등록 후 개체 수·가격 평균·지도 조각 등급·어항 테마 구매를 다시 확인한다. 로컬 생성 완료와 운영 출시 완료를 구분한다.
