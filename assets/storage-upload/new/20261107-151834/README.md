# 네온 심해도시 시안

사용자 첨부 콘셉트를 바탕으로 만든 지도·낚시터 분위기 검토용 이미지입니다. 지도는 기존 해역의 양피지 해도 형식, 낚시터는 상단 도시와 하단 열린 수면 구도를 기준으로 제작합니다.

생성 도구는 내장 image_gen입니다. 정확한 프롬프트와 직접 전달한 참고 이미지 경로는 manifest.json에 기록합니다. sources/에는 생성 원본을 보존합니다.

실제 게임 연결·Storage 업로드·해역 및 개체 등록·배포는 포함하지 않습니다. 채택 후 낚시 장면의 수면 및 발판 레이어와 모바일 크롭을 별도로 맞춰야 합니다.
