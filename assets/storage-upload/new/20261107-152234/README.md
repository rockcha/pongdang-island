# 네온 심해도시 어종 썸네일 시안

내장 image_gen으로 생성한 데이터의 신, 아카이브(신화)와 오류의 문어(희귀)의 정적 썸네일입니다. 공통 색감은 짙은 남색·먹청색 몸체, 청록 발광, 소량의 자홍·보라 포인트입니다. 각 등급의 기존 그림체 참고와 해역 지도를 역할을 나눠 전달합니다. 정확한 프롬프트·입력 경로·생성 원본·해시는 manifest.json에 기록합니다.

아카이브는 넓은 머리와 두꺼운 몸통의 고래상어 구조, 문어는 여덟 팔과 팔별 홀로그램을 기준으로 검수합니다. 두 이미지의 원본 진행 방향은 오른쪽입니다.

이동 기획은 아카이브가 중층을 천천히 유영하는 swim(높이 0.25–0.70), 문어는 홀로그램을 조작하며 중하층을 유영하는 swim(높이 0.20–0.55)입니다. 문어는 바닥 보행 개체로 기획한 것이 아니므로 crawl 대신 유영을 선택했습니다. 둘 다 travel_direction=both, flip_with_direction=true를 의도합니다. 실제 카탈로그 값은 등록 단계에서 어항 좌표 해석에 맞춰 확정합니다.

이번 요청은 외형 시안만 포함합니다. 판매가는 미정이며 카탈로그 등록·스프라이트 제작·원격 적용·배포는 하지 않습니다. 채택 후 신화 8프레임·희귀 4프레임의 움직임과 실제 어항 배치를 별도로 검증합니다.
