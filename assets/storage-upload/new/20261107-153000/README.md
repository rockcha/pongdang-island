# 홀로그램 심해도시

이 배치는 사용자 요청에 따라 제작한 신규 해역의 원본과 검수 자료입니다. 기본 색감은 짙은 남색·먹청색, 주 발광은 청록색, 변주는 소량의 자홍·보라색입니다. 등급별 그림체 참고와 해역 팔레트 참고를 구분해 전달합니다. 개체별 구조·이동 방식·가격의 원본은 scripts/prepare-hologram-assets.mjs이며 specification.json은 그 생성 결과입니다.

정확한 프롬프트·직접 전달한 참고 이미지·생성 원본 경로·파일 해시는 manifest.json에 보존합니다. sources/의 원본은 교체하거나 잘라서 여백 검사를 통과시키지 않습니다. guides/는 배치 참고이며 정지 썸네일을 반복한 가이드를 최종 애니메이션으로 쓰지 않습니다.

썸네일을 검토한 뒤 어종별 신체 구조에 맞는 동작을 생성합니다. 일반·희귀·특급은 4프레임, 신화는 8프레임이며 신화의 뒤 4프레임에는 고유 추가 행동을 둡니다. 원본의 경계·방향·동일성을 먼저 검수하고, 불투명한 머리나 몸통의 패치를 실제 그림에서 확인한 다음 정합합니다. 역방향 정수 이동과 동일 여백을 최종 PNG에 반영하며 모든 픽셀을 보존합니다. 실패한 정합을 기본 0 이동으로 대체하지 않습니다.

scripts/register-hologram-catalog.mjs는 에셋 누락이나 검수 전 상태에서는 등록을 중단합니다. 완료 후 카탈로그 원본을 변경하고 Supabase CLI migration new → db:catalog → db:context → db:verify 순서로 로컬 기대 상태를 검증합니다. 원격에는 자동 적용하지 않습니다. 실제 출시 때 species-releases.json의 시각을 확정하며 제작 시점을 출시 시각으로 쓰지 않습니다.

등록 후에는 지도 조각별 등급·해역 진입·낚시 배경·낚싯대·어항 동작을 데스크톱과 모바일에서 검증합니다. Storage 업로드·서버 적용·프론트엔드 배포는 별도 출시 단계입니다. 현재 원격 상태는 이 문서가 아닌 해당 작업의 새 조회로 확인합니다.

원본·검수용 PNG와 제외된 미출시 시안도 보존하므로 폴더 전체를 재귀 업로드하지 않습니다. scripts/publish-hologram-assets.mjs는 현재 구성의 경로와 해시를 검증해 게시 대상을 한정합니다. 기본 실행과 --dry-run은 업로드하지 않으며 실제 게시에는 --upload를 명시합니다. 제외된 초안 ID를 원격 플레이어 데이터의 삭제나 퇴역으로 해석하지 않습니다.
