# 날씨 장식물 애니메이션

사용자가 선택한 5종을 특급 장식물로 제작했다. 가격은 사용자 지정값을 따르며, 날씨 정령과 별도로 기존 날씨 개체와 같은 상대 가중치를 사용한다. 카탈로그 원본과 배치 manifest가 값의 기준이다.

몸체를 이동시키지 않는 `fixed` 장식물이다. 프레임마다 빗방울·눈과 발자국·천칭 접시·태엽과 별자리·분사구의 꽃이 움직인다. 어항과 도감은 공통 프레임 선택과 정렬 정보를 사용하며 편집 중과 모션 감소에서는 첫 프레임을 유지한다. 향수병의 꽃은 역순 복귀를 포함해 자연스럽게 닫힌다.

`image_gen.imagegen` 기본 도구로 썸네일과 2×2 스프라이트를 별도로 생성했다. 스타일·동일성·배치 참고 역할과 최종 프롬프트는 `manifest.json`에 있다. 원본은 `sources/`, 최종 PNG는 `decorations/epic/`에 보존한다. 모서리까지 완전한 원본을 사용했으며 천칭과 태엽의 가동부 여백을 확보했다. 원본 셀의 모든 방향에 최소 7%의 여백을 확인하고, 최종 PNG에는 불투명 받침/테두리 패치의 정수 위치 보정을 반영했다. 프레임마다 배율·원근·전체 불투명도를 바꾸지 않았다.

`audit.json`과 `final-audit.json`은 원본/최종 검사를 구분한다. `registered-final-4.json`의 위치 잔차는 0이며 `registration.json`에서 RGBA 보존을 확인한다. `review/browser-check.json`은 실제 도감과 Phaser 어항의 로컬 검증이다. `review/animated-preview.html`과 WebP는 공유용 반복 미리보기이며 런타임은 PNG 시트를 사용한다.

현재 로컬 검증 상태이며 원격 카탈로그·Storage·운영 앱에는 적용하지 않았다. 출시 시에는 앞선 날씨 가중치 및 요정 migration 다음에 이 장식물의 CLI migration을 적용하고, 실제 출시 시각으로 신규 개체 목록을 등록한다. 과거 baseline/SQL을 재실행하지 않는다. 앱에는 검수한 이미지 10개가 함께 포함되며, Storage 업로드 시 `sources/`와 `review/`를 제외한 최종 PNG만 임시 배치에 담고 공개 다운로드 해시를 대조한다.

재검증은 원본/최종 이미지 audit, `weather-decorations`·날씨 SQL·미리보기·공통 장식물 테스트, `db:verify`, `client-data:check`, 앱 빌드를 사용한다.
