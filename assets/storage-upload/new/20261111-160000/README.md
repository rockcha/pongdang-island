# 펫 하우스 캐릭터 확장

기존 펫 그림체를 참고해 built-in image_gen으로 만든 운영자 미리보기용 캐릭터다. 실제 획득·보상이나 운영 DB 카탈로그를 변경하지 않는다. 이동은 펫 하우스의 고정된 자리에서만 표현하며 어항 이동 설정을 사용하지 않는다.

원본·프롬프트·최종 파일 해시는 manifest.json에 보존한다. 동일한 배율로 셀을 추출하고 투명 여백을 추가한다. 프레임마다 크기를 달리하거나 캐릭터의 몸 전체를 흔들지 않는다. 이미지 수정은 image_gen에서 수행했으며 준비 스크립트는 배경 제거·알파 임계값 처리를 하지 않는다.

좌우 보정은 얼굴의 불투명한 고정 패치를 기준으로 한다. 꼬리·귀·손을 포함한 전체 실루엣 중심으로 정렬하면 동작에 따라 몸이 흔들리므로 사용하지 않는다. horizontal-registration.json에 실제 원본 해시·패치·프레임별 매칭 결과를 보존하며, 이미지 교체 시 `node scripts/register-pet-horizontal.mjs`로 다시 검증한다. 텍스처가 없거나 투명한 패치, 검색 경계에 걸린 결과는 실패 처리한다. 런타임에서는 평행 이동만 적용하고 기존 발밑·배율과 눈 깜빡임의 눈 패치 위치를 함께 유지한다.

idle은 전체 스프라이트 교체를 하지 않는다. 일반·배고픔·애정 부족 각각의 기본 몸 그림을 유지하고, resting-eye-registration.json의 눈 영역만 합성한다. 좌표를 맞춰도 프레임마다 털·몸통 윤곽이 달라지는 문제를 막기 위한 조건이다. 이미지 교체 후 `node scripts/register-pet-resting-eyes.mjs`로 눈 영역을 다시 확인한다. 회귀 검사는 깜빡임 중 몸의 원본 프레임과 그리기 좌표가 동일한지 확인해야 하며, 얼굴 기준점의 숫자가 같다는 것만으로 통과시키지 않는다.

재현: `node scripts/prepare-pet-expansion.mjs assets/storage-upload/new/20261111-160000/manifest.json`. 실제 앱 파일은 public/pets에 저장하며 Storage 업로드 대상이 아니다. resting 감정마다 전용 눈 깜빡임 행을 쓰고 먹기·만족 모션과 동일한 좌표계로 그린다.

확인: `tests/pet-expansion.test.ts`와 기존 펫 회귀 검사를 실행한다. review.png는 밝고 어두운 배경의 감정 비교이며 browser-review는 실제 모바일·PC 화면 확인 자료다. 운영 배포를 증명하는 자료는 아니다.
