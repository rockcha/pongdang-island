# 펫 하우스 배경

built-in image_gen으로 전체 방을 생성한 뒤 같은 그림에서 빈 방과 투명 방석을 각각 편집했다. 최종 프롬프트·생성 원본·파일 해시는 manifest.json에 남긴다. public/pets/house의 WebP를 앱에서 사용하며 Storage 업로드나 DB 변경은 필요하지 않다.

방은 카드 내부의 장식 배경이고 방석은 별도 절대 위치 레이어다. 방석 위치는 펫의 고정된 발밑 기준점을 따르며 표정·상호작용·텍스트에 따라 달라지면 안 된다. 방석 여백 자르기와 WebP 변환 외의 배경 제거는 image_gen에서 수행했다.

작은 모바일과 PC, 발밑 높이와 실루엣이 다른 펫에서 방석이 잘리지 않는지 확인한다. 방석은 장식 이미지이므로 접근성 이미지 목록과 레이아웃에 영향을 주지 않는다.
