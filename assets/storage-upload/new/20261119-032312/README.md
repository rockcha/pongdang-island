# 퐁순이의 러브레터

검수한 분홍 포구의 낚시터·지도·아이콘과 어종·쓰레기·장식물을 한 해역으로 연결한다. 지도의 조각 등급은 일반·희귀·특급 각 2개다. 판매가는 직전 운영 해역의 같은 종류·등급 평균에 5골드를 더한 값에 맞춰 정수로 분배한다.

특급·신화에는 판타지 채색을 사용하며 퐁이의 주황 불가사리핀과 퐁순이의 하늘색 조개핀을 캐릭터 기준으로 삼는다. 그림과 동작 프롬프트는 manifest에 기록한다. 신규 신화는 4×2 시트를 사용하며 구형 클라이언트가 읽는 Storage 시트는 앞의 네 장을 2×2에 배치한다.

업로드 전 원본과 최종 PNG의 알파와 프레임 경계를 검사한다. 공개 응답의 SHA-256으로 업로드된 바이트를 대조한 뒤 프런트엔드와 해역 전용 마이그레이션을 반영한다.
