# 오락실 공통 게임 UI

모든 신규 게임과 기존 오락실 게임에 적용합니다.

## 페이지 구조

공통 헤더 빠른 내비게이션 → 오락실 배너 → 공통 탭 → 게임 보드 순서입니다. 목록으로 버튼·햄버거·드로어와 중복 제목을 두지 않습니다. 게임 페이지는 100dvh 안에서 flex/min-height:0으로 배치합니다. 보드·이미지를 남은 공간에 맞춰 줄이며 페이지 전체와 게임 플레이 패널은 스크롤하지 않습니다. 랭킹 패널 내부만 세로 스크롤합니다. 게임 시작 전에는 탭과 모드 선택을 보여주고, 실전·연습·모션 테스트는 공통 GameModal에서 진행합니다. 게임 모달은 배경 입력을 차단합니다. 서버 제한 시간은 확인 모달을 열어도 계속 흐릅니다.

배너를 삭제하거나 얇게 잘라 숨기지 않습니다. 게임 화면에서는 80~128px 범위로 높이를 맞추고 object-contain으로 전체 그림을 보존합니다. 제목만 겹치며 소개 문구는 생략해 높이를 확보합니다. 일반 장소 배너의 표시 방식은 유지합니다.

개별 게임 배너에는 **오락실 › 게임 이름** 경로를 표시하고 오락실은 목록으로 연결합니다. 배너 오른쪽에 게임 포스터를 추가하지 않습니다. 포스터는 게임 목록과 시작 전 보드 오버레이에서만 사용하며, 게임 보드 위에 제목을 다시 나열하지 않습니다. 게임별 제한시간은 서버·연습 엔진·화면 게이지를 함께 맞춥니다. 그림자 맞추기는 문제당 **8초**입니다.

## 공통 컴포넌트

`src/features/arcade/game-controls.tsx`:

- GameTabs: 게임패드 아이콘 + **게임 플레이**, 트로피 아이콘 + **랭킹**. 두 게임이 같은 크기·색·활성 상태를 사용합니다. 방향키·탭 키와 aria-selected/controls를 지원합니다.
- GameStartOverlay: 포스터 위에 제목과 짧은 설명을, 하단에 **실전 (금화 이미지 + 참가비)**·**연습**을 배치합니다. 벽돌깨기는 **모션 테스트**를 추가합니다. 실전은 공통 참가 확인 모달을 거칩니다.
- GameModal: 시작 전 DOM을 유지하면서 플레이 시 native dialog의 top layer로 전환합니다. 모달 내부의 퐁이 확인창은 같은 dialog에 portal을 붙여 가려지지 않게 합니다. 가드 취소는 재개, 나가기는 게임별 정리·정산 성공 뒤 복귀합니다.

시작 전 보드 대신 포스터를 보여주고 보드 입력은 막습니다. 실제 플레이 중에는 오버레이를 제거합니다. 모드 선택을 보드 아래 별도 영역에 중복 배치하지 않습니다. 데이터 로드·요청 잠금·골드 부족은 버튼 disabled로 반영하며 무료 연습은 골드 잔액에 영향을 받지 않습니다. “최대 100점·서버 기록 등록”, “12짝·가운데 퐁이” 같은 상시 안내는 화면에서 생략하고 규칙 문서에 둡니다. 짝맞추기 경과 시간은 플레이 중 시계 아이콘과 24px 숫자로 명확히 표시합니다.

## 플레이 이탈 보호

실전·연습 모두 진행 중에는 목록·다른 장소·프로그램 이동·브라우저 뒤로가기/앞으로가기를 공통 GameLeaveGuard 확인 모달로 보호합니다. 취소하면 그대로 플레이하고 확인하면 이동합니다. 실전 게임은 서버에서 재접속할 수 있지만 경과 시간은 계속 흐르며 연습 진행은 페이지를 떠나면 사라집니다. 아직 시작하지 않았거나 완료한 경우에는 막지 않습니다. 새로고침·탭 닫기는 beforeunload의 브라우저 기본 경고를 사용합니다(브라우저 정책상 맞춤 모달로 바꿀 수 없음). App의 data router가 useBlocker를 지원합니다. 탭 전환은 페이지 이탈이 아니므로 가드하지 않습니다.

## 목록과 태그

오락실 목록 카드는 썸네일이 왼쪽 약 36%와 카드 세로 전체를 채우는 형태입니다. 작은 독립 아이콘처럼 축소하지 않습니다. 썸네일은 object-cover, 오른쪽은 제목·태그·짧은 소개·참가 조건으로 구성합니다. 제목은 font-normal, 얇은 베이지 테두리와 작은 모서리 곡률을 사용합니다.

게임 분류는 `games.ts`의 tags 배열로 관리합니다. memory → 기억력, reasoning → 추리력, luck → 운. 카드 짝맞추기는 기억력, 그림자 맞추기는 추리력, 홀짝 조개는 운입니다. 분류 키와 한글 표시를 분리해 향후 목록 필터에 같은 값을 사용합니다. 현재는 태그 표시만 하며 필터 기능은 추가하지 않았습니다. 정산형 게임과 즉시 지급형 게임의 보상 정책은 각 게임 서버에서 처리합니다.

레이아웃 변경으로 참가비·시간·점수·기록 정책을 변경하지 않습니다. 게임 엔진과 서버 규칙은 각 시스템 문서를 따릅니다.

## 넓고 낮은 화면

보드 논리 좌표와 난이도를 화면 비율에 맞춰 바꾸지 않습니다. 물리 게임은 고정 보드를 contain으로 맞추고 남는 공간은 여백으로 둡니다. 낮은 가로 화면에서는 상태·조작을 옆으로 옮겨 보드의 세로 공간을 확보합니다. 작은 화면은 안전 영역을 포함한 전체 화면을 쓰며, 모달 바깥 페이지를 스크롤하지 않습니다. 모션 테스트 선택 목록과 랭킹만 내부 스크롤을 허용합니다. 화면 크기별 보드 비율·주요 버튼 노출·뒤로가기 후 가드·취소 후 입력 복구를 검증합니다.
