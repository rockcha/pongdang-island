# 해역 콘셉트와 변경 조건

해역의 가격·순서·개체 수·서식지·동작 값은 카탈로그와 관련 코드에서 확인합니다. 실제 적용 상태는 작업 시 원격 조회로 확인합니다. 이 문서는 시각적 의도와 변경 시 보존할 조건만 다룹니다. DB 변경은 [DB 관리](../systems/database-management.md), 이미지 작업은 [에셋 기준](../../assets/README.md)을 따릅니다.

## 태고의 원시섬

공룡 시대의 고사리 정글·화산·호박빛 안개와 청록빛 바다를 기준으로 풍경·지도·배너·장비를 같은 팔레트로 구성합니다. 장비는 나무 몸체·화석 마디·호박 릴·호박 속 고사리 찌로 표현하며 기존 휘어짐·회전·게이지 동작을 보존합니다. 다른 지역 생물을 임의로 복사해 채우지 않습니다.

## 백야의 빙해

밝은 극지 하늘·청록 빙벽·은빛 눈꽃 장비·얼음 발판을 하나의 시각 언어로 구성합니다. 지도는 빙하가 그려진 두루마리입니다. 다른 해역 전용 개체나 원시섬 개체를 가져오지 않습니다.

서식지 확장 시 기존 토착 지정을 보존합니다. 실제 대상 DB에서 토착 해역이 없는 공통 개체인지 확인한 뒤 확장하며, 퐁당 전용 개체를 공통 개체로 바꾸거나 기존 서식지를 일괄 삭제하지 않습니다.

## 지브리의 구름나루

초록 섬·낮게 흐르는 구름·청록 바다·작은 나루를 손그림 애니메이션과 수채화 질감으로 표현합니다. 왼쪽 먼 물가의 붉은 목욕탕과 오른쪽 언덕의 움직이는 성을 유지하며 낚시 배경에서는 두 건물을 수평선 쪽에 두어 조작 영역을 비웁니다.

장비는 대나무·초록 바인딩·구름 릴·청록 찌를 사용합니다. 토토로 석상 아이콘과 토토로 모양 목제 찌는 같은 모티브를 유지하되 찌의 위치·회전·판정을 바꾸지 않습니다. 지도에는 풍경·목욕탕·성·항로를 보존하면서 작은 캐릭터 카메오를 배치합니다.

공통 개체와 해당 해역 전용 개체를 함께 배치하며 다른 해역 전용 개체를 가져오지 않습니다. 실제 토착 지정 차이를 존중합니다. 시트는 동일 프레이밍과 고정 몸통 등록을 유지합니다.

원본·프롬프트·검수 근거는 [해역 배치](../../assets/storage-upload/new/cloudferry/), [개체 배치](../../assets/storage-upload/new/20261017-175022/)에서 확인합니다.

## 녹빛 고물섬

떠다니는 쓰레기·바닥에 놓이는 장식품·고철 환경의 생물로 구분합니다. 무생물에 얼굴을 억지로 넣지 않습니다. 그린아크는 평상시 선체를 유지하며 크레인으로 빛나는 고물을 건져 올립니다. 회전 크로스페이드나 몸통 확대 효과는 사용하지 않습니다.

낚시는 등급 선택 후 해당 등급 안에서 물건을 우선하는 두 단계 의도를 유지합니다. 선택한 종류가 없으면 같은 등급의 존재하는 종류로 대체하고 장식품 전용 미끼는 장식품만 추첨합니다. 다른 해역 규칙을 바꾸지 않으며 실패를 쓰레기 지급으로 바꾸지 않습니다. 구체적인 비율은 관련 함수와 테스트에서 확인합니다.

이미지·프롬프트·검수 근거는 [고철섬 배치](../../assets/storage-upload/new/20261017-183433/)에서 확인합니다.
