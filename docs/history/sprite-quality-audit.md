## 바다악어 원본 확인

`assets/storage-upload/new/20261015-124837/fish/rare/sea-crocodile_sprite.png`와 대응 썸네일을 실제로 열어 확인했습니다. 시트는 1254×1254이고 프레임은 627×627입니다. 파일 해상도 부족을 우선 원인으로 볼 증거는 없습니다. 그림이 프레임에서 작고, 몸통이 가늘며 세밀한 비늘 무늬가 많아 게임에서 축소될 때 디테일이 줄어드는 쪽이 우선 점검 대상입니다. 전체 네 프레임과 썸네일이 왼쪽을 향하는 기존 원본입니다.

재작업 시 긴 축의 여백을 줄이고 머리·몸통 기준점을 고정합니다. 현재 폭 점유율을 80~88% 수준으로 만들면 size 88에서 보이는 폭은 약 70~77px가 됩니다. 프레임을 개별 확대하지 않고 전체 동작 범위에 같은 배율을 적용해야 합니다. 오른쪽 원본으로 교체할 경우 기존 방향 보정도 함께 갱신해야 합니다.

## 확인 범위

악어·복어·오로라장어의 원본 시트를 시각 확인했고 68개 로컬 시트의 점유율을 수치로 검사했습니다. 다른 개체의 원본 선명도까지 일괄 판정하지 않았습니다. Storage 파일, 현재 DB의 size, 실제 모바일 캔버스와 DPR은 이번 점검에서 검증하지 않았습니다. 이미지는 아직 재생성·교체·업로드하지 않았습니다.
