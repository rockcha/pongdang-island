# 아쿠아리움 테마 등급과 기획 기준

등급은 화면의 구성과 디테일을 구분한다. 비싸거나 화려하다는 이유만으로 등급을 올리지 않는다. 심플도 완성도 높은 배경이며, 스페셜도 물고기를 가릴 만큼 복잡하게 만들지 않는다.

## 심플

**물빛과 여백만으로 분위기가 완성되는 테마.**

물의 색, 부드러운 빛줄기, 잔잔한 수면, 단순한 바닥이 중심이다. 가장자리의 작은 산호나 풀처럼 가벼운 장식은 허용한다. 건물이나 가구 없이도 성립해야 한다. 기존 카탈로그의 **맑은 물빛·산호 정원**을 기준으로 삼는다.

추천 기획:

| 테마 | 구성 |
| --- | --- |
| 우윳빛 새벽 | 옅은 크림빛 물과 흐릿한 아침 햇살 |
| 민트빛 잔물결 | 투명한 민트색 물과 얇은 수면 반사 |
| 복숭아 물안개 | 살구색에서 연분홍으로 번지는 물빛 |
| 청보라 밤물결 | 짙은 청보라 물과 적은 수의 작은 빛점 |
| 하얀 모래 여울 | 밝은 모래 바닥과 맑은 하늘색 물 |
| 은빛 달무리 | 은회색 물과 넓고 희미한 달빛 한 줄기 |

## 감성

**심플한 물 공간에 자연 요소와 계절감이 더해진 테마.**

나뭇잎·갈대·꽃잎·얼음·구름·오로라처럼 분위기를 설명하는 요소를 제한적으로 넣는다. 물고기가 주인공이고, 풍경은 둘레에서 분위기를 만든다. 전체 공간이 상점이나 방처럼 꾸며지면 스페셜로 분류한다. 사용자가 말한 가을 정원 계열은 현재 카탈로그의 **가을이 잠긴 연못**을 감성 기준으로 사용한다.

추천 기획:

| 테마 | 구성 |
| --- | --- |
| 반딧불 갈대습지 | 하단의 갈대 실루엣과 드문 금빛 반딧불 |
| 벚꽃이 고인 연못 | 상단 모서리의 벚꽃 가지와 소량의 떠 있는 꽃잎 |
| 수련이 잠든 밤 | 가장자리의 넓은 수련잎과 차분한 푸른 달빛 |
| 비 개인 수국길 | 바깥쪽의 연보라 수국 덩어리와 촉촉한 아침빛 |
| 단풍 비치는 물가 | 물에 비친 붉은 단풍과 하단의 작은 낙엽 무리 |
| 눈꽃 자작나무숲 | 먼 배경의 옅은 자작나무 실루엣과 은은한 눈빛 |

## 스페셜

**방·가게·정류장처럼 장소와 이야기가 보이는 테마.**

최근 제작한 우체국·오락실·음악실·꽃시장·보물창고·다락방·세탁소·항구가 기준이다. 대표 소품 몇 묶음과 구조물로 장소를 표현한다. **심해 우체국 정도의 디테일은 적절하며, 그보다 소품을 더 빽빽하게 채우는 방향은 피한다.** 모든 곳을 잔무늬·금속 장식·작은 물건으로 메우지 않는다.

추천 기획:

| 테마 | 구성 |
| --- | --- |
| 해저 찻집 | 모서리의 작은 찻상, 주전자와 찻잔, 따뜻한 등 하나 |
| 잠수함 관측실 | 둥근 관측창과 양옆의 단순한 계기판 |
| 별가루 시계방 | 가장자리의 큰 시계 두 개와 작은 수리 작업대 |
| 산호 재봉실 | 조개 재봉틀, 접힌 천, 짧은 리본 몇 가닥 |
| 달빛 유리공방 | 작업대와 큼직한 유리병 몇 개, 푸른 화로빛 |
| 바닷속 작은 영화관 | 양옆의 커튼, 하단 모서리의 좌석, 먼 곳의 희미한 스크린 |

## 등급을 수정할 때

실제 배정의 원본은 [catalog.json](../../supabase/catalog/catalog.json)의 `aquarium_backgrounds[].tier`다. `simple`은 심플, `mood`는 감성, `special`은 스페셜이다. 문서의 추천 목록은 등급별 기획 예시다. 제작·등록 여부와 운영 가격은 카탈로그에서 확인하며 이 문서에 중복 관리하지 않는다.

등급은 이름보다 실제 이미지를 보고 결정한다. 산호가 몇 개 있다고 감성으로 올리거나, 가격이 높다고 스페셜로 올리지 않는다. 애매하면 여백과 단순한 물빛이 중심인지, 자연 풍경이 중심인지, 꾸며진 장소가 중심인지로 판단한다. 가격·기존 보유권·장착 상태는 등급 수정만으로 바꾸지 않는다.

원본 수정 후에는 [DB 관리 절차](database-management.md)에 따라 CLI migration 생성 → 카탈로그 SQL 생성·검토 → 컨텍스트 갱신·검증 순서로 반영한다. 기존 migration을 수정하거나 문서만 바꿔 실제 필터 등급을 변경하지 않는다.

## 생성·검수 공통 조건

- 모든 등급에서 중앙은 물고기가 잘 보이는 낮은 대비의 열린 공간으로 남긴다.
- 자연물과 소품은 주로 가장자리와 하단에 배치한다. 중앙을 큰 가구나 기둥으로 가르지 않는다.
- 스페셜의 차이는 소품 개수보다 장소의 개성과 구도에서 만든다.
- 스마트폰 크기의 미리보기로 확인하고, 물고기를 올렸을 때 배경이 시선을 빼앗는지 점검한다.
- 물고기·캐릭터·글자·UI는 배경 이미지에 포함하지 않는다.
