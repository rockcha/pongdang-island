# 미끼 도감과 획득 구분

## 설치
01~13 적용 후 `supabase/sql/14-bait-catalog/01-baits.sql`만 추가 실행합니다. 원격 적용은 이 작업에서 수행하지 않았습니다. 기존 인벤토리 키와 낚시 기록을 유지합니다. 이미지는 public/items/baits/에 포함되어 Storage 업로드가 필요 없습니다.

| ID | 이름 | 역할 | 가격 |
| --- | --- | --- | --- |
| bait | 퐁당 지렁이 | 기본 확률 | 30골드 |
| bait_special | 달빛 진주새우 | 최소 희귀 보장 | 판매 안 함 |
| bait_safe | 이슬잎 경단 | 실패 확률 상대20% 감소 | 판매 안 함 |
| bait_magnet | 심해 인력석 | 장식물 보장용, 현재 사용 비활성 | 판매 안 함 |
| bait_epic | 별잠의 유혹 | 최소 특급 보장 | 판매 안 함 |

‘선홍빛 지렁이만 판매’는 사용자가 지정한 정식 이름 **퐁당 지렁이**의 외형 설명으로 해석했습니다. 미끼 중 퐁당 지렁이만 구매할 수 있으며 다른 미끼에는 가격을 표시하지 않습니다. 획득 방식은 아직 지정되지 않아 ‘획득 전용 · 획득처 준비 중’으로 표시합니다. 임의 무료 지급이나 획득 버튼은 추가하지 않았습니다.

## 세계관 설명
- 퐁당 지렁이: 퐁당섬의 촉촉한 모래와 풀숲에서만 서식하는 선홍빛 지렁이. 물속에서도 꼬물꼬물 움직여 물고기의 호기심을 자극한다. 매우 흔하고 구하기 쉬워, 섬의 초보 낚시꾼들이 가장 먼저 챙기는 미끼다.
- 달빛 진주새우: 달빛이 스며드는 얕은 바다에서 자라는 작은 진주새우. 반투명한 껍질 속 푸른 진주가 은은하게 빛나며, 평범한 먹이에는 다가오지 않던 진귀한 물고기까지 불러 모은다고 한다.
- 이슬잎 경단: 새벽 이슬을 머금은 어린 잎에 향긋한 해초 반죽을 감싼 수제 미끼. 작은 쇠바늘에 단단히 붙어 쉽게 흩어지지 않고, 잎 사이로 퍼지는 순한 향이 경계심 많은 물고기를 안심시킨다.
- 심해 인력석: 깊은 해구에서 건져 올린 푸른 자철석을 다듬어 만든 인양용 미끼. 물고기 대신 바다 아래 잠든 장식물에 반응하며, 오래전에 가라앉은 보물의 흔적을 조용히 끌어당긴다.
- 별잠의 유혹: 별잠 유적의 틈에 맺힌 별가루를 자수정 조각에 봉인한 미끼. 물결에 닿으면 보랏빛 잔광이 길게 번져, 깊은 바다에 몸을 숨긴 비범한 생명까지 잠에서 깨운다고 전해진다.

## 구현
fishing_baits.price를 nullable로 바꿨고 null은 판매 불가입니다(무료가 아님). 서버 buy_fishing_bait에서도 BAIT_NOT_FOR_SALE로 거절합니다. effect_description은 숫자 효과, description은 세계관 설명으로 화면에 함께 표시합니다.
새 effect_kind=fish/decoration으로 장식물용 미끼를 분리합니다. 심해 인력석은 UI 선택 비활성, cast_fishing/resolve_fishing에서도 DECORATION_NOT_READY로 거절하며 재고를 소모하지 않습니다. 장식물 획득 로직은 아직 없고 기존 물고기 확률에 섞이지 않습니다. 카탈로그의 장식물 확률 열은 미사용 자리표시자이며 UI에 포획 확률로 표시하지 않습니다.
별잠의 유혹: 특급99.7%/신화0.3%, 나머지0%. 희귀 보장과 같은 방식으로 낮은 구간을 특급으로 올립니다. 기존 일반·희귀보장·안전 확률은 유지합니다.
일반 미끼 ID bait를 유지해 기존 재고·상점과 호환합니다. 기존 섬 상점의 조개 상품은 미끼가 아니므로 유지합니다. 퐁당 지렁이의 기존 판매 기능(18골드 환매)도 유지합니다.
