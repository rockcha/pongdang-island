# 미끼·인벤토리·기본 낚시

## 최신 낚시 화면

지역 낚시는 [사전 추첨 장력 미니게임](../design/fishing-minigame.md)을 사용합니다. 62 SQL 적용 후 시작 시 미끼 1개를 사용하고 성공 예정35%·등급·개체를 서버가 예약합니다. 3~5초 뒤 길게 누르기/떼기로 장력을 조절하며, 예정된 등급에 따라 힘이 달라집니다. 미니게임 실패·취소는 반드시 실패이고, 성공 예정과 미니게임 성공을 모두 만족해야 예약한 개체가 지급됩니다. 실패 예정은 일반 실루엣으로 진행하다 무작위 사유로 끝납니다. 성공 결과는 화면 중앙 포획 연출에서 이름·등급과 함께 확인하고 화면을 눌러 닫습니다. 실패·오류는 화면 안 카드, 미끼 설명과 확률은 미끼통 모달입니다. 상단 등급 테스트는 보상 없는 로컬 연습입니다. 아래 초기 구현 기록은 현재 동작과 다릅니다.

## 사전 추첨 낚시 (62)

[62 적용 및 API](../../supabase/sql/62-prepared-fishing/README.md). 61의 추가 실패 제거 정책을 성공 예정35%+미니게임 확정 정책으로 대체합니다. app_private.prepared_fishing_casts는 예약·미끼 소모·개체 스냅샷을 보존하며, 계정당 진행 중 예약은 하나입니다. public.prepare_fishing에서 소모/예약하고 public.finish_fishing에서 결과와 획득을 확정합니다. 단일 cast_fishing API는 차단합니다.
