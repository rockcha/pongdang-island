# 친구 아쿠아리움 방문과 먹이 주기

등대(`/friends`)에서 친구 아바타나 이름을 누르면 해당 친구의 아쿠아리움을 방문한다. 좌우 버튼으로 친구의 여러 어항을 둘러보고, 개체 목록에서 현재 어항에 배치된 생물과 장식품을 확인한다. 방문 화면에서는 배치·판매·보관 등 편집을 제공하지 않는다.

먹이는 무료이며 반복 횟수나 대기 시간 제한이 없다. 먹이 주기 버튼을 누르면 먹이통 커서 모드를 켠다. 이 버튼 자체는 횟수를 세지 않는다. 어항을 클릭하거나 탭한 위치에서 먹이가 떨어지며, 실제 먹이 주기 세 번에 한 회차가 완료된다. 키보드로는 먹이 영역에 초점을 두고 Enter 또는 Space로 중앙에서 먹이를 줄 수 있다. 그만하기 또는 Escape로 모드를 끄고, 같은 어항에서는 진행 횟수를 유지한 채 다시 시작할 수 있다. 개체는 기존 움직임을 유지한다. 모여들기·퀘스트는 구현하지 않는다. 어항을 바꾸거나 방문을 나가면 화면의 진행 횟수는 초기화된다. 미완료 회차는 완료 실적으로 계산하지 않는다.

청소하기는 먹이 주기와 별개로 언제든 반복할 수 있다. 솔 커서로 누른 채 누적 64 CSS px 이상 문지르고 손을 떼면 1회이며, 서로 분리된 세 번의 제스처로 완료한다. 짧은 탭·취소된 제스처·요청 처리 중의 추가 움직임은 진행시키지 않는다. 모바일에서는 청소 영역의 스크롤을 막고 손가락 이동을 솔과 비누방울에 연결한다. 키보드는 Enter/Space 한 번을 문지르기 한 회의 대체 입력으로 제공한다. 먹이·청소 모드는 동시에 켤 수 없다. 청소 중에도 개체 움직임은 유지한다. 오프라인 시간에 따른 오염 시스템은 추가하지 않는다.

친구 아바타와 이름은 어항 내부 왼쪽 위, 개체 목록은 오른쪽 위에 고정한다. 방문 경로는 배너 없이 `aquarium-shell`의 100dvh 안에 헤더·48px 탐색 줄·남은 높이를 채우는 어항을 배치한다. 친구 목록 링크는 탐색 줄 왼쪽에 둔다. 어항에 별도 vh 높이나 최소 높이를 주지 않으며, 모바일 좌우 여백을 없앤다. 먹이·청소 버튼은 하단 두 칸의 너비 안에서 줄어들도록 하고, 화면 하단 안전 영역은 앱 셸에서 확보한다. 청소 기록은 `aquarium_cleanings`에 저장하며 세 번째 단계에서만 `completed_at`을 채운다. 수락된 친구만 RPC를 호출할 수 있고, 기록 직접 쓰기는 차단한다. 청소 알림은 먹이와 독립적으로 방문자·주인·한국 날짜별 한 번 소식으로 전송한다. 포인터 경로는 브라우저에서 판정하며 현재 이 기록을 이용한 보상은 없다.

먹이통은 내장 이미지 생성 도구로 제작한 투명 PNG이며 `public/aquarium/food-canister.png`를 사용한다. 생성 프롬프트와 원본 위치는 `assets/references/feeding-canister.md`에 기록한다. 이번 커서 변경에는 추가 DB 작업이 필요하지 않다.

`feed_friend_aquarium`은 서버에서 순서대로 1→2→3 단계를 확인한다. 동일 작업 ID와 단계의 재전송은 중복 진행하지 않는다. 세 번째 단계에서만 완료 시각을 남기며, 향후 퀘스트는 `aquarium_feedings.completed_at`이 있는 기록을 이용할 수 있다. 클라이언트 클릭 수만으로 보상을 지급해서는 안 된다.

완료하면 어항 주인에게 소식 알림을 보낸다. 반복 알림을 막기 위해 방문자·주인·한국 날짜별 한 번만 알린다. 이 제한은 먹이 주기와 완료 기록에는 적용하지 않는다.

방문 조회와 먹이 RPC 모두 현재 수락된 친구 관계를 검사한다. 보관·판매·에스크로 개체는 방문 응답에서 제외한다. 완료 및 진행 기록은 방문자와 주인만 조회할 수 있고 직접 수정할 수 없다. 어항 삭제 후에도 기록은 유지되며 탱크 참조만 비운다.

설치: `supabase/migrations/20261017074923_friend_aquarium_visits_feeding.sql`. 기존 원격 프로젝트에서 수동으로 적용할 경우 동일한 내용의 `artifacts/friend-aquarium-visits-install.sql`을 한 번 실행한다. 해당 SQL은 신규 기능 설치용이므로 재실행하지 않는다. 로컬 재생과 테스트 성공은 원격 적용 증거가 아니다.

검증: `tests/friend-feeding-sql.test.ts`, `tests/friend-feeding.test.tsx`, `tests/tank-inhabitants.test.tsx`.

청소 추가 설치: 기존 친구 방문 설치 후 `artifacts/friend-aquarium-cleaning-install.sql`을 한 번 적용한다. 원본 migration은 `20261017080527_friend_aquarium_cleaning.sql`이다. 기존 방문 설치 SQL을 다시 실행하지 않는다. 청소 검증은 `tests/friend-cleaning-sql.test.ts`, `tests/friend-cleaning.test.tsx`; 방문 레이아웃은 `tests/friend-aquarium-page.test.tsx`.
