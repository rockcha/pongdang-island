# 카드 짝맞추기

두 번째 오락실 게임. 경로 `/arcade/memory`. React + CSS 3D 회전을 사용하며 Phaser를 추가하지 않습니다.

## 규칙

- 5×5 카드판, 사물 12종 × 2장과 중앙 13번 퐁이 카드. 퐁이는 처음부터 공개하고 클릭·짝 판정에서 제외합니다.
- 일반모드는 시작 시 10골드, 첫 카드를 뒤집을 때 서버 타이머 시작. 12짝 완료 때 시간을 확정하며 짧을수록 좋은 기록입니다. 일일 참가 제한 없음.
- 두 장이 다르면 900ms 이상 공개 후 닫습니다. 정답 두 장은 계속 공개합니다. 클릭 중복·완료 요청 재전송은 추가 점수나 차감을 만들지 않습니다.
- 무료 연습모드는 브라우저에서 같은 규칙으로 실행하고 참가비·서버 기록·보상 대상에서 제외합니다. 새로고침하면 연습은 초기화됩니다.
- 공통 게임 플레이 / 랭킹 아이콘 탭. 시작·완료 시 보드 위 오버레이에서 실전 시작(10골드)·연습 시작을 고릅니다. 게임 화면은 100dvh 높이에 맞추고 정사각형 카드판을 남은 너비·높이 중 작은 쪽으로 배치합니다. 배너 전체 그림을 유지하고 게임은 스크롤하지 않으며 랭킹 목록만 내부 스크롤합니다. [공통 규칙](../design/arcade-games.md).
- 한국 시간 월요일 00:00부터 다음 월요일 00:00까지 완료한 기록 중 개인 최고 기록을 표시합니다. 동점은 먼저 완료한 순서, 1·2·3등 강조, 20명씩 더 보기로 전체 순위 조회.

## 서버 판정과 보안

`supabase/migrations/20261016105544_memory_card_arcade.sql`은 새 게임 전용 migration입니다. 기존 지갑·골드 거래·프로필 테이블이 있는 호환 DB에 적용합니다. 로컬 PGlite 재생과 테스트를 통과했으며 원격 DB에는 미적용입니다. Dashboard SQL Editor에서 신규 파일만 적용하거나 CLI migration 상태를 검토한 뒤 배포합니다. baseline 재실행은 하지 않습니다.

서버는 비공개 deck과 matched/first/second 상태를 관리하고 공개/맞힌 카드만 응답합니다. 참가 operation UUID와 계정당 활성 게임 1개로 중복 결제를 막습니다. 모든 변경은 wallet → run 잠금 순서입니다. 정답·완료 시간·순위는 클라이언트가 제출하지 않습니다. 그만하기는 미완료로 종료하며 순위에 포함하지 않고 참가비를 환불하지 않습니다. 닉네임·순위·시간·시도 수·본인 여부만 순위 RPC에서 공개합니다.

주간 보상은 그림자 맞추기와 같은 서버 정산 흐름을 사용합니다. 게임·주차·계정별 개인 최고 기록에 대해 한 번만 운영자 우편을 발송하며, 연습과 미완료·포기 기록은 제외합니다. 마감된 주만 처리하고 예약 실행이 지연되면 미정산 주를 복구합니다. 보상표는 순위 RPC 응답을 사용하며 수기로 중복 관리하지 않습니다.
