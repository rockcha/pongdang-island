# 헤더 빠른 내비게이션

장소 이동은 헤더의 아이콘 링크만 사용합니다. 햄버거 버튼·왼쪽 drawer·하위 메뉴 접기와 펼치기·브라우저 접기 상태 저장은 제거했습니다. 게임 페이지의 목록으로/뒤로가기 버튼도 두지 않습니다.

`src/components/header-place-navigation.tsx`의 headerPlaces가 장소 링크의 단일 원본입니다. 새 장소는 이 배열과 src/routes.tsx에 등록합니다. 좁은 화면에서는 아이콘 줄만 가로 스크롤하며 장소명은 툴팁과 접근성 이름으로 제공합니다.

| 장소 | 경로 |
| --- | --- |
| 퐁당 섬 | / |
| 아쿠아리움 | /aquarium |
| 지도 | /harbor |
| 창고 | /warehouse |
| 오락실 | /arcade |
| 등대 | /friends |
| 광장 | /square |
| 상인거리 | /merchant-street |

하위 경로에서도 해당 장소를 강조합니다. /shop은 상인거리 소속입니다. 프로필은 아바타 메뉴, 알림은 벨에서 접근합니다. 로그인 사용자에게 장소 링크를 제공합니다.

플레이 중 헤더 링크로 이동하면 게임 공통 GameLeaveGuard가 확인 모달을 표시합니다. 실전·연습 모두 적용합니다. 상세한 [게임 UI 규칙](../design/arcade-games.md)을 따릅니다.
