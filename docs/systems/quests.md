# 퀘스트 운영

진행도는 클라이언트가 보내는 숫자를 신뢰하지 않고 기존 서버 활동 기록에서 집계한다. 낚시 횟수는 완료된 직접 낚시 시도이며 실패도 포함한다. 포획은 직접 낚시 성공과 통발 결과 수령을 포함하고, 선물·구매로 얻은 개체는 제외한다. 거래는 성사된 판매·구매 양쪽에 기록되며 취소는 제외한다. 선물은 친구에게 보낸 건수만 포함한다. 실전 게임은 유료 참가 기록을 사용하고 연습은 제외한다. 친구 어항 돌보기는 청소·먹이 주기의 마지막 동작까지 완료해야 인정한다.

일일은 한국 시간 자정, 주간은 한국 시간 월요일 자정에 초기화한다. 서버가 반환한 기간 식별자를 수령 요청에 포함하고, 지갑 잠금을 획득한 뒤 다시 시간을 확인해 지난 기간의 수령을 거절한다. 한 번 받은 보상은 사용자·기간·퀘스트의 유일 키로 보호한다. 같은 요청을 재시도해도 중복 지급되지 않으며 전체 완료 보상과 개별 보상은 별도로 받을 수 있다. 골드 한도를 넘으면 지급·수령 기록 모두 취소한다.

주간 지도·낚싯대 구매는 해당 상품을 모두 보유했고 이번 주 구매도 없으면 제외한다. 이번 주 마지막 상품을 구매한 경우에는 완료된 항목으로 유지하여 개별 보상을 받을 수 있다. 완료 여부는 개별 보상 수령 여부와 별개다. 일주일 안에 새 해역이 추가되면 구매할 지도가 생기므로 지도 항목이 다시 나타날 수 있다.

퀘스트 버튼은 출석 왼쪽에 배치한다. drawer에서만 목록을 스크롤하고 탭·초기화 시간·전체 완료 보상은 고정한다. 행의 제목을 누르면 해당 활동으로 이동하고, 보상 버튼은 완료되었을 때만 활성화한다. 네트워크 오류 시 같은 기간·항목으로 재시도한다. 기간이 바뀌면 새 목록을 불러와야 한다.

변경 후 `tests/quests-sql.test.ts`, `tests/quests-ui.test.tsx`와 DB 검증을 실행한다. 원격 배포는 새 migration만 적용하고, 설치 후 인증 계정으로 상태 조회·지급·재수령 방지와 실제 활동 집계를 확인한다. 로컬 PGlite 검증을 원격 적용의 증거로 취급하지 않는다.
