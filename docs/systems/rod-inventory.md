# 낚싯대 효과

지역 낚싯대는 어느 해역에서 사용하든 해당 낚싯대 지역을 주 서식지로 하는 개체의 추첨 가중치를 올립니다. 해당 해역에서는 ×2→×2.2, 다른 해역에서는 ×0.2→×0.3입니다. 다른 개체와 등급 추첨 확률은 그대로입니다. 같은 지역의 특수 외형 낚싯대도 동일한 효과이며 장식물 미끼에도 적용합니다.

장착·소유 여부는 서버에서 사용자 본인의 loadout을 조회해 확인합니다. 미끼 사용 시 개체와 성공 판정을 예약하므로 이미 시작한 낚시에 장비 변경은 소급되지 않습니다. 청동·잔물결 낚싯대만 직접 낚시의 기본 실패율을 줄이며, 성공 판정은 최대 100%입니다. 게이지 조작 실패와 어선 파견에는 이 보정을 적용하지 않습니다. 해역 낚싯대는 기존 고유종 보정만 유지합니다.
