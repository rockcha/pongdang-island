# 낚싯대 효과

지역 낚싯대는 어느 해역에서 사용하든 해당 낚싯대 지역을 주 서식지로 하는 개체의 추첨 가중치를 올립니다. 해당 해역에서는 ×2→×2.2, 다른 해역에서는 ×0.2→×0.3입니다. 다른 개체와 등급 추첨 확률은 그대로입니다. 같은 지역의 특수 외형 낚싯대도 동일한 효과이며 장식물 미끼에도 적용합니다.

장착·소유 여부는 서버에서 사용자 본인의 loadout을 한 번 조회해 확인합니다. 미끼 사용 시 개체를 예약하므로 이미 시작한 낚시에는 장비 변경이 소급 적용되지 않습니다. 일반 낚싯대에는 주 서식지 추가 보정이 없습니다. 과거 failure_reduction_bp/native_bonus_bp 수치는 호환용으로 유지하며, 기존 +2%p 안내는 현재 효과가 아닙니다. 성공 판정 40%는 별도이며 이번 변경으로 조정하지 않습니다.

거래는 서버 가격·보유 내역을 따르고 기본 낚싯대는 판매할 수 없습니다. 구매·판매·장착은 지갑을 먼저 잠그는 순서를 유지합니다. 개체 추첨과 “확률 10배 업” 안내의 기준은 [낚시](fishing.md)를 따릅니다.

검증: `tests/rod-habitat-weight.test.ts`, `tests/fishing-rods-sql.test.ts`, `tests/fishing-rod-ui.test.tsx`. DB 변경 절차는 [DB 관리](database-management.md)를 따릅니다.
