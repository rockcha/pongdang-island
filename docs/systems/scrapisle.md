# 녹빛 고물섬

`scrapisle`은 구름나루 다음 순서의 지도 구매 해역이다. 지도1,800골드, 녹빛 고철 낚싯대1,500골드. 낚싯대는 실패율 −2%p와 해당 지역 토착 확률 +2%p를 제공한다.

26종은 쓰레기5·장식품14·생물7로 분류한다. 떠다니며 회전하는 깡통·장화·신문지·카세트·오리인형은 쓰레기다. 바닥에 놓이는 냄비·시계·가전·가방·차량·폐선 등은 장식품이다. 소라게·방패게·탐사 로봇은 crawl, 전구집 문어와 타이어 곰치는 fixed, 철갑상어와 그린아크는 swim이다.

일반 낚시는 먼저 기존 등급 확률을 그대로 사용한다. 고물섬의 해당 등급 안에서 물건(쓰레기·장식품)을80%, 생물을20% 우선 추첨한다. 선택한 종류가 없는 등급은 같은 등급의 존재하는 종류로 대체한다. 따라서 일반은 전부 물건, 신화는 그린아크다. 장식품 전용 미끼는 기존과 같이 장식품만 추첨한다. 다른 해역의 추첨 규칙은 유지한다. 실패 확률과 쓰레기 보상은 별개이며 실패를 고물 지급으로 바꾸지 않는다.

그린아크는8프레임으로 평상시 선체를 유지하고6초 주기 안에서 크레인이 빛나는 고물을 건져 올린다. 회전 크로스페이드나 몸통 확대 효과는 사용하지 않는다. 다른 생물6종은4프레임. 일반·희귀는 퐁이, 특급·신화는 별빛 가오리 참고 그림체를 따른다. 무생물에 얼굴을 억지로 넣지 않는다.

원본 카탈로그는 `supabase/catalog/catalog.json`, CLI migration은 `20261017093723_scrap_isle_region_and_species.sql`, 수동 설치 파일은 `artifacts/scrapisle-install.sql`이다. 사용자가 설치 SQL 전달을 선택했으므로 이번 원격 SQL은 실행하지 않는다. 관리 토큰401로 원격 함수·스키마는 현재 확인하지 못했다. 로컬 PGlite 검증은 원격 호환성 증거가 아니다. 기존 준비/완료 낚시 함수나 migration history를 초기화하지 않는다.
