# 칭호

칭호는 영구 소유하며 하나만 장착한다. 칭호 화면에서 고르고, 계정 메뉴와 친구 목록에는 장착한 이름을 표시한다. 미획득 칭호는 이름만 보여주고 조건·목표·진행도는 서버 응답에서도 숨긴다. 카탈로그 직접 조회도 본인 소유 칭호만 허용한다. 조건은 획득한 뒤 공개하고, 직접 프로필 쓰기로 장착을 우회하지 못하도록 서버에서 소유를 확인한다.

서버가 직접 낚시·파견 수령의 증거를 별도로 남기므로 개체를 팔거나 선물해도 기록은 유지된다. 포획 계열은 직접 낚시와 파견을 포함하고 선물·구매는 제외한다. 직접 낚시 계열은 실패도 포함한다. 새벽·하루·자정 조건은 한국 시간 기준이고 새벽은 02:00 이상 05:00 미만이다. 마지막 미끼 여부는 낚시 준비 시 소모 전 재고로 기록하며, 증명할 수 없는 과거 마지막 미끼는 소급하지 않는다.

미발견 여부와 도감 완성 직전 상태는 개체 획득 시 비공개 증거로 저장한다. 보유 개체를 팔거나 삭제해도 이 증거는 유지한다. 해당 순간 기록이 없는 과거 획득은 추정해서 소급하지 않는다. 항구 조업의 칭호는 수령이 끝난 조업 결과만 집계하고, 낚시 퀘스트 집계와 분리한다. 어항 조건은 배치 순간 판정하며 구성 변경 후에도 획득을 유지한다.

연속 조건은 직접 낚시의 시간·서버 기록 순서를 따른다. 실패하면 연속 포획이 끊긴다. 한 번의 파견 조건은 한 묶음의 결과로 판정한다. 친구 돌보기 성장 진행도는 친구별 하루 한 번이며, 청소와 먹이 주기를 반복해도 같은 친구·날짜에서는 증가하지 않는다. 어항 꾸미기 조건은 배치 시 판정하여 재배치 후에도 소유가 유지된다. 작은 물고기는 카탈로그 기본 크기 기준이다.

활동은 처리 대기열에 사용자만 넣고, 배치 작업이 해당 사용자 기록을 집계한다. 온라인에서는 주기적으로 본인 대기열을 확인하고, pg_cron이 설치된 서버는 매분 제한된 수의 사용자를 처리한다. 달성 기록을 처음 삽입한 트랜잭션만 알림을 생성한다. 알림은 칭호 선택 창으로 연결된다. 원격 배포 후 cron 등록과 실제 알림 전달을 별도로 확인해야 한다. 로컬 PGlite에는 cron 서비스가 없다.

추가 조건과 칭호 정의는 새 migration으로 변경한다. 카탈로그 명칭을 변경할 때 장착 프로필의 외래 키 전파를 고려하고, 과거 획득을 삭제하지 않는다. 원본 아이콘·프롬프트·해시는 이미지 manifest에 보존한다. `tests/titles-sql.test.ts`, `tests/titles-ui.test.tsx`, 알림·프로필·친구 관련 테스트와 DB 검증으로 확인한다.

회원 프로필이 처음 만들어질 때 기본 칭호를 소유·장착한다. 기본 칭호는 달성 알림을 보내지 않는다. 같은 트랜잭션에서 운영자 명의의 가입 축하 골드 선물을 생성하고 선물 알림을 보낸다. 골드는 선물 수령 시에만 반영하며 로그인·닉네임 변경으로 재발급하지 않는다. 기존 회원 소급 시 장착한 칭호를 보존하고 가입 선물은 회원당 한 번만 생성한다.
