# UI 고정 규칙

오락실 게임 화면은 [공통 게임 UI 규칙](design/arcade-games.md)을 따릅니다. 두 게임과 이후 게임에서 같은 아이콘 탭·보드 시작 오버레이·배너 보존·스크롤 범위·목록 썸네일·분류 태그 구조를 유지합니다.

## 퐁이 색상과 모서리

모든 장소·낚시터·지도 배너 제목은 `font-normal`(400)로 통일합니다. 배너별로 bold/semibold/medium을 섞지 않습니다.

전체 앱의 공통 배경·카드·입력란·버튼·탭·포커스 링도 동일한 갈색 테마 토큰을 사용합니다. 기본은 크림/베이지 배경에 브라운 글자와 카라멜 버튼, 기본은 라이트 모드이며 마이페이지의 설정에서 다크 모드를 선택합니다. 시스템 테마를 자동 추종하지 않고 선택은 브라우저에 저장합니다. 기본 입력창과 알림도 선택한 색상 체계를 따릅니다. 구매·판매 확인 질문은 반드시 상품명을 첫 줄에, `[골드 이미지 + 가격]에 구매/판매하시겠습니까?`를 둘째 줄에 표시합니다.

헤더는 두 줄이며 스크롤 페이지에서도 `sticky top-0`로 상단에 유지합니다. 첫 줄 왼쪽에는 로고, 오른쪽에는 골드·아바타를 세로 중앙에 정렬합니다. 골드는 배경 없이 20px 불가사리 금화와 숫자로 표시하고 아바타 드롭다운에는 중복 표시하지 않습니다. 둘째 줄 왼쪽은 장소 이동 아이콘, 오른쪽은 출석·알림입니다. 장소 이름은 호버 툴팁으로 표시하고 현재 장소는 갈색으로 강조합니다. 상인거리는 하위 링크를 나열하지 않습니다. 좁은 화면에서는 장소 아이콘 영역만 가로 스크롤합니다. 배너는 둘째 줄 아래에 배치합니다. 좌우 여백은 12px이며 출석·알림 버튼은 40px, 두 표시 배지는 같은 `header-indicator` 클래스로 16px 갈색 원을 사용합니다. 안전 영역은 헤더 안쪽 상단에서 처리합니다. “퐁당섬” 브랜드 제목은 헤더에서 `font-normal`(400)로 고정합니다.


헤더·토스트는 퐁이의 털을 닮은 따뜻한 팔레트를 공유합니다. 배경은 크림 아이보리 `#FFF8EE`, 주색은 살구 카라멜 `#C98B57`, 포인트는 불가사리의 피치 코랄 `#F29B7D`, 글자는 짙은 브라운 `#4A3328`, 테두리는 연한 베이지 `#EAD7C2`입니다. 작은 글자·아이콘·선택 상태의 전경은 대비가 충분한 더 짙은 카라멜 `#995E36`을 사용합니다. 바다 풍경·등급 색상은 별도 기준을 유지합니다.

모서리는 살짝 둥글게 정리합니다. 토스트와 메뉴 항목·헤더의 작은 컨트롤은 8px를 사용합니다. 일반 알림·메뉴를 과도한 캡슐형으로 만들지 않습니다. 원형 아바타와 작은 수량 배지는 허용합니다. 강한 그림자·광택 대신 얇은 베이지 테두리와 작은 그림자를 사용합니다.

일반 동작 토스트는 `/branding/pongi-starfish.png` 불가사리와 짧은 텍스트를 나란히 배치합니다. 우편함 알림과 실시간 소식 토스트에는 알림 사건에 맞는 전용 그림을 사용하고, 종류 필터를 적용해도 그림을 유지합니다. 전용 그림 선택은 `notification-icon.tsx`에서 공통으로 처리하며 알림 본문의 내용·읽음 표시·이동 동작을 보존합니다. 구매 성공은 공통 GoldProvider에서 “상품명을 구매했습니다.” 형태로 한 번 표시하며, 받침에 맞춰 을/를을 선택합니다. 실패 요청에는 성공 알림을 띄우지 않습니다. [이미지와 생성 프롬프트](../assets/references/toast-starfish-manifest.json).

낚시 페이지 배너에는 해역명과 정보 버튼을 왼쪽 아래에 표시하고, 해역 설명은 제목 아래에 표시합니다. 도구는 배너 아래 낚시 화면 상단 가로 중앙에 지도·도감·토착 개체·도움말·힘 테스트 순서로 간격 없이 묶고 구분선·툴팁을 제공합니다. 낚시 중 그만하기도 아이콘으로 표시합니다. 미끼통·보관함은 왼쪽 아래에 간격 없는 하나의 묶음으로 배치하며, 릴·낚시 시작은 조작 영역에 유지합니다.

지도 지도 조각은 마우스 호버와 키보드 포커스에서 부드럽게 1.08배 확대하고 뒤에 푸른 빛을 표시합니다. 선택 상태의 배경 빛도 유지하며 모션 감소 설정에서는 확대와 전환 애니메이션을 생략합니다. 도감 카드의 서식지역은 나란한 지역 아이콘과 검정·흰색 툴팁으로 표시하고 지역 필터를 제공합니다.

장소 이동은 [헤더 빠른 내비게이션](systems/navigation.md)을 사용합니다. 광장·상인거리의 하위 장소는 부모 페이지의 카드로 접근하며 각 하위 페이지는 전용 배너를 사용합니다. 우편함 명칭은 “우편함”으로 통일합니다. [장소·메뉴 규칙](design/place-navigation.md).

## 선택 드롭다운

새로 만들거나 수정하는 선택 드롭다운은 아쿠아리움 등급 선택창 스타일을 기준으로 합니다. 펼친 항목까지 갈색 테마를 유지하도록 Base UI Select를 사용합니다. 네이티브 select의 운영체제 기본 팝업 색상에 의존하지 않습니다.

- 트리거: 최소 높이 44px, 12px 모서리, 얇은 border-border, bg-secondary/60, text-foreground, 좌우 12px 여백. 오른쪽에는 ChevronDown을 text-primary로 표시합니다.
- 목록: bg-popover, border-border, 12px 모서리, 작은 그림자와 4px 안쪽 여백. 모달 위에서도 보이도록 포털과 적절한 레이어를 사용합니다.
- 항목: 최소 높이 44px, 8px 모서리. 포커스·호버는 bg-secondary, 선택 상태는 bg-secondary/60 text-primary와 체크 아이콘으로 표시합니다.
- 라이트·다크 모두 의미 색상 토큰을 사용합니다. 라벨과 키보드 이동·선택·닫기를 제공하며, 모바일에서도 툴팁 없이 선택 내용을 이해할 수 있게 합니다.
- 구현 참고: src/features/aquarium/aquarium-inventory-dialog.tsx의 등급 필터.

## 확인 모달

확인 모달도 크림 배경·브라운 글자·카라멜 확인 버튼·베이지 취소 버튼을 사용합니다. 컨테이너 모서리는 10px, 버튼은 8px입니다. 구매·판매 질문은 `TradeQuestion`으로 “상품명을 [골드 이미지 + 가격]에 구매/판매하시겠습니까?” 형태로 표시합니다. 토스트는 body 포털에 렌더링하여 스크롤·모달에 가리지 않도록 하고, 거래 성공 즉시 확인 모달을 닫은 뒤 목록을 재조회합니다. 구매뿐 아니라 판매도 공통 거래 성공 토스트를 사용합니다.

“~~하겠습니까?” 확인 창은 `ConfirmDialog`를 공통으로 재사용합니다. 궁금한 표정의 퐁이(`/branding/pongi-curious.png`)와 질문·짧은 보조 설명을 가운데 정렬하고, 왼쪽 취소 / 오른쪽 확인 버튼만 같은 폭으로 표시합니다. 최초 포커스는 취소, 처리 중 중복 실행·닫기 금지, 실패는 모달 안에서 안내합니다. [디자인 규칙 및 사용 예](design/confirmation-dialog.md).

장소 풍경 배너는 공통 헤더 바로 아래에 120px 높이로 붙입니다. 퐁당 섬·지도·등대·우편함은 `public/banners/`의 풍경과 왼쪽 아래 제목을 사용하며 본문에서 큰 제목을 반복하지 않습니다. 아쿠아리움에는 배너를 추가하지 않습니다. [이미지 및 생성 프롬프트](design/place-banners.md).

사용자가 지정한 공통 규칙입니다. 새 UI와 기존 UI 수정 시 동일하게 적용합니다.

## 버튼 커서

- 모든 버튼은 `cursor: pointer`로 고정합니다. 아이콘 버튼·모달 열기·닫기·카테고리·구매·적용·판매 버튼에 동일하게 적용합니다.
- 공통 Button 기본 스타일과 전역 button / role=button 규칙에 적용합니다. 비활성화된 버튼도 커서 스타일은 pointer를 유지하되 실행은 disabled로 차단합니다.

## 어항 상단 버튼

- 좌측 상단에는 개체 목록·배경·보관함·바다 도감을 구분선으로 이어진 아이콘 버튼 한 묶음으로 배치합니다. 보이는 텍스트는 빼고 툴팁과 접근성 이름을 제공합니다. 보관함에는 보관 수량을 빨간 배지로 표시합니다. 보관함 모달은 다중 선택·검색·종류 필터·페이지 조회와 목적지 어항/남은 정원을 지원합니다.
- 배경 선택·구매·적용은 배경 모달 안에서 처리합니다.
- 배경 모달은 기본으로 내 배경 탭을 열며 보유 배경만 표시하고 적용할 수 있습니다. 구매 탭에는 미보유 배경과 보유 골드를 표시하며 구매한 배경은 내 배경 탭에서 적용합니다.
- 우측 상단에는 현재 어항 번호 n/n과 + · 골드 200 구매 버튼을 하나의 작은 묶음으로 배치합니다. 좌우 이동은 수조 양옆 중앙의 반투명 원형 화살표 버튼으로 제공합니다.
- 화살표 버튼 또는 수조에 포커스를 둔 상태의 좌우 방향키로 어항을 전환합니다. 첫·마지막 경계와 작업 중에는 해당 버튼을 비활성화합니다. 개체 드래그는 어항 전환으로 처리하지 않습니다.

## 툴팁

- 배경은 검정(#000000), 텍스트는 흰색(#FFFFFF)으로 고정합니다.
- 라이트/다크 테마와 무관하게 동일한 색을 사용합니다.
- 공통 컴포넌트 `src/components/ui/tooltip.tsx`를 사용합니다. 브라우저 기본 title 툴팁은 색상을 제어할 수 없으므로 대신 사용하지 않습니다.
- 아이콘 버튼은 aria-label로 이름을 제공하고 호버·키보드 포커스 시 툴팁을 표시합니다.

## 우편함

우체통 사용자 표시 이름은 우편함으로 통일합니다. 알림 탭은 공지(Megaphone)·친구(UsersRound)·소식(Bell)·선물(Gift) 순서의 고정 Lucide 아이콘을 사용하며 검정/흰색 툴팁과 접근성 이름을 제공합니다. 기본은 공지 탭이고 선물 링크에서는 선물함을 엽니다. 선물함은 받은/보낸 선물 선택과 목록을 한 번만 표시합니다. 선물 보내기 버튼은 Gift 아이콘으로 고정합니다. 선물 답장은 👍 ❤️ 🥰 😂 🎉만 허용하고 서버/클라이언트 매핑을 함께 유지합니다. 자세한 문구는 systems/gifts.md를 참고합니다.

### 헤더 알림 드롭다운
- 종 아이콘을 누르면 최근 알림 8개를 표시한다.
- 항목은 앞쪽 카테고리 아이콘·이름(소셜 / 소식 / 선물), 내용, 상대 시간(방금 전 / N분 전 / N시간 전) 순서로 배치한다.
- 읽지 않은 항목에는 작은 점을 표시한다. 여는 것만으로 읽음 처리하지 않고 항목을 클릭하거나 모달을 닫을 때 표시된 항목을 읽음 처리한다. 읽은 항목은 회색으로 구분하며 왼쪽 강조선은 사용하지 않는다. 선물 도착 알림은 예외로 수령 전까지 유지하고, 선물함 숫자는 실제 미수령 선물을 포함한다. 선물 목록은 미수령을 강조하고 수령 완료는 회색으로 표시한다.
- 선물 항목은 선물 상세로 연결하고, 하단의 ‘우편함 가기’는 우편함 페이지로 이동한다.
- 모바일에서는 화면 폭 안에 표시하며 목록만 스크롤한다.

- 아쿠아리움은 제목·설명·어항 개수 제목 없이 화면의 남은 높이를 채웁니다. 모바일에서는 화면 너비를 채우고 컴퓨터에서는 다른 페이지처럼 최대 448px로 가운데 정렬합니다. 모바일·컴퓨터 모두 페이지 스크롤이 생기지 않게 합니다. 이름 변경은 수조 하단 모달로 엽니다. 임시 개체는 바다 도감 카드 우상단의 + 버튼으로 추가하며 도감은 열린 상태를 유지합니다. 개체 상세 모달은 사용하지 않고 설명을 카드 안에 표시합니다. 새로고침하면 임시 개체는 사라집니다.
- 개체는 드래그로 이동하며 선택 중 유영을 멈춥니다. 개체 위 약 8px 간격에 좌우 반전·반시계 회전·시계 회전·−·+ 아이콘 도구 모음(176px)을 표시합니다. 버튼 사이 세로 구분선과 그림자 없는 배경을 사용합니다. 회전·크기 변경 시 중심을 유지하고 도구 모음 위치를 고정하며 드래그 시에만 따라갑니다. 유리 가장자리에서는 범위 안으로 보정합니다. 회전 15°·크기 0.1배 단위로 자동 저장하며 크기는 0.5~2배 범위입니다. 저장·닫기 버튼과 텍스트 라벨은 표시하지 않고 수조 배경을 누르면 닫힙니다.


상점은 상인거리 하위에 배치합니다. 지도·미끼·낚싯대 탭은 가로 전체를 균등 분할하며 페이지 전체 대신 상품 목록만 스크롤합니다. 배너와 탭 사이에는 여백을 두지 않습니다. 바다 도감에서는 지도를 제외합니다.

## 토착 지역 배지

토착 개체의 공통 썸네일 우측 아래에 24px 지역 배지를 표시합니다. public/region-icons의 원형 SVG 5종을 사용하고 지역명·토착 여부를 툴팁과 접근성 이름으로 제공합니다. 비토착·과거 스냅샷·알 수 없는 지역에는 배지를 생략합니다. 지도과 지역 제목에도 같은 아이콘을 사용합니다.

## 바다 도감

공통 도감 그림 아이콘과 제목, 종류 아이콘·툴팁, 갈색 해역·등급 Select를 상단에 두고 카드 목록만 스크롤합니다. 해역은 단일 선택입니다. 목록은 이미지·이름 중심으로 표시하고 설명·가치·서식지는 상세에서 확인합니다. 미발견 개체는 검은 실루엣만 표시하고 자물쇠를 덧붙이지 않으며 상세를 열지 않습니다. 토착 개체는 카드 우측 상단에 해역 아이콘을 표시합니다.

장소 이동·목록·보관함 같은 기능 진입점은 `app-art`의 공통 그림 아이콘을 사용합니다. 같은 기능은 어느 페이지에서든 같은 그림을 쓰고, 작은 조작 버튼의 선 아이콘은 유지합니다. 그림은 장식으로 처리하며 버튼 이름·툴팁으로 의미를 전달합니다. 새 그림은 투명 배경과 따뜻한 윤곽선을 맞추고, 원본·생성 프롬프트·내보낸 파일의 해시를 이미지 manifest에 남깁니다.

장소·낚시 해역 배너는 제목 왼쪽 그림을 생략하고 제목 아래 짧은 소개 문구를 표시합니다. 제목 옆 Lucide 정보 버튼을 누르면 페이지에서 할 수 있는 일을 번호가 있는 항목으로 안내합니다. 소개 문구와 이용 안내는 별도로 작성합니다. 정보 버튼에는 페이지 이름을 포함한 접근성 이름을 제공하며, 안내는 닫기 버튼·Escape로 닫을 수 있어야 합니다. 배경 그림 위 제목은 아래쪽 갈색 그라데이션과 약한 글자 그림자로 대비를 유지합니다.

편집 대상과 드래그·저장 제한은 [수족관의 드래그와 편집](systems/aquarium.md#드래그와-편집)을 따릅니다. 고정 개체는 투명 여백까지 포함한 사각 영역으로 잡을 수 있어야 합니다.

도감에는 이름 검색창과 서식 유형 필터를 두지 않습니다.

## 이미지 로딩

- 이미지 크기와 비율을 로딩 전에 확보해 목록·배너·모달의 레이아웃이 밀리지 않게 합니다.
- 목록 데이터 대기 중에는 실제 카드와 같은 열 수·비율의 크림색 스켈레톤을 표시합니다. 개별 이미지도 같은 계열의 스켈레톤을 사용합니다.
- 준비된 이미지부터 150ms 페이드인합니다. 캐시된 이미지는 complete와 naturalWidth를 확인해 불필요한 로딩 표시를 줄입니다. 이미지 경로가 바뀌면 로딩 상태도 새로 시작합니다.
- 모션 감소 설정에서는 점멸과 페이드 전환을 생략합니다. 잠긴 개체는 처음부터 실루엣으로 표시해 원본 색상이 잠깐 보이지 않게 합니다.
- 실패 시 해당 이미지 영역에 재시도를 제공합니다. 이미지 대기로 제목·탭·다른 상품의 사용을 막지 않습니다. 링크 안에 재시도 버튼을 중첩하지 않습니다.
- 배너·풍경과 상점·창고 상품은 `LandscapeImage`, 개체 썸네일 페이드인은 `CollectibleThumbnail`의 fadeIn 옵션, 상품 목록 대기는 `ProductSkeleton`을 우선 재사용합니다.

## 상품 상세 구매 버튼

미끼·지도 구매 버튼은 가로 전체, 최소 높이 56px, 모서리 12px와 동일한 글자 크기를 사용합니다. 평상시에는 골드 아이콘과 합계 금액만 표시합니다. 수량은 별도 조절 영역에 표시하고 버튼에는 반복하지 않습니다. 접근성 이름에는 상품명·구매 동작과 필요한 수량을 제공합니다. 구매 중에는 진행 문구를 표시하고 중복 요청을 막으며, 보유·구매 불가 상태는 명확하게 구분합니다.

선택형 탭·분류·해역·미끼·낚싯대에서는 선택한 그림을 컬러로 유지하고 미선택 그림만 회색과 낮은 불투명도로 표시합니다. 이름·수량은 흐리지 않으며, 선택 배경·테두리·체크 표시도 함께 유지합니다. 일반 이동·실행 버튼에는 이 처리를 적용하지 않습니다.
