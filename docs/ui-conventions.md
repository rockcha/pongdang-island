# UI 고정 규칙

선착장 지도 조각은 마우스 호버와 키보드 포커스에서 부드럽게 1.08배 확대하고 뒤에 푸른 빛을 표시합니다. 선택 상태의 배경 빛도 유지하며 모션 감소 설정에서는 확대와 전환 애니메이션을 생략합니다. 도감 카드의 서식지역은 나란한 지역 아이콘과 검정·흰색 툴팁으로 표시하고 지역 필터를 제공합니다.

사이드바는 광장(공지사항·건의함·버그 제보), 상인거리(거래소·경매소)를 부모·자식 링크 계층으로 표시합니다. 하위 페이지는 해당 부모의 풍경 배너를 공유합니다. 우편함 명칭은 “우편함”으로 통일하고 퐁당 섬 메뉴에는 섬 모양 아이콘을 사용합니다. [장소·메뉴 규칙](design/place-navigation.md).

## 확인 모달

“~~하겠습니까?” 확인 창은 `ConfirmDialog`를 공통으로 재사용합니다. 궁금한 표정의 퐁이(`/branding/pongi-curious.png`)와 질문·짧은 보조 설명을 가운데 정렬하고, 왼쪽 취소 / 오른쪽 확인 버튼만 같은 폭으로 표시합니다. 최초 포커스는 취소, 처리 중 중복 실행·닫기 금지, 실패는 모달 안에서 안내합니다. [디자인 규칙 및 사용 예](design/confirmation-dialog.md).

장소 풍경 배너는 공통 헤더 바로 아래에 120px 높이로 붙입니다. 퐁당 섬·선착장·등대·우편함은 `public/banners/`의 풍경과 왼쪽 아래 제목을 사용하며 본문에서 큰 제목을 반복하지 않습니다. 아쿠아리움에는 배너를 추가하지 않습니다. [이미지 및 생성 프롬프트](design/place-banners.md).

사용자가 지정한 공통 규칙입니다. 새 UI와 기존 UI 수정 시 동일하게 적용합니다.

## 버튼 커서

- 모든 버튼은 `cursor: pointer`로 고정합니다. 아이콘 버튼·모달 열기·닫기·카테고리·구매·적용·판매 버튼에 동일하게 적용합니다.
- 공통 Button 기본 스타일과 전역 button / role=button 규칙에 적용합니다. 비활성화된 버튼도 커서 스타일은 pointer를 유지하되 실행은 disabled로 차단합니다.

## 어항 상단 버튼

- 좌측 상단에는 개체 목록·배경·보관함·바다 도감을 구분선으로 이어진 아이콘 버튼 한 묶음으로 배치합니다. 보이는 텍스트는 빼고 툴팁과 접근성 이름을 제공합니다. 보관함에는 보관 수량을 빨간 배지로 표시합니다. 보관함 모달은 다중 선택·검색·종류 필터·페이지 조회와 목적지 어항/남은 정원을 지원합니다.
- 배경 선택·구매·적용은 배경 모달 안에서 처리합니다.
- 배경 모달은 기본으로 내 배경 탭을 열며 보유 배경만 표시하고 적용할 수 있습니다. 구매 탭에는 미보유 배경과 보유 골드를 표시하며 구매한 배경은 내 배경 탭에서 적용합니다.
- 우측 상단에는 현재 어항 번호 n/n과 + · 골드 200 구매 버튼을 하나의 작은 묶음으로 배치합니다. 크게 보기·좌우 화살표·어항 선택 네모 버튼은 표시하지 않습니다.
- 어항 이동은 모바일 스와이프와 컴퓨터의 빈 유리 드래그로 처리합니다. 개체 드래그는 이동으로 처리하지 않습니다. 수조에 키보드 포커스를 두고 좌우 방향키로도 전환할 수 있습니다. 첫·마지막 경계를 넘어가지 않습니다.

## 툴팁

- 배경은 검정(#000000), 텍스트는 흰색(#FFFFFF)으로 고정합니다.
- 라이트/다크 테마와 무관하게 동일한 색을 사용합니다.
- 공통 컴포넌트 `src/components/ui/tooltip.tsx`를 사용합니다. 브라우저 기본 title 툴팁은 색상을 제어할 수 없으므로 대신 사용하지 않습니다.
- 아이콘 버튼은 aria-label로 이름을 제공하고 호버·키보드 포커스 시 툴팁을 표시합니다.

## 우편함

우체통 사용자 표시 이름은 우편함으로 통일합니다. 알림 탭은 전체(Inbox)·친구(UsersRound)·소식(Bell)·선물(Gift)의 고정 Lucide 아이콘을 사용하며 검정/흰색 툴팁과 접근성 이름을 제공합니다. 선물 보내기 버튼은 Gift 아이콘으로 고정합니다. 선물 답장은 👍 ❤️ 🥰 😂 🎉만 허용하고 서버/클라이언트 매핑을 함께 유지합니다. 자세한 문구는 systems/gifts.md를 참고합니다.

## 개체 카테고리 아이콘

| 카테고리 | 고정 아이콘 | 설명 |
| --- | --- | --- |
| fish / 물고기 | Lucide Fish | 물고기 실루엣 |
| decoration / 장식물 | Lucide Shell | 조개 장식 실루엣 |
| trash / 쓰레기 | 공통 CrumpledPaper SVG | 구겨진 종이 조각. 휴지통 아이콘은 사용하지 않음 |
| map / 지도 | Lucide Map | 펼친 지도 |

매핑과 SVG는 `src/features/collection/collectible-kind-icon.tsx`에 고정합니다. 각 화면에서 별도 아이콘으로 재정의하지 않습니다. 기본 크기는 16px, 선 색은 currentColor, 선 두께는 2입니다. 카테고리 필터와 개체 목록의 종류 표시에서 같은 아이콘을 사용합니다.

### 헤더 알림 드롭다운
- 종 아이콘을 누르면 최근 알림 8개를 표시한다.
- 항목은 앞쪽 카테고리 아이콘·이름(소셜 / 소식 / 선물), 내용, 상대 시간(방금 전 / N분 전 / N시간 전) 순서로 배치한다.
- 읽지 않은 항목에는 작은 점을 표시한다. 드롭다운을 여는 것만으로 읽음 처리하지 않는다.
- 선물 항목은 선물 상세로 연결하고, 하단의 ‘우편함 가기’는 우편함 페이지로 이동한다.
- 모바일에서는 화면 폭 안에 표시하며 목록만 스크롤한다.

- 아쿠아리움은 제목·설명·어항 개수 제목 없이 화면의 남은 높이를 채웁니다. 모바일에서는 화면 너비를 채우고 컴퓨터에서는 다른 페이지처럼 최대 448px로 가운데 정렬합니다. 모바일·컴퓨터 모두 페이지 스크롤이 생기지 않게 합니다. 이름 변경은 수조 하단 모달로 엽니다. 임시 개체는 바다 도감 카드 우상단의 + 버튼으로 추가하며 도감은 열린 상태를 유지합니다. 개체 상세 모달은 사용하지 않고 설명을 카드 안에 표시합니다. 새로고침하면 임시 개체는 사라집니다.
- 개체는 드래그로 이동하며 선택 중 유영을 멈춥니다. 개체 위 약 8px 간격에 좌우 반전·반시계 회전·시계 회전·−·+ 아이콘 도구 모음(176px)을 표시합니다. 버튼 사이 세로 구분선과 그림자 없는 배경을 사용합니다. 회전·크기 변경 시 중심을 유지하고 도구 모음 위치를 고정하며 드래그 시에만 따라갑니다. 유리 가장자리에서는 범위 안으로 보정합니다. 회전 15°·크기 0.1배 단위로 자동 저장하며 크기는 0.5~2배 범위입니다. 저장·닫기 버튼과 텍스트 라벨은 표시하지 않고 수조 배경을 누르면 닫힙니다.


상점은 상인거리 하위에 배치하며 배너를 표시하지 않습니다. 광장·상인거리의 접힘 상태는 로컬 스토리지에 저장합니다. 바다 도감은 아쿠아리움 상단 아이콘으로 여는 모달입니다.

## 토착 지역 배지

토착 개체의 공통 썸네일 우측 아래에 24px 지역 배지를 표시합니다. public/region-icons의 원형 SVG 5종을 사용하고 지역명·토착 여부를 툴팁과 접근성 이름으로 제공합니다. 비토착·과거 스냅샷·알 수 없는 지역에는 배지를 생략합니다. 선착장과 지역 제목에도 같은 아이콘을 사용합니다.

## 바다 도감

📖 이모지와 제목, 종류 아이콘·툴팁, 등급·토착 여부 select, 지역 아이콘 토글을 상단에 고정하고 카드 목록만 스크롤합니다. 책 도구 아이콘은 BookOpenText입니다. 등급 뱃지 대신 공통 등급색을 카드 배경으로 사용하고 본문 글자는 테마의 기본 대비를 유지합니다. 카드에는 설명과 `서식지:`, `가치:`를 배치하며 발견 상태·보유 수·개발용 이동 수치는 표시하지 않습니다.

편집 대상과 드래그·저장 제한은 [수족관의 드래그와 편집](systems/aquarium.md#드래그와-편집)을 따릅니다. 고정 개체는 투명 여백까지 포함한 사각 영역으로 잡을 수 있어야 합니다.

도감 상단에는 이름 검색창과 검색어 지우기 버튼을 표시합니다. 검색은 종류·등급·서식 유형·지역 필터와 함께 적용하며 가치순 정렬을 유지합니다.
