# 해역별 낚시 배경

대기 중에는 정면 풍경, 낚시가 시작되면 수면 가까이에서 비스듬히 내려다보는 구도를 사용합니다. 정면 풍경은 하늘·섬·해안의 분위기를 살리되 물속을 드러내지 않습니다. 낚시 구도는 백야의 빙해처럼 가까운 물결과 수중 지형의 크기·원근감을 살립니다. 중앙 찌와 물고기 그림자의 시인성을 확보하고, 수중 특징은 수면 반사 너머로 부드럽게 표현합니다.

두 시점은 미리 로드한 상태로 유지하고 낚시 상태에 따라 짧게 교차 전환합니다. 시점 전환이나 다음 캐스팅 때문에 이미지 로딩 상태를 초기화하지 않습니다. 모션 감소 설정에서는 전환 효과를 생략합니다. 발판은 두 시점 모두 같은 별도 자산을 사용하며, 별도 발판이 없는 지역은 원본의 하단을 잘라 표시합니다.

자산 연결과 수면 크롭은 `fishing-environment.tsx`가 관리합니다. 기존 이미지의 하단에 발판이 포함돼 있다면 탑뷰 크롭에 들어오지 않도록 실제 경계에 맞춥니다. 새 수면 전용 이미지는 전체 높이를 사용합니다. 로드 실패 시 해당 해역의 기본 물색과 발판 대체 그림을 사용합니다.

생성 도구·참고 이미지·프롬프트·해시는 [시점별 manifest](../views.manifest.json)와 [가까운 수면 manifest](../close-water/manifest.json)에 보존합니다. 과거 생성 기록은 기존 manifest에 남깁니다. 이미지는 public에서 제공하며 DB나 Storage 변경이 필요하지 않습니다.

검증은 `tests/fishing-view-assets.test.ts`의 경로·PNG·크롭 검사와 `tests/tension-fishing-game.test.tsx`의 시점 전환·캐스팅 회귀 검사로 진행합니다. 실제 그림 검수에서는 정면 수면의 불투명감, 가까운 물결의 원근감, 부드러운 수중 대비와 모바일 크롭에서 중앙 찌의 시인성을 확인합니다.
