# 장식물 전환과 꾸미기

사용자 표시·코드 종류·이미지 폴더를 장식물 / `decoration` / `decorations`로 통일합니다. PNG 내용과 개체 이름·설명은 그대로입니다. 기존 enum 값과 보유 개체 ID, 어항, 위치, 선물 기록을 보존하며 전환합니다. 기존 구조물의 기본 회전은 0°, 배율은 1배입니다.

## 기존 DB 적용 순서

1. Storage의 공개 `collectibles` 버킷에서 `structures/`의 파일을 같은 하위 경로의 `decorations/`로 옮깁니다. 새 3종을 아직 업로드하지 않았다면 `assets/storage-upload/collectibles/decorations/normal/`의 PNG도 올립니다. 버킷 이름 `collectibles`는 그대로이고 하위 폴더 이름이 바뀝니다.
2. [01-decoration-editing.sql](01-decoration-editing.sql)을 SQL Editor에서 실행합니다. 반복 실행 가능합니다. 기존 23까지 필요합니다.
3. [24 일반 장식물 등록 SQL](../24-common-decorations/01-common-decorations.sql)을 실행합니다. 예전 구조물 버전 24를 실행한 경우도 같은 순서로 실행합니다.
4. 변경된 앱을 함께 적용하고 새로고침합니다. 기존 설치에서 이름 변경 전의 15~23 SQL을 다시 실행하지 마세요. 특히 15는 기존 낚시 기록을 초기화합니다. 신규 설치는 현재 01~23 → 25 → 24 순서입니다.

Storage 관리용 스크립트도 준비했습니다.

```powershell
# 로컬 파일 기준 계획 보기. 원격 변경 없음.
node scripts/migrate-decoration-storage.mjs
# 관리 키가 환경변수에 준비된 로컬 환경에서 이동 및 누락 이미지 업로드
node scripts/migrate-decoration-storage.mjs --apply
```

`SUPABASE_URL`(또는 기존 `VITE_SUPABASE_URL`)과 `SUPABASE_SECRET_KEY` 또는 `SUPABASE_SERVICE_ROLE_KEY`를 사용합니다. 관리 키는 브라우저에 노출되는 `VITE_` 변수에 넣지 않습니다. 기존 목적지에 다른 파일이 있으면 덮어쓰지 않고 중단합니다. 원본·목적지 내용이 같으면 이전 경로만 정리하며, 완료한 이동은 재실행 시 건너뜁니다. 현재 세션의 공개 키로는 원격 업로드·DB 변경을 수행할 수 없어 로컬 준비와 검증만 완료했습니다.

## 사용 방법

장식물을 클릭하거나 탭하면 개체 위에 회전·−·+ 아이콘 버튼만 뜹니다. 도구 모음은 약 110px 너비로 작게 표시하고 버튼 사이에 세로 구분선을 두며 그림자는 사용하지 않습니다. 회전은 한 번에 15°, 크기는 한 번에 0.1배씩 조정하며 0.5~2배 범위를 유지합니다. 변경은 자동 저장됩니다. 수조 배경을 누르면 도구 모음이 닫히며 진행 중인 저장은 계속됩니다. 위치는 직접 드래그해 조정합니다. 저장 실패 시 이전 상태로 복원하고 안내합니다.

아쿠아리움은 공통 헤더를 제외한 남은 화면 높이를 채우며 페이지 스크롤이 생기지 않습니다. 모바일에서는 화면 폭을 채우고 컴퓨터에서는 다른 페이지처럼 최대 448px 너비로 가운데 정렬합니다. 제목·설명·어항 목록·이동 화살표 대신 우측 상단에 n/n과 + · 골드 200 구매 버튼을 표시합니다. 어항 이동은 빈 유리 스와이프/드래그 또는 수조 방향키로 처리합니다. 다른 페이지의 여백은 유지합니다. 회전 후의 외곽까지 계산해 드래그·크기 조정 시 장식물이 수조 밖으로 잘리지 않게 합니다.

`arrange_decoration` RPC는 로그인·본인 어항·본인 보유·장식물 종류·미판매·미수령 선물 제외 조건을 검사합니다. 좌표는 0~1, 회전은 0~360°, 배율은 0.5~2로 서버에서 검증하며 직접 테이블 수정은 허용하지 않습니다. 선물 스냅샷의 종류와 이미지 경로, 기존 낚시·위치·판매·선물 함수의 종류 검사도 함께 전환합니다.

검증: `npm.cmd test`, `npm.cmd run build`, `node scripts/verify-common-decorations.mjs`.
