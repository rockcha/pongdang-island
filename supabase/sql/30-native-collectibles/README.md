# 토착 개체·지역 등급

29 이후 [01-native-collectibles.sql](01-native-collectibles.sql)을 실행합니다. 산호빛 작은 집은 희귀로, 안개달 해역은 희귀로 변경합니다. 이미지·판매가·기존 보유 개체·배치·해금은 유지합니다. 산호 관련 개체를 포함해 기존 서식지는 변경하지 않습니다.

`collectible_species.native_region_id`는 토착 지역 FK이며 기본값은 null입니다. `is_native`는 `native_region_id is not null`에서 자동 계산하는 boolean입니다. 물고기·쓰레기·장식물에 사용할 수 있고 지도는 토착 개체가 될 수 없습니다. 클라이언트는 두 필드를 받으며 도감 상세에서 토착 여부를 표시합니다. 기존 `to_jsonb(s)` 응답에 새 필드가 자동 포함됩니다. 이전 선물 스냅샷은 그대로 둡니다.

토착 개체는 커밋 시 `collectible_habitats`가 정확히 한 행이어야 하고 그 지역이 native_region_id와 같아야 합니다. 개체와 서식지 양쪽의 지연 제약 트리거로 0개·2개·다른 지역을 차단합니다. 서식지 변경 시 부모 행을 잠가 동시 변경을 직렬화합니다. 함수는 security invoker이고 외부 실행 권한을 부여하지 않습니다. 카탈로그 쓰기 권한은 기존 관리자 권한을 유지합니다.

관리자가 토착으로 지정할 때는 한 트랜잭션에서 native_region_id를 설정하고 기존 서식지를 정리한 다음 해당 지역 한 행을 등록합니다. 일반 개체로 되돌릴 때는 native_region_id를 null로 설정합니다. is_native는 직접 입력하지 않습니다. 기존 개체는 모두 비토착으로 유지하며 안개달 신규 후보는 추천 단계로 등록하지 않습니다.

안개달 지도는 희귀 결과에서 목적지 등급 기준으로 추첨합니다. 지도 템플릿 ocean-map 자체 등급과 무관하게 지역의 등급을 사용하고 낚시 결과 기록도 목적지 등급으로 남깁니다. 일반 낚시 실패·다른 개체 등급 규칙은 유지합니다. 원격 실행은 SQL Editor에서 수행합니다.
