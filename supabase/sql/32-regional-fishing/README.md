# 해역별 낚시 확률·지역 지도·퐁당 토착 개체

31 이후 새 PNG 9장을 업로드하고 [01-regional-fishing.sql](01-regional-fishing.sql)을 실행합니다. 원격 적용은 SQL Editor에서 수행합니다. 보유 개체·배치·지도 해금·낚시 operation ID를 보존합니다. 업로드 매핑과 이미지 프롬프트는 `assets/storage-upload/new/regional-fishing/manifest.json`에 기록합니다.

## 확률

일반 미끼의 **성공 조건부 등급 분포**는 아래와 같습니다. 미끼별 실패율은 유지하며 실제 화면에는 실패를 포함한 서버 계산 확률을 표시합니다. 정수 basis point 반올림 오차는 최저 허용 등급으로 배분합니다.

| 해역 등급 | 일반 | 희귀 | 특급 | 신화 |
| --- | --- | --- | --- | --- |
| 일반 | 85% | 13% | 1.8% | 0.2% |
| 희귀 | 81% | 16% | 2.6% | 0.4% |
| 특급 | 77% | 19% | 3.4% | 0.6% |
| 신화 | 73% | 22% | 4.2% | 0.8% |

희귀 보장 미끼는 일반을 제외합니다. 일반 해역은 희귀 98.7%·특급 1%·신화 0.3%, 해역 등급이 한 단계 오를 때 희귀 -0.5%p·특급 +0.4%p·신화 +0.1%p입니다. 특급 보장 미끼는 특급 99.7%·신화 0.3%에서 단계마다 신화 +0.2%p입니다. 기존 장식물 미끼는 현재 해역 장식물의 균등 추첨과 획득 보장을 유지하며 지도는 나오지 않습니다.

`regional_bait_odds`가 실제 표시와 추첨의 단일 기준입니다. `fishing_state()`는 현재 이동 지역을 기준으로 유효 확률·지역명을 반환하며 외부에서 임의 확률을 전달할 수 없습니다. 내부 함수는 실행 권한을 공개하지 않습니다. 낚시 인증·지역 잠금·미끼 재고·행 잠금·재시도 멱등성을 유지합니다.

## 지도

지역마다 독립된 지도 5종을 등록하고 지역과 같은 등급을 부여합니다. 퐁당섬 앞바다·산호빛 여울은 일반, 안개달 해역·별잠 유적은 희귀, 꿈먹는 심연은 특급입니다. 지도 카탈로그에도 희귀·특급을 허용하도록 기존 제약을 조정합니다.

일반 낚시에서 등급을 결정한 뒤, 해당 등급에 **잠긴 목적지 지도 후보가 있을 때 5%**로 지도 후보 하나를 선택합니다. 나머지는 현재 해역의 동일 등급 어종·쓰레기입니다. 지도 후보가 없거나 이미 모두 해금했다면 전체를 어종·쓰레기에 배분합니다. 시작 해역 지도는 도감에만 있으며 기본 해금 지역이므로 낚시에서 나오지 않습니다. 기존 ocean-map 템플릿은 신규 추첨·카탈로그 목록에서 제외하되 과거 소유 개체와 발견 기록은 보존합니다.

## 퐁당 개체

| 이름 | 종류 | 등급 | 크기 | 판매 골드 |
| --- | --- | --- | --- | --- |
| 잠수부 퐁당이 | 유영 개체 | 특급 | 82 | 650 |
| 퐁당 물고기 | 어종 | 희귀 | 66 | 180 |

두 개체는 퐁당 앞바다 토착입니다. 이름에 ‘퐁당’이 들어가는 물고기·쓰레기·장식물은 native_region_id=pongdang으로 자동 지정하는 트리거를 추가합니다. 기존 해당 개체의 서식지를 퐁당 하나로 정리합니다. ‘퐁이’나 설명에만 ‘퐁당’이 들어가는 기존 개체·미끼·지도는 이 규칙에 포함하지 않습니다. 이후 같은 이름 규칙으로 등록하는 개체도 단일 서식지를 함께 등록해야 합니다.

기존 토착 지역 배지에 자동 반영됩니다. 잠수부는 참고한 퐁이 얼굴과 불가사리를 살린 잠수복 차림의 유영 개체이며 2×2 시트로 헤엄칩니다. 퐁당 물고기는 불가사리를 머리에 단 살구색 어종이며 2×2 유영 시트를 사용합니다. PNG는 내장 image_gen으로 만들고 `assets/storage-upload/new/regional-fishing/`에 평면으로 저장합니다.
