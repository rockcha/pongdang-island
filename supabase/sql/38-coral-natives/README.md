6종 모두 native_region_id='coral'이며 서식지는 산호빛 여울 하나입니다. 기존 산호집게 꽃게와 다른 개체의 서식지는 변경하지 않습니다. 기존 지역 아이콘이 도감·보관함 등에서 자동으로 붙습니다.

일반·희귀는 저장된 퐁이 카툰 참고, 특급 산호왕관 거북은 별빛 가오리 참고의 부드러운 판타지 일러스트를 사용합니다. 말미잘은 고정 장식물이라 썸네일 한 장, 어종 5종은 각각 썸네일과 2×2 시트로 총 11 PNG입니다.
