# 원본 이미지 방향

38 이후 `01-artwork-facing.sql`을 Supabase SQL Editor에서 실행합니다.
기존 프로젝트는 수동 SQL 방식이므로 이 파일이 DB 적용본입니다.

`collectible_species.facing_direction`은 원본 그림의 머리 방향입니다.
`left` / `right` / `front`(정면 또는 좌우 방향 없음)를 사용하며,
NULL은 미검토 상태입니다. `travel_direction`은 실제 이동 방향으로 별도 유지합니다.
현재 실행 규칙은 오른쪽 원본을 기본으로 하며, 검토한 왼쪽 원본 14종만 예외 처리합니다. 과거 `front` 값은 반전 금지에 사용하지 않고 오른쪽 기준으로 처리합니다. 이동하는 어종은 `flip_with_direction`의 과거 값과 관계없이 실제 이동 방향에 맞춰 반전합니다. 원본이 오른쪽이면 왼쪽 이동 시 반전하고, 원본이 왼쪽이면 오른쪽 이동 시 반전합니다. 고정 개체는 제외합니다. 검토한 이미지 경로의 방향은 오래된 DB 값보다 우선합니다.

2026-10-15 Storage의 실제 유영 이미지 50종, 각 2×2 시트의 네 프레임을 검토했습니다.
왼쪽 14종, 오른쪽 23종, 정면/방향 없음 13종입니다.
기록은 `src/features/aquarium/artwork-facing.json`에 이미지 경로와 SHA-256으로 보관합니다.
원본 파일이나 경로를 바꾸면 방향도 다시 검토해야 합니다.

DB 값이 있으면 우선 사용하며, 아직 컬럼을 적용하지 않은 환경은 검토한 이미지
경로별 설정을 사용합니다. 미검토 이미지는 기존 오른쪽 기준 처리를 유지합니다.
SQL은 검토한 경로와 일치하는 어종의 NULL 값만 채우므로 수동 변경 값은 보존합니다.
앵무조개의 기존 반전 금지 설정은 함께 해제합니다.

이 변경은 Storage 원본, 보유 개체, 이동 경로, 위치 및 접근 정책을 변경하지 않습니다.
