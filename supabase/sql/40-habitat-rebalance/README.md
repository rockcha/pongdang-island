# 서식지 조정과 장식물 삭제

39 이후 [01-habitat-rebalance.sql](01-habitat-rebalance.sql)을 적용합니다. 2026-10-15 연결된 프로젝트에 동일한 데이터 변경을 적용하고 재조회로 검증했습니다. 다른 프로젝트나 새 설치에서는 이 SQL이 필요합니다.

| 개체 | 서식지 |
| --- | --- |
| 은안개 망둑 | 퐁당섬 앞바다 · 안개달 해역 |
| 흐릿한 유리구슬 | 퐁당섬 앞바다 · 산호빛 여울 · 안개달 해역 |
| 초승달 해마 | 산호빛 여울 · 안개달 해역 |
| 산호콩 새우 | 퐁당섬 앞바다 · 산호빛 여울 |
| 산호집게 꽃게 | 퐁당섬 앞바다 · 산호빛 여울 |

다섯 종의 `native_region_id`를 비워 기존 단일 서식지 제약과 일치시킵니다. 토종은 서식지가 한 곳인 개체를 의미하며 도감에서는 별도 배지·문구 대신 서식지 아이콘만 표시합니다.

달잠 수련과 안개종 풍경은 카탈로그와 서식지에서 삭제합니다. 적용 당시 보유·발견·미수령 선물은 모두 0건이었습니다. SQL은 미수령 선물이 있으면 중단하고, 보유·발견 기록이 생긴 경우에도 외래 키가 삭제를 막아 트랜잭션을 되돌립니다. 기존 보유 개체와 낚시 기록은 지우지 않습니다. Storage 원본 PNG와 과거 생성 기록은 보존합니다.

31·36·38은 과거 등록 SQL입니다. 재실행하면 과거 서식지나 삭제한 장식물이 복구될 수 있으므로 마지막에 40을 다시 적용합니다.
