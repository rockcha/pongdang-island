새 종 3개는 아직 원격 DB에 등록되지 않았습니다. API로 종과 서식지를 따로 삽입하면 원격 DB의 단일 서식지 제약으로 중단되어, 이 SQL로 함께 등록해야 합니다. 로컬 PostgreSQL(PGlite)에서 등록·등급·단일 서식지·재실행 검증을 통과했습니다. 사용자의 보유 개체와 배치는 변경하지 않습니다.

29·37 같은 이전 등록 SQL은 기존 설정을 복원할 수 있으므로 재실행 시 41을 마지막에 적용합니다.
