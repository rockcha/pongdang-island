# 상어·고래 이름·서식지·유영 시트 교체

41 이후 [01-shared-shark-whale.sql](01-shared-shark-whale.sql)을 실행합니다. [교체 배치](../../../assets/storage-upload/new/20261015-155535/README.md)의 시트 2장이 업로드되어 있어야 합니다.

퐁당 상어는 햇물결 상어, 퐁당 고래는 물결날개 고래로 변경합니다. 특급 등급·종 ID·보유 개체·발견 기록·썸네일은 유지하고 설명과 시트 경로를 교체합니다. native_region_id를 비우고 적용 당시 모든 regions 행을 서식지로 연결합니다. 현재 5개 해역에 실제 반영하고 조회·시트 해시 검증을 마쳤습니다.

41은 과거 고유 개체 등록 기록입니다. 다시 실행했다면 42를 마지막에 적용해야 현재 이름과 공통 서식지·새 시트가 유지됩니다. 퐁이 탐사선은 이 변경에 포함하지 않습니다.
