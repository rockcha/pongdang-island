# 주황 토착 상어·고래와 기존 이동 시트 교체

42 이후 [01-native-pongdang-and-current-swim.sql](01-native-pongdang-and-current-swim.sql)을 SQL Editor에서 실행합니다. [생성 배치](../../../assets/storage-upload/new/20261015-161244/README.md)의 PNG 7개는 업로드와 다운로드 해시 검증을 완료했습니다.

기존 햇물결 상어·물결날개 고래·퐁이 탐사선은 이름·등급·서식지와 보유 개체를 유지하고 새 시트 경로만 연결합니다. 이 세 종의 변경은 실제 DB에 반영했습니다.

새 퐁당 상어(`pongdang-native-shark`)와 퐁당 고래(`pongdang-native-whale`)는 특급이며 주황·크림색 몸과 머리에 붙은 불가사리로 구분합니다. 서식지는 `pongdang` 한 곳입니다. 기존 공통 서식 상어·고래와 별도 종으로 등록하며, 기존 종을 이름 변경하거나 복제 보유 처리하지 않습니다.

새 종 등록은 API로 종과 서식지를 따로 삽입할 수 없어 아직 미적용입니다. 이 SQL은 같은 트랜잭션에서 종과 서식지를 등록하고 마지막에 단일 서식지 제약을 검증합니다. 반복 실행해도 보유 개체·발견 기록·위치는 유지합니다. 이전 41·42를 재실행했다면 43을 마지막에 적용합니다.
