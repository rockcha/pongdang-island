# 안개달 쓰레기·장식품 등록

44번 다음 [01-mistmoon-relics.sql](01-mistmoon-relics.sql) 전체를 Supabase SQL Editor에서 실행합니다. 이미지 6개는 Storage 업로드 완료이며 **원격 DB 등록은 SQL Editor 적용 대기**입니다. 현재 연결에는 SQL 실행 인터페이스가 없습니다.

[이미지·등급·가격·프롬프트](../../../assets/storage-upload/new/20261015-173555/README.md).

쓰레기: 금 간 찻잔(일반), 멈춘 달시계(희귀), 루네아의 실패한 초대장(특급). 장식품: 졸음버섯 군락(일반), 꿈을 담는 우물(희귀), 루네아의 기록 서가(특급). 모두 안개달 한 곳에만 서식합니다.

기존 `collectible_nonfish_common` 제약은 쓰레기를 일반으로 제한하므로 제거합니다. 기존 등급 enum·필수값 제약은 유지합니다. 32번의 지역 낚시는 이미 물고기·쓰레기를 등급별로 선택하므로 희귀·특급 쓰레기도 해당 등급 후보에 포함됩니다. 기존 개체의 등급이나 서식지는 바꾸지 않습니다.

SQL은 한 트랜잭션으로 종과 단일 서식지를 등록하며 재실행해도 보유·배치 기록을 보존합니다. 로컬 PGlite에서 반복 적용과 장식품 보유 위치 보존을 검증했습니다.
