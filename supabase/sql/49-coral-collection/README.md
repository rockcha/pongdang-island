48 이후 `01-coral-collection.sql`을 적용합니다. 이미지 배치는 `assets/storage-upload/new/20261015-192806/`입니다. 먼저 해당 PNG를 collectibles 버킷의 동일 하위 경로로 업로드합니다. SQL은 반복 실행할 수 있으며 기존 소유·배치·발견을 유지합니다.

## 신규 15종

| 등급 | 분류 | 이름 |
| --- | --- | --- |
| 일반 | 어종 | 산호짐꾼 게 |
| 일반 | 장식품 | 산호꽃 아치 |
| 일반 | 쓰레기 | 산호 조각 · 바다 오르골 |
| 희귀 | 어종 | 홍련 지느러미돔 · 산호모자 문어 · 진주등 산호거미게 · 꽃섬 등딱지게 |
| 희귀 | 장식품 | 여울의 작은 회전목마 · 첫 산호의 요람 · 물고기 낮잠표지판 |
| 특급 | 어종 | 꽃너울 해파리 · 홍옥 눈동자 곰치 · 꽃갈기 바다사자 |
| 신화 | 고정 어종 | 천년산호 거대게 |

모두 coral 토착종이며 서식지는 산호빛 여울 하나입니다. 신화 거대게는 movement_type=fixed로 좌표를 유지하고 idle_animated=true로 다리·산호 끝의 작은 동작을 재생합니다. 분류 fish는 게임의 생물 카테고리로 갑각류·문어·해파리·바다사자를 포함합니다.

## 기존 개체

- 사용자가 확인한 산호해마는 꽃산호 해룡입니다. 기존 ID·썸네일·등급·서식지는 유지하고 v2 스프라이트 경로만 교체합니다. 기존 왼쪽 원본을 유지합니다.
- 산호꽃 말미잘은 기존 장식품 ID로 upsert하며 촉수 시트를 추가합니다. DB에 없다면 같은 희귀 장식품으로 등록합니다. 기존에 있던 개체의 소유권과 위치를 보존합니다.

`idle_animated`는 기본 false인 선택적 설정입니다. 장식품의 선택적 스프라이트를 허용하도록 collectible_sheet_layout 제약을 갱신하며, 다른 어종의 이동 설정은 변경하지 않습니다. 고정 개체는 이동 없이 천천히 재생하고 편집 중·모션 감소 설정에서는 프레임 0으로 정지합니다.

원격 SQL 적용은 별도입니다. 파일 존재 여부만으로 DB 적용이나 업로드 완료를 가정하지 않습니다.

후속 50 SQL은 공통 4종의 토착 여부·서식지와 거대게의 이동 방식을 변경합니다. 현재 설정은 50을 마지막으로 적용한 상태가 기준입니다.
