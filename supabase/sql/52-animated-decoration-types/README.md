# 스프라이트 장식품 분류와 크기 조정

51 다음에 실행합니다. 기존 이미지 경로를 그대로 사용하므로 재업로드는 필요하지 않습니다.

- 침수된 풍차: 장식품으로 변경, 크기 98 → 145.
- 완두 해면·안개빵 해면: 장식품으로 변경.
- 위 세 종은 `fixed`, `idle_animated=true`로 제자리 스프라이트를 재생합니다. 장식품은 `sprite_sheet_path`가 있으면 사용하고 없으면 썸네일을 사용합니다.
- 새벽을 여는 일각고래: 크기 118 → 160. 어종과 유영 동작 유지.

개체 ID·보유 내역·발견·서식지·배치 좌표는 유지합니다. 안개빵 해면은 안개달 토착종, 풍차와 완두 해면은 공통 개체입니다. 장식품으로 전환한 세 종은 장식품 낚시 대상으로 분류됩니다. 예전 시드를 다시 실행했다면 마지막에 52를 재실행합니다.

표시 크기는 수조 너비의 40% 상한과 사용자 확대·축소 설정도 적용받습니다. 원격 SQL은 별도 실행합니다.
