# 걷는 아틀란티스 수호병

56 다음에 `01-walking-atlantean-sentinel.sql`을 실행합니다. 새 보행 시트는 `assets/storage-upload/new/20261015-221928/fish/mythic/atlantean-sentinel-walk_sprite.png`입니다.

수호병을 `crawl`, 속도 0.012, 바닥 높이 0.84~0.94로 변경합니다. 제자리 재생용 `idle_animated`는 끄고 보행 애니메이션을 사용합니다. 다리를 번갈아 디디고 삼지창을 든 채 이동하며 망토가 함께 흐릅니다. 원본은 오른쪽이며 진행 방향에 따라 반전합니다.

신화 등급·별잠 토착·크기 150·썸네일·보유 개체와 배치는 유지합니다. 기존 고정 배치 좌표는 삭제하지 않으며 이동형 렌더러가 유영 좌표를 사용합니다. 56을 다시 실행했다면 이 SQL도 다시 적용합니다. 원격 SQL은 별도 실행합니다.
