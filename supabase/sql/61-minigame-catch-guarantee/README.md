# 미니게임 성공 후 획득 보장

60 이후 `01-minigame-catch-guarantee.sql`을 SQL Editor에서 실행합니다. 추가 이미지 업로드는 없습니다. 미끼의 서버 실패 확률을 0으로 바꿔 미니게임 통과 후 다시 실패하는 문제를 해결합니다. 해역별 등급 보정·최소 등급·지도 추첨과 미끼 1개 소모는 유지합니다. 적용 전 실패 기록은 보존하므로 기존 operation_id 재확인에는 이전 결과가 그대로 반환됩니다. 적용 후 새로운 낚시부터 보장됩니다.

트랜잭션 안에서 모든 미끼·해역의 합계 10000bp와 0/9999 추첨 경계를 검사합니다. 실패하면 전체 변경을 롤백합니다. 원격 DB 적용 여부는 별도 확인이 필요합니다.
